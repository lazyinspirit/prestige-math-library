## Example

Take the worldsheet $\Sigma=\mathbb C$ with its standard global complex chart $z=x+iy$, orientation $dx\wedge dy$, and dimensionless coordinates. Use the ordinary norm topology, generated by $p(a)=|a|$, on the state space $\mathcal H=\mathbb C$; set the common domain $\mathcal D=\mathbb C$ and field-label space $\mathcal F=\mathbb C$ with the same norm topology. Present $\mathcal H$ as the completed direct sum with one sector $\mathcal H_*=\mathbb C$, indexed by $I=\{*\}$ and carrying joint weight $(0,0)$. Let every left and right Virasoro mode vanish, $L_n=\bar L_n=0$ for every $n\in\mathbb Z$, with $c_L=c_R=0$. Set the vacuum to $\Omega=1$ and the correlator functional to $\epsilon(a)=a$.

Use the identity state-field map $\sigma:\mathcal F\to\mathcal D$, $\sigma(a)=a$, and the pointwise weak field representative $Y(a;z,\bar z)=a\,\operatorname{Id}_{\mathbb C}$. For any chart domain $U\subseteq\mathbb C$, view a test function $f\in C_c^\infty(U)$ as a smooth complex-valued function of the coordinate $z$, and define smearing by coordinate Lebesgue integration with $d^2z=dx\,dy$:

$$Y(a;f)=a\left(\int_U f(x+iy)\,dx\,dy\right)\operatorname{Id}_{\mathbb C}.$$

Use all restrictions of biholomorphic coordinate charts on $\mathbb C$.
For every chart set $\Omega_i=1$ and $\epsilon_i(a)=a$;
for a centered chart at $p$, set $\sigma_i(a)=a$. For every overlap set
$R_{ji}(z)=I_{\mathbb C}$ and $W_{ji}=I_{\mathbb C}$.
Use the usual compact-support test topology on
$E_i(V)=C_c^\infty(V,\mathbb C)d^2z$, and put
$\mathcal Y_i(s)=(\int_V s(z)d^2z)I$. Transport test densities by
$(P_{ji}s)(g_{ji}(z))=|g_{ji}'(z)|^{-2}s(z)$.
These choices include arbitrary non-affine chart changes and all centered
insertion charts, not just the one global coordinate.

For every ordered pair $a,b\in\mathcal F$, use the single identity-channel OPE with index set $\{*\}$, field $\phi_*=1$, coefficient $C_{a,b}^*(z-w,\bar z-\bar w)=ab$, and radial domain $0<|z-w|<1$. The package is bosonic, unitary, reflection-positive, rational in the declared finite-dimensional module category below, and discrete-spectrum; its continuous-spectrum flag is false. The analytic continuation convention treats barred insertion coordinates as independent complex variables and then restricts to the Euclidean locus. All fields, coefficients, and correlators are constant, so continuation has no branch ambiguity.

For unitarity use $\langle u,v\rangle=u\bar v$, linear in the first argument, with pointwise field adjoint $Y(a;z,\bar z)^*=Y(\bar a;z,\bar z)$. For reflection positivity take $\theta(z)=\bar z$, positive half-surface $U_+=\{z:\operatorname{Im}z>0\}$, and field polynomials generated by smearings supported in $U_+$. If $f$ is such a test function, set $f^\theta(z)=\overline{f(\bar z)}$ on the lower half-plane and define $\Theta$ on the algebra generated by both reflected half-surface domains antilinearly by $\Theta(Y(a;f))=Y(\bar a;f^\theta)$ and $\Theta(FG)=\Theta(G)\Theta(F)$. For rationality, declare left and right chiral algebras $A_L=A_R=A=\mathbb C\mathbf1$, identifying scalar $a$ with $a\mathbf1$; their product is $(a\mathbf1)(b\mathbf1)=ab\mathbf1$, the vacuum is $\mathbf1$, translation is zero, and each conformal vector and central charge are $\omega=0$ and $c=0$. Their state-field map is $Y_A(a\mathbf1,z)b\mathbf1=ab\mathbf1$. Use the category of finite-dimensional modules satisfying the ordinary module axioms for either algebra, with module homomorphisms.

This is an example of the selected genus-zero state-space/OPE package. It asserts no physical model, path-integral measure, higher-genus sewing or factorization, or equivalence with another CFT axiom system.
