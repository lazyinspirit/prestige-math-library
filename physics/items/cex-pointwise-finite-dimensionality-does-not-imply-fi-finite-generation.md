## Statement refuted

**Refuted claim:** an FI-module over a field whose values $V_S$ are
finite-dimensional for every finite set $S$ is finitely generated.

The witness is built below: over a field $k$, take $V_S=k\,e_S$
one-dimensional for every finite set $S$, with bijections acting as the
identity identification of the lines and non-bijections acting as $0$. Then
$\dim_kV_S=1$ for all $S$, but no finite set of elements generates $V$
([[def-finite-generation-and-generation-degree-of-an-fi-module]]).

## Facts & Assumptions

**Given:** A field $k$ and, for every finite set $S$, the one-dimensional $k$-vector space $V_S:=k\,e_S$ with distinguished nonzero vector $e_S$; for an injection $f\colon S\to S'$ let $V(f)\colon V_S\to V_{S'}$ send $e_S\mapsto e_{S'}$ when $f$ is a bijection and $e_S\mapsto0$ otherwise.

[F1] An FI-module over $k$ is a covariant functor from the category of finite sets and injections to $k$-modules, so $V(\mathrm{id}_S)=\mathrm{id}_{V_S}$ and $V(g\circ f)=V(g)\circ V(f)$ for composable injections ([[def-fi-category-and-fi-module]]).

[F2] For a set $\Sigma$ of supported elements $(S,s)$, $\operatorname{span}_V(\Sigma)_T$ is the $k$-span of the elements $f_*(s)$ with $(S,s)\in\Sigma$ and $f\colon S\to T$ an injection; $V$ is finitely generated when $\operatorname{span}_V(\Sigma)=V$ for some finite $\Sigma$ ([[def-finite-generation-and-generation-degree-of-an-fi-module]]).

[F3] A composite of bijections is a bijection; if $g\circ f$ and $f$ are bijections then $g$ is a bijection; and if $f$ is not a bijection then $g\circ f$ is not a bijection ([[def-injection-surjection-bijection]]).

[F4] For every $n\ge0$ the set $[n]=\{0,1,\dots,n-1\}$ has exactly $n$ elements ([[def-finite-symmetric-group-and-permutation-notation]]).

## Counterexample

**Proof technique:** direct.

1.1 $V$ is a functor: $V(\mathrm{id}_S)$ sends $e_S$ to $e_S$ because $\mathrm{id}_S$ is a bijection; and for composable injections $f\colon S\to T$, $g\colon T\to U$ the two sides of $V(g\circ f)=V(g)V(f)$ agree on $e_S$ in each case — if $f$ and $g$ are bijections both sides send $e_S\mapsto e_U$; if $g$ fails to be a bijection then $g\circ f$ fails to be a bijection, so both sides are $0$; and if $f$ fails to be a bijection then $g\circ f$ fails to be a bijection and both sides are $0$. Hence $V$ is an FI-module and $\dim_kV_S=1$ for every finite set $S$. [F1, F3, given, algebra]

1.2 Suppose $\Sigma=\{(S_1,s_1),\dots,(S_r,s_r)\}$ is a finite set of supported elements that generates $V$, with $s_i\in V_{S_i}$, and put $M:=\max_i|S_i|$ (if $r=0$, then $\operatorname{span}_V(\varnothing)=0\ne V$, so $r\ge1$). For every finite set $T$ with $|T|>M$, every injection $f\colon S_i\to T$ satisfies $|S_i|\le M<|T|$, so $f$ is not a bijection and $f_*(s_i)=V(f)(s_i)=0$. [F3, given]

2.1 By the explicit description of the span, step 1.2 shows $\operatorname{span}_V(\Sigma)_T=0$ for every finite set $T$ with $|T|>M$. Taking $T=[M+1]$, which has $M+1>M$ elements, gives $\operatorname{span}_V(\Sigma)_T=0$ while $V_T=k\,e_T\ne0$; hence $\operatorname{span}_V(\Sigma)\ne V$ and no finite set of elements generates $V$. [F2, F4, step 1.2]

3.1 Thus $V$ has $\dim_kV_S=1$ for every finite set $S$ by step 1.1, yet is not finitely generated by step 2.1: pointwise finite-dimensionality does not imply finite generation, and the refuted claim fails. [F2, step 1.1, step 2.1] ∎
