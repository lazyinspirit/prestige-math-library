## Definition

Assume the Axiom of Choice [[def-axiom-of-choice]] and fix an integer dimension $d\geq1$. A configuration is a locally finite simple point set $\omega\subset\mathbb R^d$ with the count sigma-algebra and unit-intensity Poisson reference from [[def-tdmath-poisson-configuration-reference]]; thus every bounded Borel set contains finitely many points, and the sigma-algebra is generated by its bounded-set counts. Write $N_A(\omega)=|\omega\cap A|$.

Use the interface of [[def-csm-stable-superstable-continuum-interaction]]: $\phi:\mathbb R^d\to\mathbb R\cup\{+\infty\}$ is even and Borel, and some finite $B\geq0$ satisfies $U_N(X)\geq-BN$ for every finite position list $X=(x_1,\ldots,x_N)$. For a finite simple configuration $\omega$, enumerate its points as such a list and write $U_\phi(\omega)=\sum_{\{x,y\}\subset\omega}\phi(x-y)$; its unordered-pair arguments are nonzero, and stability gives $U_\phi(\omega)\geq-B|\omega|$. For this item assume finite range $R>0$, meaning $\phi(x)=0$ whenever $\|x\|_2>R$.

Let $\Lambda\subset\mathbb R^d$ be a nonempty bounded Borel region and let $\eta\subset\Lambda^c$ be a locally finite exterior configuration. The relevant exterior set is
$$\eta_\Lambda^R=\{y\in\eta:\operatorname{dist}_2(y,\Lambda)\leq R\};$$
it is finite because it lies in a bounded set. For a finite interior configuration $\omega\subset\Lambda$, define the conditional energy
$$H_\Lambda(\omega\mid\eta)=\sum_{\{x,y\}\subset\omega}\phi(x-y)+\sum_{x\in\omega}\sum_{y\in\eta_\Lambda^R}\phi(x-y).$$
For positive mathematical parameters $z,\beta>0$, define the unit-Poisson-reference partition integral and candidate kernel by
$$Z_\Lambda^\eta(z,\beta)=\int z^{N_\Lambda(\omega)}e^{-\beta H_\Lambda(\omega\mid\eta)}\,Q_\Lambda(d\omega),\qquad \gamma_\Lambda^\eta(d\omega)=\frac{z^{N_\Lambda(\omega)}e^{-\beta H_\Lambda(\omega\mid\eta)}}{Z_\Lambda^\eta(z,\beta)}\,Q_\Lambda(d\omega),$$
where $Q_\Lambda$ is the restriction of the unit-intensity Poisson law and $e^{-\beta(+\infty)}=0$. The accompanying lemma proves that $Z_\Lambda^\eta$ is finite and strictly positive and that $\eta\mapsto\gamma_\Lambda^\eta$ is a probability kernel.

Extend $\gamma_\Lambda^\eta$ to a kernel on full configurations by replacing the interior with $\omega$ and leaving $\eta$ unchanged outside $\Lambda$. A continuum DLR law for this specification is a probability measure $\mu$ on configuration space satisfying $\mu\gamma_\Lambda=\mu$ for every nonempty bounded Borel $\Lambda$, where this identity means equality of integrals for every bounded measurable full-configuration test. The kernel consistency and its conditional-law interpretation are proved in [[lem-csm-continuum-kernel-normalization]]. This definition asserts no existence, uniqueness, or thermodynamic-limit result.
