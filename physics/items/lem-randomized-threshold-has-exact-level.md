## Statement

Let $Q$ be a Borel probability measure on $\mathbb R$ and let $0<\alpha<1$.
There are $c_+,c_-\in\mathbb R$ and $\gamma_+,\gamma_-\in[0,1]$ such that
$$Q((c_+,\infty))+\gamma_+Q(\{c_+\})=\alpha,\qquad Q(( -\infty,c_-))+\gamma_-Q(\{c_-\})=\alpha.$$

## Facts & Assumptions

**Given:** A Borel probability measure $Q$ on $\mathbb R$ and $0<\alpha<1$.

[F1] A measure is countably additive on pairwise disjoint measurable sequences. ([[def-measure]])

[F2] $Q(\mathbb R)=1$ and $Q$ is a measure. ([[def-probability-measure]])

[F3] Every nonempty real set bounded below has an infimum, and an infimum is its greatest lower bound. ([[def-infimum]], [[thm-infimum-property]])

[F4] The Borel sigma-algebra is generated by the open sets. ([[def-borel-sigma-algebra]])

## Proof

1.1 If $E_n\uparrow E$, write $D_0=E_0$ and $D_n=E_n\setminus E_{n-1}$ for $n\ge1$; these sets are disjoint with union $E$, so [F1] gives $Q(E)=\sum_nQ(D_n)=\lim_nQ(E_n)$. If $E_n\downarrow E$ and $Q(E_0)<\infty$, apply continuity from below to $E_0\setminus E_n\uparrow E_0\setminus E$ and subtract from $Q(E_0)$. Thus $Q$ is continuous from below and above. [given, F1, algebra]

2.1 Set $S(t)=Q((t,\infty))$ and $C=\{t:S(t)\le\alpha\}$. By step 1.1, $S(n)\to0$ and $S(-n)\to1$, so $C$ is nonempty and bounded below; it is upward closed. Let $c_+=\inf C$ by [F3]. For $t>c_+$ there is $s\in C$ with $s<t$, hence $S(t)\le\alpha$; for $t<c_+$, $S(t)>\alpha$. Continuity from below and above gives $Q((c_+,\infty))\le\alpha\le Q([c_+,\infty))$. If $d=Q(\{c_+\})>0$, set $\gamma_+=(\alpha-Q((c_+,\infty)))/d\in[0,1]$; if $d=0$, the inequalities force $Q((c_+,\infty))=\alpha$, so take $\gamma_+=0$. [given, F2, F3, step 1.1, choose, algebra]

3.1 Define $Q^-(B)=Q(\{x:-x\in B\})$. Continuity of reflection and [F4] show every Borel $B$ has Borel preimage; [F1]–[F2] then make $Q^-$ a Borel probability. Apply step 2.1 to $Q^-$, obtaining $c'$ and $\gamma_-$. With $c_-=-c'$, $Q^-((c',\infty))=Q(( -\infty,c_-))$ and $Q^-(\{c'\})=Q(\{c_-\})$, which gives the lower-tail equality. [step 2.1, F1, F2, F4, construct, algebra] ∎

## Remarks

The value $\gamma$ randomizes only at the boundary atom. If there is no atom at the selected threshold, the tail already has probability exactly $\alpha$ and the boundary value is immaterial.
