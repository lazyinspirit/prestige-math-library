## Statement

Let $(X,\omega)$ be a smooth closed symplectic manifold, $J$ a smooth $\omega$-tame almost-complex structure, $2g-2+n>0$, and $\beta\in H_2(X;\mathbb Z)$. For a target Riemannian metric $k$ and a conformal metric on each normalization component, use $E_k(u)=\frac12\sum_D\int_D|du|^2$, summing over the smooth components. Then $\overline{\mathcal M}^\beta_{g,n}(X,J)$ is compact Hausdorff and metrizable in the auxiliary-marked universal-family graph topology. Every sequence admits stable-map convergence of the same integral class, including every sphere and neck component, with exact energy identity and no lost homology (including torsion). The conclusion is uniform for a convergent compact smooth tame family of $J$; the parameterized union over a compact interval is compact. In particular the varying-domain input assumed in the former conditional formulation is proved, with all its original target, metric, genus, markings and class inputs retained.

1.1 Put $g_J(v,w)=\tfrac12(ω(v,Jw)+ω(w,Jv))$. Tameness makes it positive and J-invariant. In an oriented domain orthonormal frame (e,je), holomorphicity gives du(je)=Jdu(e), and hence $E_{g_J}(u)=\int u*\omega =<[\omega ],\beta >=A.$ On compact X this controls any fixed target Dirichlet energy uniformly; over a compact smooth tame family the comparison constants stay uniform. If $A<0$ the moduli is empty; if $A=0$ all component maps are constant. There is then no map unless β=0, because the integral class of a constant connected map is zero. For β=0 this moduli is $X×Mbar_{(g,n)}$, since map stability is then domain stability, and it is compact by the domain construction. Thus assume $A>0$. [F1, F2, F3, F4, F5, given, construct, algebra]

There are at most $N=\operatorname{floor}(A/h)$ such components in any map in the sequence. Let $V_0$ be the number of constant components. For a vertex v of the domain dual graph set $a_v=2g_v−2+s_v$, where $s_v$ counts original marks and incident half-edges. Stability gives $a_v≥1$ on constant vertices, while always $a_v≥−2$ on nonconstant vertices.
