## Definition

Let $\Omega$ be the positional configuration space of [[def-tdmath-poisson-configuration-reference]]. The **marked configuration space** $\Omega^{\rm mark}$ consists of marked point sets $\xi\subseteq\mathbb R^d\times\mathbb R^d$ with spatial projection $q=\{x\in\mathbb R^d:\exists p\in\mathbb R^d,\ (x,p)\in\xi\}$ that is simple and locally finite, and with exactly one mark $p_x$ paired to each $x\in q$. Its sigma-algebra is generated by the marked counts $N_{A\times C}(\xi)=\#\{(x,p)\in\xi:x\in A,\ p\in C\}$ for bounded Borel $A\subseteq\mathbb R^d$ and Borel $C\subseteq\mathbb R^d$. The positional projection is $\pi(\xi)=q\in\Omega$. For a bounded Borel set $\Delta$, the **marked local restriction** is $\xi_\Delta=\{(x,p)\in\xi:x\in\Delta\}$ with the induced count sigma-algebra; write $N_\Delta(\xi)=\#\xi_\Delta$. A **marked-local observable on $\Delta$** is a real measurable function of $\xi_\Delta$; it is bounded when its supremum norm is finite.

Let $d\geq1$, $L>0$, and $\Lambda_L=[0,L)^d$. A finite marked configuration consists of a finite simple set of positions $q\subseteq\Lambda_L$ and a mark map $p:q\to\mathbb R^d$, as in [[def-csm-full-marked-model]]. Its **marked periodic continuation** is
$$\omega^{\mathrm{per}}_{L,q,p}:=\{(x+Lk,p_x):x\in q,\ k\in\mathbb Z^d\}.$$
The spatial positions in this set are distinct: if $x+Lk=y+Lj$ for $x,y\in[0,L)^d$, then coordinatewise $x-y=L(j-k)$ forces $j=k$ and $x=y$. Every bounded spatial region meets finitely many lattice translates of the finite set $q$, so the continuation has a locally finite spatial projection.

For a bounded Borel set $\Delta\subseteq\mathbb R^d$, define its **marked local restriction** by
$$\omega^{\mathrm{per}}_{L,q,p}|_\Delta:=\{(y,p_x)\in\omega^{\mathrm{per}}_{L,q,p}:y\in\Delta\}.$$
This is an element of $\Omega^{\rm mark}$, with the induced sigma-algebra of marked counts above. If $\Delta\subseteq\Lambda_L$, the restriction is exactly the original marked points with positions in $\Delta$.
