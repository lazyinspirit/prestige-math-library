## Statement

For a left $R$-module $M$, consider:

1. Every submodule is finitely generated: $M$ is Noetherian ([[def-noetherian-module]]).
2. Every ascending sequence $N_0\subseteq N_1\subseteq\cdots$ of submodules eventually stabilizes (ACC).
3. Every nonempty set of submodules has a maximal member under inclusion.

The implications $1\Rightarrow2$ and $3\Rightarrow1$ are choice-free.
Assuming Dependent Choice ([[def-dependent-choice]]), $2\Rightarrow3$ also
holds, so all three conditions are equivalent.

## Facts & Assumptions

**Given:** A left $R$-module $M$ and conditions 1–3 above. Dependent Choice is assumed only for $2\Rightarrow3$.

[L1] Finite generation means generation by a finite set; the generated submodule is the smallest submodule containing that set ([[def-noetherian-module]], [[def-generated-cyclic-finitely-generated-and-free-modules]]).

[L2] A nonempty subset is a submodule if it is closed under $ru+v$ for scalars $r$ and its elements $u,v$ ([[lem-submodule-criterion-sums-and-intersections]]).

[L3] Under DC, every entire relation on a nonempty set admits a function from $\mathbb N$ following the relation from a prescribed starting point ([[def-dependent-choice]]).

## Proof

**Proof technique:** direct.

1.1 Assume condition 1 and let $(N_n)$ be ascending. The union $N:=\bigcup_nN_n$ contains zero. Any two of its elements lie in a common stage, so their combination $ru+v$ lies there too. Thus $N$ is a submodule by [L2]. By condition 1, $N$ has a finite generating set $S$. A finite subset of this ascending union lies in one stage: start with stage zero for the empty set, and when adjoining one element take the larger of the previous stage and a stage containing that element. Hence $S\subseteq N_k$ for some $k$, so $N=\langle S\rangle_R\subseteq N_k\subseteq N$. For $n\ge k$, $N_k\subseteq N_n\subseteq N=N_k$. This proves condition 2 without countably many choices. [L1, L2, given]

1.2 Assume condition 2 and DC. Let $\mathcal F$ be a nonempty set of submodules. If it has no maximal member, the relation $A\mathrel{R}B$ defined by $A\subsetneq B$ is entire on $\mathcal F$. Fix $A_0\in\mathcal F$. By [L3] there is a sequence $(A_n)$ in $\mathcal F$ with $A_n\subsetneq A_{n+1}$ for every $n$, contrary to condition 2. Thus $\mathcal F$ has a maximal member, proving condition 3. [L3, given]

1.3 Assume condition 3 and fix a submodule $N\le M$. Its finitely generated submodules form a set $\mathcal G$ containing the zero submodule, generated by the empty set. Condition 3 gives a maximal $L\in\mathcal G$. Fix a finite generating set $S$ of $L$. If $L\ne N$, an element $x\in N\setminus L$ makes $\langle S\cup\{x\}\rangle_R$ a finitely generated submodule of $N$ strictly containing $L$, a contradiction. Hence $L=N$, proving condition 1 without DC. [L1, given]

2.1 Steps 1.1, 1.2 and 1.3 prove the stated implications. Only step 1.2 uses DC. [step 1.1, step 1.2, step 1.3] ∎
