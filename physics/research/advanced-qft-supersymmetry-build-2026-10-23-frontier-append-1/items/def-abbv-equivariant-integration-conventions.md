## Definition

Assume the Axiom of Choice. Let $T=(\mathbb R/\mathbb Z)^r$ have the standard product presentation, smooth structure, and period-one basis $e_1,\ldots,e_r$ of the upstream torus definition. Use its selected product Milnor model $ET=(E_{S^1})^r$ with the right diagonal action and $BT=ET/T$. For a smooth left $T$-manifold $X$, define real Borel equivariant cohomology by $H_T^*(X;\mathbb R)=H^*(ET\times_T X;\mathbb R)$ using the quotient convention $(e\cdot t,x)\sim(e,t\cdot x)$. Its coefficient ring is $\mathcal R=H^*(BT;\mathbb R)\cong\operatorname{Sym}_{\mathbb R}(\mathfrak t^*)=\mathbb R[u_1,\ldots,u_r]$, where $u_i$ is the class corresponding to the dual period-one basis vector $e_i^*$ and each $u_i$ has degree $2$.

For an integer vector $m=(m_1,\ldots,m_r)$, write the character as $\chi_m(t)=\exp(2\pi i\sum_i m_i t_i)$ and define its degree-two class by $u_{\chi_m}=\sum_i m_i u_i$. With the stated quotient convention, this is the Euler class of the Borel line $ET\times_T\mathbb C_{\chi_m}$, where $T$ acts on $\mathbb C_{\chi_m}$ by $\chi_m$. Use the complex-orientation convention $c_1(L)=e(L_{\mathbb R})$ for a complex line $L$; thus $u_\chi$ is also the first Chern class of its Borel character line. Let $S\subset\mathcal R$ be the multiplicative set generated by these classes for all nontrivial characters, together with $1$; thus $u_\chi\ne0$ exactly for nontrivial $\chi$. Write $S^{-1}H_T^*(X;\mathbb R)$ and $S^{-1}\mathcal R$ for the corresponding localizations. The coefficient-ring identification is used under AC: the upstream classifying-space cohomology proof invokes AC in its Künneth and coefficient arguments.

If $X$ is a compact oriented smooth $T$-manifold without boundary of dimension $n$ and the action preserves its orientation, the Borel projection $\pi_X:ET\times_T X\to BT$ has compact oriented $n$-dimensional fibers. Define equivariant integration $\int_X\alpha=(\pi_X)_!\alpha$, the cohomological pushforward along those fibers; it lowers degree by $n$ and has values in $\mathcal R$. For an oriented $T$-equivariant vector bundle $E\to X$ whose Borel-associated bundle has a normalized Thom class, define its equivariant Euler class $e_T(E)$ as the pullback of that Thom class by the zero section. The Thom class is normalized to restrict on each oriented fiber pair $(D^c,S^{c-1})$ to the positive generator of $H^c(D^c,S^{c-1};\mathbb R)$. For rank $c=0$, the Thom class and Euler class are $1$. For a complex representation line of character $\chi$, this convention gives Euler class $u_\chi$. For a fixed component $F$ of a $T$-action on $M$, the orientation convention is $o(TM|_F)=o(TF)\wedge o(\nu_F)$, where $\nu_F$ is its chosen equivariantly oriented normal bundle. This is the Borel convention; no identification with a Cartan, Chow, or quotient-stack cohomology model is assumed here.
