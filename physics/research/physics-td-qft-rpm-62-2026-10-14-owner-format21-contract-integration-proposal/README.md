# Root-only integration of21format repair contracts

This is a separate implementation proposal. It does not rerun the earlier240scientific-proposal integration or hash its497-source context. It consumes exactly the final QFT, TD and RPM formatting release packets plus the final TD two-subject quote-only supplement (three changed quote fields) and21guarded final sources and18existing contract subjects across13shared documents. It does not write source items, manifests, plan, page carriers, native state, or recertification records.

From `physics/`, root alone executes after all three owner releases and relevant writers drain:

```sh
node research/physics-td-qft-rpm-62-2026-10-14-owner-format21-contract-integration-proposal/integrate-format-contracts.mjs --apply --writers-drained
```

Default/`--dry-run` performs metadata validation and no shared writes. `--verify-guards --writers-drained` verifies raw guards only. Neither mode should be repeated unnecessarily. The author does not execute the helper. Root must use the final released index, not a partial preparation index.

The frozen index binds each proposal, its release/evidence, current source raw SHA, archived beforeimage SHA, and initial shared contract document SHA. Every final source is hashed once and memoized. Source input stat identity (device/inode/size/mtime/ctime) must remain exact at commit; any change refuses integration. Exact citation providers outside the21are read once on demand for quote comparison and tracked by stat currency, without blanket hashing or scientific review. The quote-only owner supplement additionally guards exactly its three named providers; one is already among the21and reuses its cached hash, so only two extra provider hashes are needed.

Full YAML frontmatter bytes must match archived beforeimages exactly, preserving physical scope and qualifications. Owner-confirmed public sections are compared with archived beforeimages under the exact declared mode: byte preservation or whitespace-only preservation. Canonical public sections are Statement, Statement refuted, Definition, Example, Remark, Postulate, and Observations. All proposed IDs must be among the21 and routed to their actual current MF-owned contract document. Exactly18subjects must already exist in both their current owning contract and scope; the helper cannot create contracts or scope entries. Only actual formatting fields are accepted. Absent and unrelated current fields, finite smoke, manual worksheets, and historical records are preserved.

Merged citations require legal current public-section quote substrings and nonempty current proof-step uses. Boundaries retain canonical case/status and exact final source bindings. Explicit step references are checked in the current consumer proof; supplier quotes and provider-specific worksheets are excluded from consumer-step interpretation. Successful checks are metadata currency evidence, not mathematical or physical acceptance.

All validation errors are grouped by subject/type with full evidence archived before shared mutation. Apply archives every shared beforeimage, stages all proposed documents, rechecks input currency/shared raw hashes, then atomically renames each file. There is no multi-file filesystem transaction; guarded rollback restores only this helper's unchanged staged outputs if any commit fails, preserving concurrent changes and recording manual-recovery requirements. Root's drained-writer assertion avoids partial visibility.

No native gate control, source rehash, numeric-label mutation, software tests, or independent acceptance action exists in this helper. Only JavaScript syntax checking is performed by the proposal author.
