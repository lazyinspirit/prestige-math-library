## Definition

Fix $d\ge1$. Let $\mathcal B(\mathbb R^d)$ be the $\sigma$-algebra generated by the Euclidean open sets, and understand all measures below as defined on $(\mathbb R^d,\mathcal B(\mathbb R^d))$. A measure here is a countably additive map from $\mathcal B(\mathbb R^d)$ to $[0,\infty]$ that assigns $0$ to the empty set. A locally finite counting measure on $\mathbb R^d$ is a measure of the form $\xi=\sum_{r\in I}\delta_{x_r}$, where $I$ is finite or countable, repetitions among the points $x_r\in\mathbb R^d$ are allowed, and every compact set contains only finitely many listed points, counting repetitions. The empty sum is allowed and is the zero measure. For a Borel set $B$, $\xi(B)$ is the number of listed points in $B$, with multiplicity. Write $\Gamma_{\mathrm{lf}}(\mathbb R^d)$ for the set of these measures. For $x\in\mathbb R^d$, the point mass $\delta_x$ assigns mass $1$ to a Borel set containing $x$ and mass $0$ otherwise.

The vague topology on $\Gamma_{\mathrm{lf}}(\mathbb R^d)$ is the coarsest topology for which $\xi\mapsto\int f\,d\xi$ is continuous for every nonnegative continuous compactly supported function $f:\mathbb R^d\to\mathbb R$. Thus $\xi_n\to_{\mathrm v}\xi$ exactly when $\int f\,d\xi_n\to\int f\,d\xi$ for every such $f$.

Given a probability space $(\Theta,\mathcal A,\mathbb P)$, meaning that $\mathcal A$ is a $\sigma$-algebra on $\Theta$ and $\mathbb P$ is a countably additive probability measure on $\mathcal A$ with $\mathbb P(\Theta)=1$, a random locally finite counting measure is an $(\mathcal A,\mathcal B_{\mathrm v})$-measurable map $\Xi:\Theta\to\Gamma_{\mathrm{lf}}(\mathbb R^d)$, where $\mathcal B_{\mathrm v}:=\sigma\{U:U\text{ is open in the vague topology just defined}\}$. We require that, for every bounded Borel set $B\subseteq\mathbb R^d$, the evaluation $\Xi(B):\Theta\to[0,\infty)$ given by $\Xi(B)(\theta)=\Xi(\theta)(B)$ is $\mathcal A$-measurable; it is finite by local finiteness. Write $\mathbb E_{\mathbb P}$ for integration with respect to $\mathbb P$. A sequence $(\Xi_n)$ of such measures on a common probability space uses this same domain and target for every $n$. If $K$ is compact, its local counts are uniformly integrable on $K$ when

$$\lim_{R\to\infty}\sup_n\mathbb E_{\mathbb P}\!\left[\Xi_n(K)\mathbf1_{\{\Xi_n(K)>R\}}\right]=0.$$

This is the count-tail condition used when an argument needs control of unbounded observables supported in $K$. The definition asserts no convergence of expectations without the exact test-function, support, and tail hypotheses of the result being applied.

## Remarks

This measure-space topology is distinct from finite-spin product topology and cylinder convergence. Vague convergence tests compactly supported spatial functions and can lose mass at infinity; weak convergence of probability measures cannot be inferred from it without an additional tightness condition.
