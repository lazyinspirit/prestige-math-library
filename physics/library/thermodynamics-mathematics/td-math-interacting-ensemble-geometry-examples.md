These leaf examples keep the ensemble qualifications concrete. A one-dimensional hard-rod calculation shows that retaining the forbidden-pair rule at zero inverse temperature does not produce an unrestricted Poisson gas. A uniform field throughout an ideal-gas volume changes the pressure exactly. Close packing can have zero canonical configuration volume, and a nonunique variational minimum permits multiple local accumulation points. The last example is an abstract conditional convex-mixture demonstration; it does not claim that a particular potential has a phase transition.
