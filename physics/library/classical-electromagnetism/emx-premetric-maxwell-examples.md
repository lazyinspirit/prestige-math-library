These are conditional calculations within the stated classical Maxwell model; neither is a reported observation.

[[ex-emx-topological-flux-sector]] constructs a smooth source-free vacuum field on $\mathbb R^3\setminus\{0\}$ with a specified nonzero magnetic flux. The cycle has no global smooth potential, and no smooth divergence-free full-space extension agrees with it on the enclosing sphere. The excluded point is not assigned a magnetic-charge source law.

[[ex-emx-duality-pec-failure]] applies the source-free vacuum quarter-turn to a constant field in a half-space. The rotated electric field is tangential and nonzero on the same ideal PEC boundary, so that boundary condition is not preserved.
