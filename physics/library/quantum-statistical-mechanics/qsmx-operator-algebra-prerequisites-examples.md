The example separates two representations of the same finite matrix algebra.
In its defining representation every nonzero vector is cyclic, while a
nonzero projection kills each vector, so none is separating. In the
Hilbert–Schmidt left representation, a faithful density matrix supplies a
unit cyclic-separating vector through its positive square root. The example
proves both statements directly and identifies the resulting vector
functional with the density-matrix trace functional.
