## Scope

These examples calculate the outer equatorial circular null-orbit radius in
the selected dyonic RN exterior and exhibit a fixed-angular-coordinate
spacelike curve in a selected rotating KN ergoregion. The first uses the
adopted geometric-optics rule to interpret a null geodesic as an ideal light
ray; neither example reports an observation. The rotating example concerns
only the specified stationary Killing field and does not claim an extraction
process or rule out trajectories with angular motion.
