These companions compute the kernel and Green data of the main page. The
normalized flux of the fundamental solution is evaluated on every centered
sphere in dimensions $n\ge2$ and separately for the two-dimensional
logarithmic kernel, and the one-dimensional interval kernel is exhibited with
its slope jump. Exact shell and radial-density formulas show how Newtonian
potentials of symmetric data reduce to one-dimensional integrals, and adding
an entire harmonic function is shown to preserve a fundamental solution.

The counterexamples mark the limits of the page's claims. The Hessian of the
fundamental solution fails absolute local integrability, so the subtraction in
the classical potential theorem cannot be dropped; an isolated boundary point
admits no pointwise-zero Dirichlet Green function, so the naive boundary
regularity cannot be assumed; and the smooth constant data $f\equiv1$,
$g\equiv0$ violate the necessary Neumann compatibility equation, so flux
compatibility cannot be omitted. Each construction inherits Countable Choice
($\mathrm{AC}_\omega$) through the stated Euclidean measure, surface,
divergence and Green interfaces, and none of the items asserts an existence
result beyond what it proves.
