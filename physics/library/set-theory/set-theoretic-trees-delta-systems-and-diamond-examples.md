The binary tree supplies a calculated finite-level instance and an explicit all-zero branch. Decreasing natural-number sequences explain why countable levels cannot replace finite levels in König’s lemma. Two-element sets give an uncountable delta system with a singleton root, while nested countable ordinals show why the finite-set hypothesis matters.

Finite specialization conditions illustrate compatibility directly. The conditional diamond–Suslin example concerns failure of ccc in a square, and the Aronszajn example refutes the assertion that every omega-one tree has a cofinal branch.
