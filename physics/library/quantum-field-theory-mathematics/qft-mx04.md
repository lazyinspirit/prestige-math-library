This page proves the ideal linear Penning mode-frequency invariant as a conditional trace identity for the stated uniform-field, harmonic-quadrupole matrix model. It also supplies a deterministic finite-error estimate for a positive-denominator frequency ratio. The first result uses the matching draft QFT-MX01 mass-energy definition; the definition is not independently accepted in this run. Neither result claims an experimental measurement or a nonlinear, relativistic, or cavity-corrected model.
