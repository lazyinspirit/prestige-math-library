# Constructed level-one connectivity lemma

Let e>=2 be finite. In the balanced signed Jantzen formula use the polynomial-DVR valuation v(h)=nu([h]_X) at X=q; it is positive exactly on e-divisible h. For q=1 in characteristic p=e this includes multiplicities of the polynomial root, and v(h) need not equal1. The proof below uses only v(h)>0 iff e divides h and compares only a divisible and a nondivisible hook, so applies without any mixed-characteristic lift.

Use conjugate beta numbers beta_j=lambda'_j+N-j with N sufficiently large. For row i put g_i=N+i-1-lambda_i; this is a gap in the beta set and h_(i,j)=beta_j-g_i. A balanced term for b<c replaces beta_b,beta_c by beta_b+h_(i,c),g_i. If it survives, the new upper bead exceeds both lost beads and the new lower bead is below both. Its two lost and two gained values determine the pair and g_i uniquely; the row gaps g_i are strictly increasing. Thus no other hook pair contributes the same sorted partition label. Its accumulated coefficient is exactly its nonzero signed hook-valuation difference, not merely a nonzero individual summand.

1. If lambda has no outgoing nonzero Jantzen coefficients, then each row has either all hook lengths divisible by e or none. To prove this, suppose its row-hook set contains divisible s and nondivisible t. When s+t is another row hook, replace t by s+t; it remains nondivisible. This finite climb eventually gives a pair s,t with s+t absent from the row-hook set. The two distinct hook nodes are valid and their corresponding upper shifted bead is g_i+s+t. It is not in the beta set: bead values >g_i are precisely the row's hook values plus g_i. The lower shifted bead is the gap g_i. Hence the balanced symbol survives, and its valuation difference is plus or minus v(s), nonzero. The uniqueness observation above proves its accumulated coefficient nonzero, a contradiction. Call the resulting elementary property binary Carter.

2. Binary Carter partitions have only vertical removable e-hooks, and this property persists during core removal. If a node has hook length e, its row's hooks are all divisible. Its last-column hook is a positive multiple of e no larger than e, hence equals e; strict decrease of hook lengths across a row forces the node to be at the row end. Thus the corresponding strip is vertical, in column j, on e equal-length rows i,...,i+e-1. Removing it reduces those row lengths by1 and column j's height by e. Hooks in unaffected rows change by either0 or e, preserving their binary divisibility property. For an affected row r=i+t, all its hooks in columns m<j were congruent to -t mod e, because the top row i had all hooks divisible and all the affected rows originally had length j. After removal these hooks become congruent to -t-1 mod e, independently of m, so each new row again has the binary Carter property. Induction proves that all e-hooks in a complete core-removal sequence are vertical.

3. The dominance-minimal partition in the fixed-core class gamma at weight w is rho=(gamma_1,...,gamma_l,1^(ew)). It has core gamma, by removing the appended vertical strips. Every same-core partition contains gamma as a diagram, because a core-removal sequence only deletes boxes. Among partitions containing gamma with ew added boxes, appending all added boxes as rows of size1 minimizes every dominance partial sum: in the first l rows containment gives the bound, and after that each additional nonempty row contributes at least1 until the full size is reached. Thus every class member dominates rho.

4. Let mu be binary Carter and mu!=rho. Choose the smallest row index i containing a divisible hook, and let j=mu_i be its last column. Every hook in row i is divisible, in particular h=h_(i,j)=mu'_j-i+1 is a positive multiple of e. The rim h-hook is vertical and consists of the tail of column j. If j=1, then all divisible hooks are in column1 (all later rows have length<=1); by step2 every core-removal strip is in this column, giving mu=rho. Thus j>1. Remove this vertical h-hook to get sigma. Its tail rows stay nonempty since j>1. The h removal is a sequence of vertical e-removals and preserves the core. Let nu be sigma with h boxes appended to row1, and eta be sigma with h rows of size1 appended. All three partitions have mu's core. Moreover nu dominates mu and eta, while eta is strictly below mu: the h nodes formerly in column j have moved to new bottom rows, strictly decreasing a dominance partial sum.

5. Both balanced Jantzen coefficients J_(nu,mu) and J_(nu,eta) are nonzero. Write l=length(mu)=length(sigma). If i>1, sigma_1=mu_1. The row1 hook pair in nu at columns j and mu_1+1 has lengths A=h^mu_(1,j) and h. The first is nondivisible because row1 precedes the first divisible row i; the second is divisible. Its balanced symbol sorts to mu: it replaces the two lost beta values at these columns by the restored column-j bead and the smallest bead freed by removing the appended first-row strip. Its coefficient is therefore nonzero. If i=1, sigma_1=j-1, and the pair at columns j,j+1 in nu has hook lengths h,h-1. Its balanced transfer h-1 sorts to mu, and its coefficient is nonzero since h-1 is nondivisible. For eta, use the row1 hook pair at columns1 and sigma_1+1; its lengths are A'=sigma_1+h+l-1 and h. If i>1, A'-h^mu_(i,1)=A, so A' is nondivisible because h^mu_(i,1) is divisible and A is nondivisible. If i=1, A'=h^mu_(1,1)+h-1, again nondivisible. The balanced transfer h restores the tall first-column bead and removes the appended first-row bead, giving eta. Thus J_(nu,eta) is also nonzero. In each case the surviving target has precisely two lost and two gained beta values, so the uniqueness observation rules out cancellation.

6. Now induct upwards from rho in the finite dominance poset. For mu!=rho, if some outgoing J_(mu,tau) is nonzero, then tau is strictly dominated by mu and has the same core by residue preservation; by induction tau is connected to rho, so mu is too. If no outgoing coefficient exists, step1 makes mu binary Carter, and steps4–5 connect mu to nu and then to eta, with eta strictly dominated by mu. Induction again connects eta to rho. This proves connectivity of every fixed-core class using actual accumulated signed coefficients.
