The worked example applies Holm's rank-specific cutoffs to four ordered p-values and compares the resulting rejection set with the one-step Bonferroni cutoff for the same fixed family. It illustrates only the arithmetic for one observed vector. The theorem's strong FWER guarantee still requires valid p-values under each true null.
