# Deferred reviews of native-created prerequisites

A deferred owner collection preserves original review rows against the historical posts actually reported for its assigned items **and declared created items**. This is historical continuity only. The collection `post` remains the actual current source hashes. Original native reports, authored rows and author identities are never rewritten. Normal creation validation still requires unique new IDs, declared registration and contract, an authored review, actual direct dependency and a load-bearing repaired consumer in the author's scope.

Owner continuation and completed-closure verification derive a local set of created subjects only from already collected native declarations. Each declaration must remain bound to its original native author result/report/pack and exact authored declaration, be draft, and retain valid current registration. These IDs are local continuation subjects; the original frozen frontier is unchanged. Unrelated manifest additions receive no authority. They are classified with that local scope before ordinary outside-maintenance routing.

For example, an actually created lemma may retain a sound proof but have `dependency_level: 5` when its in-run computed level is zero. After the exact metadata correction, deferred collection retains the native authored row at hash 5 and records current hash 0. The old row fails ordinary current-review matching. Continuation queues the helper in a genuine next owner pass, whose regular review at hash 0 is required before completed verification/certification. Authorship remains bound to the original native author; the later review supplies currency, not replacement authorship. All ordinary current context, native worker identity, certification, judgment and gate requirements remain in force.
