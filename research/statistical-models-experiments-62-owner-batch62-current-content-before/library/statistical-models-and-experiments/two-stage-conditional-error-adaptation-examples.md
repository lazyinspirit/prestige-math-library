The worked example uses a finite null model to select one of two stage-2
sample sizes from interim information while retaining the selected-size
conditional p-value law; the rejection probability equals the original
conditional-error budget. A second calculation uses independent normal stage
statistics. Its original equal-weight inverse-normal test has size $\alpha$,
while an interim-selected, unit-norm weight rule with an unchanged critical
value has size $3\alpha/2$. The calculation shows why normalized weights alone
do not replace conditional recalibration.
