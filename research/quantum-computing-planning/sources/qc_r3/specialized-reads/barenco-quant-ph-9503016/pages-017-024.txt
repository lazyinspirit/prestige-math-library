Lemma 7.7: Any simulation of a nonscalar ∧n−1(U) gate (i.e. where U ̸= Ph(δ) · I)

requires at least n −1 basic operations.

Proof:
Consider any n-bit network with arbitrarily many 1-bit gates and fewer than

n −1 ∧1(σx) gates. Call two bits adjacent if there there is a ∧1(σx) gate between

them, and connected if there is a sequence of consecutively adjacent bits between

them. Since there are fewer than n −1 ∧1(σx) gates, it must be possible to partition

the bits into two nonempty sets A and B such that no bit in A is connected to any

bit in B. This implies that the unitary transformation associated with the network is

of the form A ⊗B, where A is 2|A|-dimensional and B is 2|B|-dimensional. Since the

transformation ∧n−1(U) is not of this form, the network cannot compute ∧n−1(U).✷

It is conceivable that a linear size simulation of ∧n−1(U) gates is possible. Al-

though we cannot show this presently, in the remaining subsections, we show that

something “similar” (in a number of different senses) to a linear size simulation of

∧n−1(U) gates is possible.
