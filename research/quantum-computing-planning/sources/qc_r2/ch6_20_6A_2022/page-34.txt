6.6 Quantum Searching

For the hardest instances of NP-hard problems, no better method is known than ex-
haustive search for a solution. For example, suppose that for some efficiently computable
Boolean function

f : {0, 1}n −→{0, 1};
(6.147)

we wish to determine whether there is an x such that f(x) = 1. We could search for
a solution by trying all of the N = 2n possible values of the input x, but that might
require time O(NpolylogN) — assuming we can evaluate f in time O(polylogN). That’s
very slow, yet if f has no structure that we know how to exploit, we might not know
how to do better.
