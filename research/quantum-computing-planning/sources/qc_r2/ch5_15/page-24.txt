A quantum gate, being a unitary transformation, is reversible. In fact,
a classical reversible computer is a special case of a quantum computer.
A classical reversible gate

There are four main issues concerning our model that we would like to
address in this Chapter. The first issue is universality. The most general
unitary transformation that can be performed on n qubits is an element of
U(2n). Our model would seem incomplete if there were transformations
in U(2n) that we were unable to reach. In fact, we will see that there
are many ways to choose a discrete set of universal quantum gates. Using
a universal gate set we can construct circuits that compute a unitary
transformation coming as close as we please to any element in U(2n).
Thanks to universality, there is also a machine independent notion
of quantum complexity.
