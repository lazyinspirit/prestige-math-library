## Statement

Let $\mathcal D$ be the finite-support count functions on a nonempty record universe, with neighbors formed by adding or removing one record occurrence. Let $k\ge1$ and let $\mathcal Y_1,\ldots,\mathcal Y_k$ be measurable output spaces. For each round $i$, let $K_i(D,h,\cdot)$ be a probability kernel on $\mathcal Y_i$ for every database $D\in\mathcal D$ and prior transcript $h\in\mathcal Y_1\times\cdots\times\mathcal Y_{i-1}$. Suppose that for every neighboring pair $D\sim D'$, every prior transcript $h$, and every measurable event $A\subseteq\mathcal Y_i$,
$$
K_i(D,h,A)\le e^{\varepsilon_i}K_i(D',h,A)+\delta_i,
$$
where $\varepsilon_i\ge0$ and $\delta_i\ge0$. If $\sum_{i=1}^k\delta_i\le1$, then the full transcript is $(\sum_{i=1}^k\varepsilon_i,\sum_{i=1}^k\delta_i)$-differentially private on the finite product sigma-algebra.

## Facts & Assumptions

**Given:** The finite sequence of history-dependent probability kernels, common neighboring-database relation, and the conditional event inequalities in the Statement.

[F1] [[def-differential-privacy-and-adjacency|Differential privacy]] is the event inequality for every ordered neighboring pair; its database source has the power-set sigma-algebra, so all event-evaluation functions of the database are measurable.

[F2] [[def-measure-kernel-and-probability-kernel|Probability kernels]] have measurable event evaluations and probability-measure sections.

[F3] [[def-product-sigma-algebra-and-finite-product-sigma-algebras|Finite product sigma-algebra]] is generated by measurable rectangles.

[F4] [[thm-sections-of-product-measurable-functions-are-measurable|Sections]] of product-measurable sets are measurable.

[F5] [[thm-measurability-of-integration-against-a-kernel|Kernel integration measurability]]: integrating a nonnegative product-measurable function against a probability kernel gives a measurable function of the history.

[F6] [[lem-dp-test-function-extension|Bounded-function extension]]: a prefix event inequality extends to every measurable function with values in $[0,1]$ with the same additive error.

[F7] [[def-composition-of-probability-kernels|Kernel composition]] uses iterated integration.

[F8] [[lem-kernel-composition-is-well-defined-and-associative|Composed probability kernels]] remain probability kernels and their event values are the iterated integrals.

[F9] [[thm-exponential-addition-formula|The exponential addition formula]] gives $\exp(x+y)=\exp(x)\exp(y)$ for all real $x,y$.

## Proof

1.1 Put $H_0=\{*\}$ and $H_i=\mathcal Y_1\times\cdots\times\mathcal Y_i$. For fixed $D$ and $i$, define $T_i^D(h,B)=\int_{\mathcal Y_i}\mathbf1_B(h,y)K_i(D,h,dy)$ for measurable $B\subseteq H_i$. By [F4], $B_h$ is measurable; taking sections preserves the whole space, complements, and countable disjoint unions, so $B\mapsto T_i^D(h,B)=K_i(D,h,B_h)$ is a probability measure by [F2]. By [F5], $h\mapsto T_i^D(h,B)$ is measurable, so $T_i^D$ is a probability kernel. Starting with the point mass on $H_0$, compose these kernels using [F7]–[F8] to obtain transcript laws $\mu_i^D$ with $\mu_i^D(B)=\int_{H_{i-1}}K_i(D,h,B_h)\mu_{i-1}^D(dh)$. Every transcript-event evaluation is measurable in the database because its sigma-algebra is the power set by [F1]. No choice is used in these finite compositions. [F1, F2, F3, F4, F5, F7, F8, given, construct]

2.1 Write $E_i=\sum_{j\le i}\varepsilon_j$ and $D_i=\sum_{j\le i}\delta_j$, with $E_0=D_0=0$. We prove by induction that $\mu_i^D(B)\le e^{E_i}\mu_i^{D'}(B)+D_i$ for every measurable $B\subseteq H_i$; it is equality at the one-point prefix $i=0$. Suppose it holds at $i-1$, fix an event $B\subseteq H_i$, and put $p(h)=K_i(D,h,B_h)$ and $q(h)=K_i(D',h,B_h)$. By [F2], [F4], and [F5], these are measurable and lie in $[0,1]$. The round-$i$ event inequality and $p\le1$ imply $p(h)\le\min\{1,e^{\varepsilon_i}q(h)\}+\delta_i$, because $\min\{1,x+\delta_i\}\le\min\{1,x\}+\delta_i$ for $x\ge0$. Let $g(h)=\min\{1,e^{\varepsilon_i}q(h)\}$; it is measurable and $[0,1]$-valued. Integrating first against $\mu_{i-1}^D$, applying [F6] to the induction hypothesis, then using $g\le e^{\varepsilon_i}q$ and [F9] with $E_i=E_{i-1}+\varepsilon_i$, gives $\mu_i^D(B)\le e^{E_{i-1}}e^{\varepsilon_i}\int q\,d\mu_{i-1}^{D'}+D_{i-1}+\delta_i=e^{E_i}\mu_i^{D'}(B)+D_i$. The same argument with $D,D'$ interchanged proves the reverse ordered inequality. At $i=k$, [F1] gives the asserted differential-privacy guarantee. [F1, F2, F4, F5, F6, F7, F9, step 1.1, algebra, induction] ∎
