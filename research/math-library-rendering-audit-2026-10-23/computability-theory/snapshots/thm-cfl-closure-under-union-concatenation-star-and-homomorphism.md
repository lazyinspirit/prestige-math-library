## Statement

If $L_1,L_2$ are context-free languages over an alphabet $\Sigma$, and if
$h:\Sigma\to\Delta^*$ is an alphabet map, then the following languages are
context-free:

1. $L_1\cup L_2$,
2. $L_1L_2$,
3. $L_1^*$,
4. $\widehat h(L_1)=\{\widehat h(w):w\in L_1\}$.

## Facts & Assumptions

**Given:** Context-free languages $L_1$ and $L_2$, together with grammars $G_1=(V_1,\Sigma,P_1,S_1)$ and $G_2=(V_2,\Sigma,P_2,S_2)$ generating them, and an alphabet map $h:\Sigma\to\Delta^*$.

[L1] A language is context-free exactly when it is generated by some context-free grammar, by [[def-language-generated-by-a-cfg]].

[L2] The induced word map $\widehat h$ is obtained by replacing each letter $a$ of a word by the word $h(a)$ and concatenating the results, by [[def-alphabet-homomorphism-and-induced-word-map]].

## Proof

**Proof technique:** direct.

1.1 Rename variables of $G_1$ and $G_2$ apart, and add a fresh start variable $S$. The grammar with productions of $G_1$ and $G_2$ together with $S\to S_1$ and $S\to S_2$ generates exactly $L_1\cup L_2$. Similarly, adding only the bridge rule $S\to S_1S_2$ yields a grammar for the concatenation $L_1L_2$. [given, L1, construct]

1.2 For Kleene star, keep $G_1$ and add a fresh start variable $S$ with productions $S\to\varepsilon$ and $S\to S_1S$. Repeating the second rule any finite number of times and then using $S\to\varepsilon$ generates exactly a concatenation of finitely many words from $L_1$, so the new grammar generates $L_1^*$. [construct, L1]

1.3 For homomorphism, first rename the variables of the chosen grammar for $L_1$ so that they are disjoint from $\Delta$. Then replace every terminal letter $a$ occurring in a production by the word $h(a)$, keeping that renamed variable set unchanged. The result is still a context-free grammar over $\Delta$, and if a derivation in the source grammar yields $w=a_0\cdots a_{n-1}$, then the corresponding derivation in the rewritten grammar yields $h(a_0)\cdots h(a_{n-1})=\widehat h(w)$ by [L2]. [L2, construct]

2.1 Conversely, any terminal derivation in the rewritten grammar follows the same variable-expansion pattern as a terminal derivation in the renamed source grammar, because the only change was to replace each source terminal occurrence by its prescribed image word $h(a)$. Therefore the terminal word produced at the end is exactly the image under $\widehat h$ of a word of $L_1$, so the new grammar generates exactly $\widehat h(L_1)$. [L2, step 1.3]

3.1 Steps 1.1, 1.2, 1.3, and 2.1 construct grammars for all four languages, so [L1] shows that context-free languages are closed under union, concatenation, Kleene star, and homomorphism. [L1, step 1.1, step 1.2, step 1.3, step 2.1] ∎
