## Confirmed defects and supplier-first resolution

1. The published QR algorithm's finite-precision rank branch had an unspecified full-column-rank predicate. It now interprets finite binary input real/imaginary entries and f as their exact dyadic values, and explicitly scans columns with exact rational Gaussian elimination, using the first nonzero pivot and finite row eliminations. The pivot count is the exact rank of the represented matrix. Rank deficiency returns the existing rank-deficient-input status. The same finite instructions over the exact field decide the original exact-mode rank predicate; its full real/complex input capability and exact outputs remain unchanged. The represented selected-block singularity test uses the same exact finite elimination before rounded solves. Finite candidate score comparisons scan finite rounded lists; nonfinite or invalid primitive operations return range-failure. QR factorizations perform bounded finite local elimination sweeps, with zero-target and zero-pair rules. Optional certification uses a preassigned finite operation/refinement budget and returns uncertified on failure, preserving the core status. No numerical threshold is substituted for exact rank and no unrepresented pre-rounding rank claim is made.

2. The native draft ID repair still certified a quotient of candidate R blocks rather than its actual returned T, and left the residual data unspecified. The owner repair now retains the actual finite candidate X, inserts exact identity entries and permutes without extra rounding. In exact rational arithmetic it computes D=A-A(:,J)T, r²=sum|D_ab|² and c²=max|T_ab|². Certification checks the actual dimensions, distinct valid selected indices, T(:,J)=I and c²<=f². A certified output carries the concrete spectral bound ||D||₂<=sqrt(r²), with the root reported symbolically, avoiding overflow during conversion. Failing checks give uncertified while retaining the finite candidate and exact diagnostic data. Range failures return no J,T; all nonsuccess and endpoint certificate statuses are explicit. Step 4 now retains outputs and continues to step 5, so it cannot return before the certificate decision.

The direct ID certificate is independent of RRQR score certification. This preserves both capabilities: an actual reconstructed interpolation can receive its explicit direct residual certificate even if the stronger RRQR factorization certificate is unavailable; singular-value-relative computed claims still require the original rigorous score/unitary-residual certificate. No computed g*sigma_(k+1) bound is asserted from a rounded X. All exact-arithmetic error claims are retained.

3. The original error theorem was conditional on exact success and supplied no termination/well-definedness proof. The smallest missing prerequisite is now the approved same-frontier lemma lem-strong-rrqr-interpolative-decomposition-returns-a-status. It proves finite Gaussian elimination and exact represented rank, finite factorization/solve/score work or an explicit failure, at most S swaps and S+1 score passes, finite endpoint/propagation/construction/certificate work, and the actual direct residual bound by rowwise Cauchy–Schwarz. It is a justified_by supplier for the ID definition (ordinary deps from lemma to algorithms, without a reverse deps cycle). The algorithm retains full exact and represented finite-precision branches rather than dropping one.

The cap proof requires no volume-potential argument, no claim that floating-point swaps increase exact volume, and no assertion that a finite cap guarantees success. The published exact volume and sufficient-cap theorems continue to provide their stronger existing exact conclusions.
