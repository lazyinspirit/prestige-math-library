## Uneditable findings and page verdicts

1. `hecke-markov-traces-and-polynomial-link-invariants-examples`, Body, first paragraph: phrase "mirror-convention Jones value $-t^4+t^3+t$". **false-claim, fatal.** The assigned two-strand example identifies the closure of sigma_1^3 as the right-handed trefoil and computes V=t+t^3-t^4 in the fixed convention. The Jones-specialization definition now fixes that same convention through Birman–Brendle section 4.3 property 6. The mirror value is t^(-1)+t^(-3)-t^(-4), so describing the displayed positive-trefoil value as the mirror convention conflicts with the current mathematical carriers. Replace the phrase with the right-handed trefoil value in the fixed convention. B-page prose is outside reader edit authority.

2. `hecke-markov-traces-and-polynomial-link-invariants-examples`, Body, final sentence: "any normalization whose parameters fail ... distinguishes the two Markov stabilizations". **false-claim, fatal.** Failing one normalization relation forces at least one stabilized value to differ from the original, but does not force the two stabilized values to differ from each other. In the assigned coefficient ring choose u as defined and alpha=-(uz)^(-1). Then u*alpha*z=u^(-1)*alpha*z_-=-1, although u*alpha*z!=1. On 1 in B_1 the original value is 1 and both stabilizations have value -1. The counterexample item now states the correct distinction. Replace the page assertion with failure of invariance under at least one stabilization. B-page prose is outside reader edit authority.
