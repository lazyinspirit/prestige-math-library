# First-cycle Sol5.4 empty-leaf invariant proposal

The actual original Sol5.4 rejection of `alg-certified-spatial-branch-and-bound` is confirmed against its current Definition and `def-spatial-box-bound-certificate`. A report may certify emptiness without an objective lower bound. The procedure marks that leaf empty but selects from all nonclosed leaves by least lower bound. That set can therefore contain a leaf with no comparable value. Calling empty leaves “closed” would conflict with the supplier's separate gap-closure definition, which requires a lower bound and the incumbent threshold.

The smallest repair keeps the states distinct. Certified-empty leaves retain their proof in the coverage ledger, require no lower bound, and are never split/refined. Every evaluated leaf not certified empty needs a finite valid lower bound or the existing inconclusive return. The global minimum ranges over those not certified empty, including gap-closed leaves; splitting/refinement ranges over evaluated leaves neither certified empty nor closed. Child boxes are explicitly pending before evaluation, and the no-incumbent upper bound is explicitly infinity. No bound is invented for an empty box and no oracle, certificate or budget branch is removed.

A concrete permitted trace shows the defect: take D=[0,1], C=(1/2,1], f(x)=x and epsilon=1/8. The root can report lower bound0 and feasible witness x=1 with upper bound1. After splitting, the lower child [0,1/2] reports only its valid emptiness proof; the upper child [1/2,1] reports lower bound1/2 and the same feasible upper bound1. The global gap is still1/2. The original selector contains both nonclosed leaves although the first has no lower bound. The proposed selector chooses only the upper child. This is a local mathematical witness, not an executed test or new library item.

At a fully evaluated checkpoint, either all leaves are certified empty and infeasible returns before any minimum, or the remaining finite nonempty index set has finite valid bounds. If no feasible witness exists, U=infinity, so none of those finite bounds can close a leaf. If U is finite and every remaining leaf is closed, each retained bound is at least U−epsilon: bounds closed against an earlier incumbent remain above this threshold because U only decreases. Thus L≥U−epsilon and the existing gap test would already have returned. Whenever branching is needed, a selectable nonempty-in-the-bookkeeping-sense candidate therefore exists. A pending child is evaluated before selection; exhaustion between children returns the existing complete ledger with its pending state. Singleton refinement, unavailable-field returns, exact midpoint witnesses, call counting and all certificate conditions stay intact.

The direct mixed-integer consumer already handles empty leaves correctly in enumeration fallback, but its main-tree Definition repeats the same ambiguous least-bound selection over nonclosed nodes while empty reports may omit bounds. Its focused companion proposal makes certified-empty terminal nodes explicitly ineligible for branching/minima, selects only evaluated nonempty/nonclosed nodes with finite bounds, and treats a missing nonempty-node bound through the existing unavailable-bound fallback. It preserves the exact fallback allocation, dummy-coordinate case, split order, feasible-incumbent updates and statuses. This is a same-reviewer consumer invariant repair, not an invented native rejection of the mixed algorithm.
