### Local contract 1: coherent coloring on omega_1

Suggested local sublemma name: **countable-ladder walk coloring**; put its
statement and proof inside `lem-small-dowker-coloring-gives-ad-guessing`
before the matrix construction. A separate item is optional, not necessary.

**Contract (AC).** Write S for the nonzero limit ordinals below omega_1.
There exists a map e from pairs (alpha,gamma), alpha<gamma<omega_1, to omega
with both properties:

1. For beta in S and beta<=gamma<delta<omega_1, there is epsilon<beta such
   that e(xi,gamma)=e(xi,delta) whenever epsilon<xi<beta.
2. For beta in S, gamma>=beta and n<omega, the set
   {xi<beta : e(xi,gamma)<=n} is bounded in beta.

Thus e is S-coherent and S is contained in partial(e), exactly as required
by RST Fact 3.2. Any stationary subset of S inherits both properties. The
contract does not assert subadditivity, global finite-to-one behavior, or
closedness; none is needed for the unstarred AD construction used for the
commissioned aleph_1 Dowker example.

**Complete proof.** By AC choose, simultaneously for every beta in S, a
strictly increasing omega-sequence C_beta cofinal in beta. Put C_0 empty
and C_(eta+1)={eta}. For every eta>alpha, C_eta has an element >=alpha,
and C_eta intersect alpha is finite. For the latter assertion at a limit
eta, a sufficiently late term of its increasing cofinal omega-sequence
exceeds alpha, so only finitely many earlier terms can lie below alpha.

For alpha<gamma, start eta_0=gamma and, while eta_i>alpha, let
eta_(i+1)=min(C_(eta_i) minus alpha). This is an ordinal >=alpha and
strictly below eta_i. The procedure reaches alpha after finitely many
steps: otherwise its strictly decreasing ordinal sequence would have a
least member followed by a smaller member. Let W(alpha,gamma) be the
finite sequence of nodes before the terminal alpha. Define

    e(alpha,gamma) = max{|C_eta intersect alpha| : eta in W(alpha,gamma)}.

This is a natural number because the sequence is finite and nonempty.

Fix a limit beta<gamma. Let P=W(beta,gamma) and
j=max{|C_eta intersect beta| : eta in P}=e(beta,gamma). The finite union
of the finite sets C_eta intersect beta, eta in P, is bounded below beta.
Choose epsilon<beta at least as large as all its members and sufficiently
large that |C_beta intersect epsilon|>=j. Such epsilon exists because
C_beta has order type omega and beta is limit.

If epsilon<alpha<beta, every step of the walk from gamma towards beta is
also the corresponding step of the walk from gamma towards alpha: for
each node eta in P, C_eta has no element in [alpha,beta), so its least
element >=alpha equals its least element >=beta. Consequently

    W(alpha,gamma) = P concatenated with W(alpha,beta).

Moreover, for eta in P, C_eta intersect alpha=C_eta intersect beta.
Since beta is the first node of W(alpha,beta),

    e(alpha,beta) >= |C_beta intersect alpha| >= j.

The displayed concatenation therefore gives

    e(alpha,gamma) = max(j,e(alpha,beta)) = e(alpha,beta).

This is the required eventual comparison with the column at beta.
For beta<=gamma<delta, compare each column above beta with that at beta,
taking the larger of the two thresholds; when gamma=beta only one
comparison is needed. This proves property 1.

For property 2, |C_beta intersect xi| tends to infinity as xi tends to
beta. If gamma=beta this is directly a lower bound for e(xi,beta); if
gamma>beta, the preceding eventual comparison supplies the same lower
bound on a tail. For each n choose a threshold beyond which that count
exceeds n. Thus the indicated sublevel set is bounded. This proves both
properties.

**Dependencies and boundary.** Only countable ordinal/cofinality facts,

### Local contract 2: strengthened stick at omega_1

Suggested local sublemma name: **double-stick finite-avoidance lemma**;
include the full argument inside
`lem-small-dowker-stick-gives-ad-guessing` before the ladder recursion.

**Contract (AC).** Assume stick at omega_1: there is a sequence
(s_xi)_(xi<omega_1) of countably infinite subsets of omega_1 such that
every uncountable X subset omega_1 contains some s_xi. There is a fixed
sequence (x_gamma)_(gamma<omega_1) of countably infinite subsets such
that, for every sequence (A_alpha)_(alpha<omega_1) of at most countable
sets with A_alpha intersect A_beta finite whenever alpha!=beta, and
every uncountable X subset omega_1, some gamma satisfies

    x_gamma subset X,
    x_gamma minus union{A_alpha : alpha in F} is infinite
        for every finite F subset omega_1.

This is RST Fact 4.2(2) specialized to lambda=omega. The same x sequence
must work for all A sequences and X; the construction below has exactly
that quantifier order. Conversely this property implies ordinary stick
by taking all A_alpha empty.

**Complete proof.** Define once and for all

    x_gamma = union{s_xi : xi in s_gamma}.

Each x_gamma is infinite (it contains any one of the infinite s_xi)
and countable (a countable union of countable sets, using AC). In
particular this sequence is constructed from s alone, before A and X.

Now fix A and X as in the statement. Construct for each i<omega_1 an
index xi_i, and when possible an index zeta_i, recursively. At stage i,
remove from X all previously selected s_(xi_j), j<i, and all A_(zeta_j)
for j<i for which zeta_j was defined. Only countably many countable sets
are removed, because i is a countable ordinal. The remainder is still
uncountable. By stick it contains s_xi for some xi; choose the least such
index and call it xi_i. If some A_alpha meets s_(xi_i) infinitely, let
zeta_i be the least such alpha; otherwise leave zeta_i undefined.

The xi_i are distinct: later selected s sets are disjoint from earlier
ones and are nonempty. The defined zeta_i are also distinct: a later
s_(xi_i) avoids each earlier chosen A_(zeta_j), and hence cannot meet
that same set infinitely.

The set R={xi_i : i<omega_1} is uncountable, so choose gamma with
s_gamma subset R. Let I={i : xi_i in s_gamma}; injectivity makes I
countably infinite. Then

    x_gamma = union{s_(xi_i) : i in I} subset X.

Suppose, contrary to the desired conclusion, that some finite F makes
x_gamma minus union_(alpha in F) A_alpha finite. Every s_(xi_i), i in I,
is therefore almost contained in that finite union. It is infinite, so
it has infinite intersection with one member of the union. Thus zeta_i
is defined for each i in I. Since A_(zeta_i) meets s_(xi_i) infinitely
and the latter is almost covered by the finite union, A_(zeta_i) meets
some A_alpha, alpha in F, infinitely. Pairwise almost disjointness forces
zeta_i=alpha in F. This injects the infinite I into finite F, a
contradiction. Thus every required remainder is infinite.

This completes the proof; the reverse implication was noted above.
The proof adapts CGW20's double-family idea and Claim 3.2, simplifying
its case split at omega_1. It does not assume CH, any bounding-number
identity, or the partition relation proved elsewhere in that paper.

**Dependencies and consumer fit.** Use
`thm-countable-union-of-countable`,
`thm-omega-one-is-the-least-uncountable-ordinal`,
`thm-transfinite-recursion`, and `def-axiom-of-choice`, with elementary
finite pigeonhole reasoning. Verify the actual published dependency

coincide under these hypotheses. RST Theorem 4.3 subtracts only finitely
