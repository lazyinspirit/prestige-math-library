# Native smoke callbacks: deep networks and Wasserstein examples

The staged self-contained module exports `deepWassersteinMLChecks` with14 distinct `ml101-*` callbacks covering every original failed row in batches45,50,51 (13 items; the bump has separate1D/2D obligations). Each callback computes a bounded independent fixture and returns `{ok, summary}`. No callback claims a general mathematical proof.

`obligation-coverage.json` maps every original object to its exact preserved/revised object and current source excerpt. `root-integration-operations.json` contains13 finite_smoke array-field compare-and-swap operations,13 current source guards, the new module hash, and two unique registry insertions. Source files are unchanged. Every old field is preserved except check/asserts, whose former values are retained as original_check/original_asserts and in archived before files. All unrelated contract fields remain unchanged.

Computations include softplus Gaussian quadrature,500 Gram/remainder updates (including20 zero residuals),243 zero-feature matrix/event fixtures,24 ReLU quotient pairs, explicit depth3 residual unrolling, the one-point interpolation counterexample, forced Dirac transport costs/action, explicit1D and2D bump integrals, Gaussian cost/midpoint quadrature plus finite three-atom permutation comparisons,64 sphere-crossing segments,80 sine-mixture fixtures, and finite-difference/RK4 particle normalization checks. Numerical windows, tolerances and model limitations are explicit in the module and report.

`focused-callback-check.mjs` invokes these14 callbacks on the actual proposed contract objects and actual source excerpts;14 pass and140 invalid selectors/objects are rejected. It is a proposal-only check. No native finite-smoke gate, global self-test or synthetic acceptance has been used. Independent review requested rejection of arbitrary option keys; this is implemented with an own-key whitelist, while declared fixture/check/numeric selectors require exact supported values.

`ROOT-ONLY-apply.py` is syntax-checked but unexecuted. It composes the module import/spread into the current shared registry through unique excerpts, applies exact per-array CAS, guards all sources and assertions, stages files before renaming and rolls back on an apply error. The registry full preimage SHA is historical only because other owner modules may be integrated meanwhile; no full old registry snapshot is installed. Root owns integration, rehash, actual gate runs and native credit.
