For each encoded instance length $n$ and explicitly declared public data $p$, a **quantum query algorithm** is a specified finite circuit protocol on its query and work registers, fixed independently of the hidden instance $z$ at fixed $(n,p)$. The hidden encoding labels the oracle instance; it is not supplied as a readable input register. A register is a finite-dimensional complex inner-product space with its ordered computational basis; an $r$-qubit register uses the lexicographic bit-string basis, with the first wire most significant ([[def-qc-register-and-computational-basis]]). The finite promise-computation model [[def-qc-promise-computation-model]] supplies the public-classical-input, zero-initialized ancillary-register, ordered-output-tuple, and final-predicate conventions. Its classical input and terminal predicate receive only the declared public data, not the hidden encoding. Circuit syntax fixes the ordered wires and finite gate list [[def-qc-circuit-syntax-and-register-order]], and its denotation fixes the chronological gate composition [[def-qc-circuit-denotational-semantics]]. Registers outside the declared public input start in the zero state unless an explicit preparation interface is supplied. Intermediate measurements and classical feed-forward are represented by finite trees of instrument outcomes and branch-specific unitary operations. All initial states, nonoracle gates and instruments, branch-control rules, and terminal output rules are independent of the hidden instance at fixed $(n,p)$; later operations may depend on observed outcomes. For each instantiated oracle, [[def-qa-finite-branch-output-law]] gives the normalized output law of this tree with its public classical input. The output is interpreted according to the decision bit or search relation in [[def-qa-task-and-promise-domain]].

In the ordinary oracle-only model, hidden-instance dependence enters only through the designated oracle calls. Explicit public parameters and arithmetic inputs remain available when the task declares them. Any additional instance-dependent state preparation or data-access operation is a separately declared and charged resource. Oracle-only lower bounds compare instances with the same public data and without such additional input access; the hidden encoding itself supplies none.
