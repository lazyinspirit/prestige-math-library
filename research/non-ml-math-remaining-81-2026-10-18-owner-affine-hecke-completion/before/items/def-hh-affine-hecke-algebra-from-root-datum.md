## Definition

Let $R=(X,\Phi,Y,\Phi^\vee,\Delta)$ be a reduced based root datum: $X,Y$ are finite-rank free lattices in perfect integral duality, $\Phi\subset X$ is the finite root set, $\Phi^\vee\subset Y$ its coroot set, $\Delta$ a base, and $W_0$ the finite Weyl group ([[def-abstract-root-datum-and-its-weyl-group]]). Its finite simple-reflection set is $S_0:=\{s_\alpha:\alpha\in\Delta\}\subset W_0$; the simple reflections in a chosen base generate $W_0$ ([[lem-root-datum-combinatorics]]). Write $Q^\vee=\mathbb Z\Phi^\vee\subseteq Y$ for the coroot lattice.

An **affine Coxeter extension of $R$** in this definition is specified data $(W_{\mathrm{aff}},S_{\mathrm{aff}},\Omega)$ with the following content: $W_{\mathrm{aff}}=Q^\vee\rtimes W_0$ is given a Coxeter system with finite simple set $S_{\mathrm{aff}}$ containing $S_0$, whose Coxeter labels on $S_0$ are $m(s,t)=\operatorname{ord}_{W_0}(st)$, and the subgroup generated by $S_0$ is the displayed finite Weyl subgroup $W_0$; $W_{\mathrm e}=Y\rtimes W_0$ is the extended group; and $W_{\mathrm e}=W_{\mathrm{aff}}\rtimes\Omega$, where $\Omega$ preserves $S_{\mathrm{aff}}$ by conjugation. The compatibility with the chosen base $\Delta$ is part of the supplied data, so $q_s$ below is defined for every $s\in S_0$. Extend the Coxeter length by $\ell(w\omega)=\ell_{\mathrm{aff}}(w)$ for $w\in W_{\mathrm{aff}}$ and $\omega\in\Omega$, so exactly the elements of $\Omega$ have length zero. This affine Coxeter extension is part of the input, so the definition fixes the length-zero group and the lattice convention and does not itself assert a construction theorem for every root datum.

Choose a parameter function $q:S_{\mathrm{aff}}\to\mathbb R_{>0}$ invariant under conjugation by $W_{\mathrm e}$. For $s,t\in S_{\mathrm{aff}}$ with finite Coxeter label $m(s,t)$, impose the alternating braid relation with $m(s,t)$ factors. Define $\mathcal H_{\mathrm{aff}}(R,q)$ to be the quotient of the free associative $\mathbb C$-algebra on $(T_s)_{s\in S_{\mathrm{aff}}}$ by those braid relations and

$$
(T_s-q_s)(T_s+1)=0\qquad(s\in S_{\mathrm{aff}}).
$$

The extended **Iwahori–Matsumoto affine Hecke algebra** is the crossed product $\mathcal H_{\mathrm{IM}}(R,q):=\mathcal H_{\mathrm{aff}}(R,q)\rtimes\Omega$. Its underlying vector space is $\mathcal H_{\mathrm{aff}}(R,q)\otimes_\mathbb C\mathbb C[\Omega]$, with multiplication $(hU_\omega)(h'U_\eta)=h\,\omega(h')U_{\omega\eta}$. Thus it adjoins symbols $U_\omega$ with $U_\omega U_\eta=U_{\omega\eta}$ and $U_\omega T_sU_\omega^{-1}=T_{\omega s\omega^{-1}}$. Parameter invariance makes each conjugation an algebra automorphism. If $v_s=\sqrt{q_s}>0$ and $N_s=q_s^{-1/2}T_s$, then $(N_s-v_s)(N_s+v_s^{-1})=0$, the symmetric normalization in [[def-hh-universal-coxeter-hecke-parameters-and-presentation]].

This definition asserts neither an Iwahori–Matsumoto basis nor an equivalence with a Bernstein presentation. It does not identify an arbitrary reductive $p$-adic group's Iwahori-fixed category with modules over this algebra; that requires a separate group-specific equivalence.
