## Definition

**Inputs.** A smooth hybrid ODE system with a fixed total event-priority order; an initial mode, time $t_0$, and state; a finite horizon $T\ge t_0$; a finite trial-step provider; a finite enclosure provider satisfying [[def-certified-hybrid-event-enclosure]] for every accumulated mode prefix; a physical-time root-box width target $\omega>0$; a separate guard-residual tolerance $\epsilon>0$; and finite nonnegative integer limits $B_{\mathrm{step}},B_{\mathrm{root}},B_{\mathrm{event}}$. Each provider or certificate-validation call returns data or a failure status in finite time. The trial provider returns a finite real interval $J=[a,b]$ with $a$ equal to the current reported time and $a<b\le T$. For each trial interval use $\theta=(t-a)/(b-a)$ and the transformed guard $\widetilde h_{mn}(\theta)=g_{mn}(a+(b-a)\theta,y_{\rm ref}(a+(b-a)\theta))$. The root isolator then starts from the finite dyadic interval $[0,1]$, regardless of the physical-time endpoints. For $Q\subseteq[0,1]$, write $J(Q)=[a+(b-a)\inf Q,a+(b-a)\sup Q]$. $B_{\mathrm{root}}$ is the maximum number of root-isolator boxes processed for one guard on one trial interval, summed over initial isolation, root-box refinement, endpoint checks, and event-order refinement. The enclosure provider supplies justified local and total reference-error bounds, valid dense-guard, exact-guard, and exact-guard-derivative enclosures on every queried subinterval, and a certified positive separation bound $\delta$ between consecutive selected exact event times on the horizon. It may use a rational residual-tube checker as one provider branch; no particular checker is required. A common-root certificate is a finite proof object with a finite sound validation procedure; it is admissible only when validated to certify that the unique exact roots in all named physical-time boxes occur at one common time. A certified exact singleton root is one such certificate. The error ledger $E$ is measured at the aligned mode-segment start, initially $E=0$. The provider accumulates a continuous piecewise-$C^1$ reconstruction $U$ from the last reported reset. The formula in [[def-heun-quadratic-dense-output]] is one possible reconstruction, not an error certificate.

**Procedure.**

1. Initialize the current reported time, mode, and state from the inputs; set the accepted-event count and trial-step count to zero; set $E=0$. If the current time is $T$, return the completed prefix. If the trial-step budget is exhausted before reaching $T$, return `budget-exhausted` with the certified prefix. Check the event budget only after a next enabled event has been certified, so it does not prevent a no-event step from reaching $T$.

2. Increment the trial-step count and request the next interval $J=[a,b]$. If the increment exceeds $B_{\rm step}$, return `budget-exhausted`. If $a$ is not the current reported time or $a<b\le T$ fails, return `inconclusive`. Extend $U$ by the proposed panel. Obtain and validate the provider's data for the whole accumulated prefix, including a $C^1$ reference-mode continuation on an open interval containing $J$, the total bound $\eta_{\rm ref}$, and each active guard's interval evaluators. Continue only on a `certified` response under [[def-certified-hybrid-event-enclosure]]; if the provider returns `inconclusive` or any required bound, inclusion, reset datum, or evaluator is missing, unjustified, or nonfinite, return `inconclusive` with the certified prefix.

3. For each outgoing transition in its fixed order, initialize a processed-box counter $c_{mn}=0$ and apply [[alg-smooth-function-root-isolation]] to $\widetilde h_{mn}$ on $[0,1]$. On each queried local interval $Q$, use the exact-guard range enclosure $E_{mn}(J(Q))$ and the derivative enclosure $(b-a)D_{mn}(J(Q))$; these enclose $\widetilde h_{mn}(Q)$ and $\widetilde h'_{mn}(Q)$. Set the minimum width to $\eta=\omega/(b-a)$ and the box budget to $B_{\rm root}$. Add the returned processed-box count to $c_{mn}$. If any result is `inconclusive` or contains unresolved boxes, return `inconclusive`. The result is usable only when it is `complete`, so all roots in the physical interval $J$ are covered by excluded or certified boxes.

4. Classify each certified local-time root box $Q$ using $D_{mn}(J(Q))$. If $\sigma_{mn}D_{mn}(J(Q))\subseteq(-\infty,-\nu_Q]$ for some $\nu_Q>0$, record that root as strictly opposite-oriented and nontriggering. If $\sigma_{mn}D_{mn}(J(Q))\subseteq[\nu_Q,\infty)$ for some $\nu_Q>0$, it is an enabled candidate. If neither inclusion is proved and $(b-a)\operatorname{width}(Q)=0$, return `inconclusive`; otherwise call the refinement procedure below with requested physical width $w=(b-a)\operatorname{width}(Q)/2$, then repeat this classification on the returned smaller unique-root box. If refinement cannot certify one of the two strict signs within the remaining box budget, return `inconclusive`.

   **Unique-root refinement.** This procedure is called only on a local-time box $Q$ already certified to contain exactly one root and with a positive requested physical width $w$. While $(b-a)\operatorname{width}(Q)>w$, initialize a FIFO worklist with $Q$ and an empty set of certified subboxes. Remove the first local-time interval $I$ from the worklist. If $(b-a)\operatorname{width}(I)=0$, return `inconclusive`; otherwise bisect $I$ at its dyadic midpoint into two closed halves. For each half $K$, call [[alg-smooth-function-root-isolation]] on $K$ with minimum width $\eta_K=\min\{w/(b-a),\operatorname{width}(K)/2\}$ and the remaining per-guard budget; charge every processed box, including singleton calls, to $c_{mn}$. Add every certified root box returned to the set of certified subboxes, and append every unresolved box returned to the worklist; discard root-free boxes. Any certified subbox lies in $Q$, so the unique root of $Q$ is the root it certifies. If the certified set is nonempty, replace $Q$ by the intersection of its boxes; they all contain the same root, so the intersection is nonempty and contains exactly that root. If the new box is still too wide in physical time, repeat with worklist initialized to this smaller $Q$. If the certified set is empty, continue processing the worklist; root-isolation soundness ensures the root remains in its unresolved union. If the worklist empties without a certified subbox, or $c_{mn}=B_{\rm root}$ while more work is required, return `inconclusive`. Closed halves include their shared midpoint, so an endpoint root cannot be dropped; if both halves certify it, their intersection records it once, possibly as a singleton.

5. For each guard, sort its certified local-time root boxes by lower endpoint. Normalize adjacent boxes that share a bisection endpoint $m$ by calling the root isolator on $\{m\}$ for $\widetilde h_{mn}$ with minimum width $\omega/(b-a)$ and the remaining per-guard budget, charging its processed boxes to that guard's counter. If it certifies a root, replace all touching boxes by the singleton root. If it certifies that $m$ is root-free, keep the boxes as distinct roots on opposite sides of $m$. If it is inconclusive, refine the touching boxes using step 4; if their relation remains undecided or $c_{mn}=B_{\rm root}$, return `inconclusive`.

6. If every isolator is complete and every certified root is strictly opposite-oriented, accept the no-event panel. Set the current reported time to $b$ and state to $U(b)$, append the dense panel, and retain the aligned-start ledger $E$. Obtain updated certified local and total error bounds on the enlarged prefix; if the provider does not certify them, return `inconclusive`. A no-event decision is therefore based on complete root isolation and direction classification of the entire trial interval, not on endpoint signs or on the absence of guard roots.

7. If enabled candidates remain, order their local-time root boxes. For boxes that are strictly disjoint, their interval order gives their physical root order. If two boxes meet only at a local-time endpoint $m$, query the root isolator on $\{m\}$ for each guard with minimum width $\omega/(b-a)$ and the remaining budget, charging each call to that guard: two certified singleton roots give a common-root certificate at physical time $a+(b-a)m$ and a priority-selected tie; a singleton root-free result proves that guard's root is strictly to its box's side of $m$ and orders it against a root at $m$ or on the other side. If a singleton result is inconclusive, refine the boxes. For boxes with a nontrivial overlap, use a valid common-root certificate to establish exact simultaneity and apply the fixed priority among those enabled transitions; otherwise refine the overlapping boxes one bisection level at a time by requesting half their physical widths in step 4. If a box has zero physical width and still overlaps another candidate without a certified tie, return `inconclusive`. For same-guard boxes that touch at a bisection endpoint, the singleton check in step 5 either merges one root there or proves that the roots lie strictly on opposite sides. If the order is not certified before a box budget is exhausted, return `inconclusive`. Select the earliest enabled root or the priority-selected transition at a certified tie. Refine its box to physical width at most $\omega$.

8. Let $\widehat\tau=a+(b-a)\sup Q$ be the physical upper endpoint of the selected local-time box $Q$, so the exact root $\tau$ satisfies $\tau\le\widehat\tau$. From the dense-guard enclosure $G^U_{mn}(\{\widehat\tau\})$, take the maximum absolute endpoint as a certified upper bound $\epsilon_{\rm obs}$ for $|g_{mn}(\widehat\tau,U(\widehat\tau))|$. If the enclosure is nonfinite or $\epsilon_{\rm obs}>\epsilon$, return `inconclusive` when $(b-a)\operatorname{width}(Q)=0$; otherwise call unique-root refinement with requested physical width $w=(b-a)\operatorname{width}(Q)/2$ and recompute. If the tolerance still cannot be certified within the remaining budget, return `inconclusive`.

9. If the accepted-event count is already $B_{\rm event}$, return `budget-exhausted` with the certified prefix without applying another reset. Otherwise let $\nu>0$ be the certified signed derivative margin on the selected box and compute $\Delta=(L_g\eta_{\rm ref}+\epsilon_{\rm obs})/\nu$ by [[lem-transverse-hybrid-event-time-error]]. If the certified separation bound is missing or $\Delta\ge\delta/3$, return `inconclusive` without restarting, since the exact reference may have another event before the reported time. Check that $(\widehat\tau,U(\widehat\tau))$ lies in the reset domain and that the reset value lies in the next mode's state domain; a failed check returns `domain-failure`. Otherwise apply the reset. A root at $T$ is processed by this same rule, and the output at $T$ is post-reset. The reference trajectory has already reset by $\widehat\tau$; its outgoing flow over the lag contributes at most $M^+\Delta$. Set the next aligned-segment state-error bound to
$$E\leftarrow L_R\eta_{\rm ref}+(L_RM^-+L_{R,t}+M^+)\Delta,$$
then discard the pre-reset reconstruction, set the current reported time and state to $\widehat\tau$ and the reset value, start a new accumulated reconstruction in the selected mode, append the event certificate, and increment the accepted-event count. Continue from step 1. Any exhausted step, root-box, or event budget returns `budget-exhausted` with the certified prefix.

**Outputs.** A finite list of certified no-event panels and transverse event boxes with selected transitions, reset states, event-time bounds, and an updated state-error ledger; or an explicit `inconclusive`, `domain-failure`, or `budget-exhausted` status with the certified prefix. No no-event conclusion is drawn from endpoint signs alone.
