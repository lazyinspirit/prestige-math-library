## Statement

Assume AC. Let a supervised prediction problem have a measurable instance space $(\mathsf X,\Sigma_X)$, finite label set $\mathcal Y=\{y_1,\ldots,y_K\}$ with distinct labels, the full power-set sigma-algebra on $\mathcal Y$, and $K\ge2$, and joint probability law $P$ on $\mathsf X\times\mathcal Y$; let $X$ and $Y$ be its coordinate random variables and let $\mathcal G=\{X^{-1}(A):A\in\Sigma_X\}$, the sigma-algebra generated by $X$. There is a measurable function $\eta=(\eta_1,\ldots,\eta_K):\mathsf X\to\Delta_K$, where $\Delta_K=\{p\in[0,1]^K:\sum_jp_j=1\}$, such that for every label index $j$ and $A\in\Sigma_X$,
$$P(X\in A,\ Y=y_j)=\mathbb E[\eta_j(X)\mathbf1_{\{X\in A\}}].$$

## Statement references

[[def-supervised-learning-problem]]: supplies measurable instance and label spaces, the joint law, and the coordinate random variables; here the finite label sigma-algebra is explicitly the full power set.

[[def-conditional-expectation-given-a-sigma-algebra]]: a conditional-expectation version is measurable with respect to the conditioning sigma-algebra and has the same integrals on its events.

[[thm-conditional-expectation-exists-by-radon-nikodym]]: under AC, an integrable real random variable has a conditional-expectation version given any sub-sigma-algebra.

[Durrett, Section 4.1](https://sites.math.duke.edu/~rtd/PTE/PTE5_011119.pdf): defines conditional expectation by event integrals and constructs it from Radon–Nikodym derivatives.

## Facts & Assumptions

**Given:** AC; a finite-label supervised prediction problem with joint law $P$ and full power-set label sigma-algebra; the instance coordinate $X$; and the sub-sigma-algebra $\mathcal G=\{X^{-1}(A):A\in\Sigma_X\}$.

[A1] Assume AC, the choice principle used by the published conditional-expectation existence theorem. [[def-axiom-of-choice]]

[F1] Each indicator $\mathbf1_{\{Y=y_j\}}$ is integrable because it is bounded by $1$ on a probability space; under AC, its conditional-expectation version exists and has the defining event integrals. [[def-probability-measure]] [[def-conditional-expectation-given-a-sigma-algebra]] [[thm-conditional-expectation-exists-by-radon-nikodym]]

[F2] Conditional expectation preserves order and constants almost surely. [[thm-basic-algebra-and-order-properties-of-conditional-expectation]]

[F6] A conditional-expectation version is unique almost surely. [[lem-conditional-expectation-is-unique-almost-surely]]

[F3] Integrable functions equal almost surely have identical integrals over every measurable event. [[thm-the-lebesgue-integral-respects-almost-everywhere-equality]]

[F4] Measurability is determined by preimages of measurable sets. [[def-measurable-function-between-measurable-spaces]]

[F5] The family of all inverse images $X^{-1}(A)$ is a sigma-algebra because inverse images preserve complements and countable unions; by definition it is $\sigma(X)$.

[F7] Finite sums, products by indicators, and level sets of measurable real functions are measurable. [[prop-closure-properties-of-measurable-functions-used-by-the-integral]] [[def-measurable-function-between-measurable-spaces]]

## Proof

1.1 For each $j$, choose a version $Z_j$ of $\mathbb E[\mathbf1_{\{Y=y_j\}}\mid\mathcal G]$, which exists by [A1,F1]. Order preservation and preservation of constants give $0\le Z_j\le1$ almost surely by [F2]. Set $N_j=\{Z_j<0\}\cup\{Z_j>1\}\in\mathcal G$ and $Z'_j=Z_j\mathbf1_{N_j^c}$. Then $Z'_j$ is $\mathcal G$-measurable, takes values in $[0,1]$ everywhere, and equals $Z_j$ almost surely. By [F3], it has the same event integrals, so it remains a conditional-expectation version. Linearity shows that $\sum_jZ_j$ is a version of the conditional expectation of $\sum_j\mathbf1_{\{Y=y_j\}}=1$; the constant 1 is another version, so [F6] gives $\sum_jZ_j=1$ almost surely. Hence $\sum_jZ'_j=1$ almost surely. [A1, F1, F2, F3, F6, F7, given]

2.1 For each label $j$ and rational $q\in\mathbb Q\cap[0,1]$, the event $\{Z'_j<q\}\in\mathcal G$ equals $X^{-1}(A_{j,q})$ for some $A_{j,q}\in\Sigma_X$ by [F5]. AC permits choosing these sets for the countable family of label-rational pairs. Define $\tilde\eta_j(x)=\inf(\{q\in\mathbb Q\cap[0,1]:x\in A_{j,q}\}\cup\{1\})$. For $0<t\le1$, $\{x:\tilde\eta_j(x)<t\}=\bigcup_{q<t}A_{j,q}$; for $t\le0$ this sublevel set is empty and for $t>1$ it is all of $\mathsf X$. Thus each $\tilde\eta_j$ is measurable and takes values in $[0,1]$ by [F4,F7]. [A1, F4, F5, F7, step 1.1, choose, construct]

3.1 For every $j$ and $\omega$, the rationals $q$ satisfying $X(\omega)\in A_{j,q}$ are exactly those with $Z'_j(\omega)<q$. Their infimum is $Z'_j(\omega)$ when this value is below $1$; at value $1$ the rational set is empty and the filler $1$ gives the same value. Thus $\tilde\eta_j(X)=Z'_j$ everywhere. The measurable set $D=\{x:\sum_j\tilde\eta_j(x)=1\}$ is well-defined by [F7]. Define $\eta(x)=(\tilde\eta_1(x),\ldots,\tilde\eta_K(x))$ on $D$ and $\eta(x)=(1,0,\ldots,0)$ off $D$. Then $\eta$ is measurable, takes values in $\Delta_K$ everywhere, and $\eta_j(X)=Z'_j$ almost surely because $\sum_jZ'_j=1$ almost surely. [F7, step 1.1, step 2.1, construct]

4.1 For every $A\in\Sigma_X$ and label index $j$, the event $\{X\in A\}$ belongs to $\mathcal G$. The conditional-expectation identity [F1] and almost-sure equality [F3] therefore give $P(X\in A,Y=y_j)=\mathbb E[\mathbf1_{\{X\in A\}}Z_j]=\mathbb E[\mathbf1_{\{X\in A\}}Z'_j]=\mathbb E[\mathbf1_{\{X\in A\}}\eta_j(X)].$ This is the claimed event identity for every class. [F1, F3, step 1.1, step 3.1, given] ∎
