## Definition

For an integer $K\ge2$, let the label set be $\mathcal Y=\{1,\ldots,K\}$ and let $\Delta_K=\{q\in[0,1]^K:\sum_{j=1}^Kq_j=1\}$. A finite-label score loss is a function $S:\Delta_K\times\mathcal Y\to[0,+\infty]$ whose section $q\mapsto S(q,j)$ is Borel measurable for every label $j$. If the true label distribution is $p\in\Delta_K$ and the reported forecast is $q\in\Delta_K$, its expected score loss is $\bar S(p,q)=\sum_{j=1}^Kp_jS(q,j)$, where a term with $p_j=0$ contributes zero even when $S(q,j)=+\infty$. The loss is **proper** if $\bar S(p,p)\le\bar S(p,q)$ for every $p,q\in\Delta_K$, and **strictly proper** if equality implies $q=p$. The logarithmic loss is $S_{\log}(q,j)=-\log q_j$, with $-\log0=+\infty$, where $\log$ is the natural logarithm; the Brier loss is $S_{\mathrm B}(q,j)=\sum_{i=1}^K(q_i-\mathbf1_{\{i=j\}})^2$.
