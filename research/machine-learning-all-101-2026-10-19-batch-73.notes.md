## Mathematical obligations and caveats

- Static regret uses an attained minimum; the definitions state the required attainment hypothesis. Interval regret is defined only for nonempty contiguous intervals and uses the same attainment condition.
- Dynamic regret compares against an explicitly supplied sequence in a normed real vector space. Path length uses that space’s specified norm and Hazan’s additive `1` convention.
- Strong adaptivity is a property relative to a named base algorithm, constants, interval horizon bound, and environment/comparator class. The definition makes no claim that any algorithm satisfies it. Interval validity is distinct from anytime statistical validity.
- Stochastic pseudo-regret is a random variable indexed by the chosen arm; realized reward regret uses sampled rewards. The local lemma states finite arms, integrable rewards, and the exact pre-reward-history conditional-mean identity, and proves equality of expectations plus the action-count decomposition.
- All arguments are choice-free. No hidden concentration, independence, attainment, or adversary-regret theorem is used.
