The first example verifies an exact Bernoulli sample-mean expansion, and the second calculates the covariance for two fixed-weight independent groups. The final example uses a shrinking risk set whose denominator is empty with probability one half, so its root-$n$ error is not tight. These examples distinguish applying a terminal limit theorem from proving the estimator-specific expansion it requires.
