## Example

Consider eight enrolled participants indexed by $i\in\{1,\ldots,8\}$. Each
participant is both the biological unit and the assignment unit; all eight
participants are included, so this example does not posit probability sampling
from a wider population. Exactly four participants are assigned to treatment
($Z_i=1$), uniformly over
$$\mathcal Z=\{z\in\{0,1\}^8:\ \sum_{i=1}^8z_i=4\},$$
which has $\binom84=70$ assignments. The response is recorded at baseline
$t=0$ and four weeks after assignment $t=1$. At each participant-visit
combination one specimen is read in three technical assay replicates
$r\in\{1,2,3\}$.

For each $i,t,a$, let $u_{it}(a)\in\mathbb R$ be a fixed response value under
arm $a\in\{0,1\}$. Let $d_{itr}\in\mathbb R$ be a fixed reading offset for
technical replicate $r$. The stipulated deterministic observation mechanism
is
$$R_{itr}=u_{it}(Z_i)+d_{itr}.$$
The full data object has one row per participant and six response cells
indexed by $(t,r)$; for this example the participant is the analysis unit as
well as the biological and assignment unit. The assignment vector $Z$ is
random under $\pi$, so the response vector $R$ is random under $P_\theta$.
Both $Z$ and the 48 response coordinates are recorded. All $u_{it}(a)$ and
$d_{itr}$ are fixed latent model quantities; in particular,
$u_{it}(1-Z_i)$ is unobserved. The target population is these eight
participants, and the estimand is the finite-schedule mean contrast at the
four-week visit,
$$\psi(u,d)=\frac18\sum_{i=1}^8\bigl(u_{i1}(1)-u_{i1}(0)\bigr).$$
The experiment law averages over the stated assignment distribution. Its
support is the finite set of records generated by the 70 assignments. The
assignment law is stipulated, with no implementation evidence supplied; the
deterministic measurement rule is an unvalidated modeling assumption. No independence
between the 48 readings or generalization beyond the eight participants is
asserted.

## Facts & Assumptions

**Given:** The finite assignment mechanism and the deterministic record rule above.

[F1] [[def-scientific-statistical-model-contract]]: a contract specifies the observation space, distinct unit and index roles, target and estimand, observation mechanism, support and law, conditioning convention, and the epistemic status of adequacy assumptions; it proves no empirical or physical applicability.

[F2] [[def-statistical-experiment]]: an experiment consists of a measurable space, a parameter set, and a family of probability measures on that space.

[F3] [[def-measurable-space]]: a measurable space is a set together with a sigma-algebra.

[F4] [[def-measure]]: countable additivity on pairwise disjoint measurable sets is a defining condition for a measure.

[F5] [[def-probability-measure]]: a probability measure is a measure of total mass one.

[F6] [[def-measurable-function-between-measurable-spaces]]: a map is measurable when the preimage of every measurable target set is measurable in the source.

[F7] [[def-random-element-and-real-random-variable]]: a random element is a measurable map from a probability space into a measurable space.

[F8] [[def-law-or-distribution-of-a-random-element]]: the law of a random element assigns to each measurable target set the probability of its preimage.

[F9] [[lem-law-of-a-random-element-is-a-probability-measure]]: the law of a random element is a probability measure.

[F10] [[def-parametric-statistical-model]]: a parametric statistical model is the parameter map from the parameter set to the experiment's probability measures.

[F11] [[def-estimand-on-a-statistical-model]]: an estimand is a specified target-valued function on the parameter set of a parametric model.

## Verification

1.1 The set $\mathcal Z$ has $\binom84=70$ members. Put $\Omega=\mathcal Z$ and equip it with $\mathcal F=\mathcal P(\Omega)$, which is a sigma-algebra because a full power set is closed under complements and countable unions. Define $\pi(B)=|B|/70$ for $B\in\mathcal F$. Then $\pi(\varnothing)=0$ and $\pi(\Omega)=1$. Any pairwise disjoint sequence of subsets of the finite set $\Omega$ has at most 70 nonempty terms, so cardinality is countably additive; hence $\pi$ is a probability measure by [F4] and [F5]. [given, F4, F5, algebra, construct]

1.2 Let the parameter set be $$\Theta=\{(u,d):u:\{1,\ldots,8\}\times\{0,1\}\times\{0,1\}\to\mathbb R,\quad d:\{1,\ldots,8\}\times\{0,1\}\times\{1,2,3\}\to\mathbb R\},$$ so $\theta=(u,d)$ indexes all stated real outcome and offset arrays. Each participant contributes $2\cdot3=6$ readings, giving 48 response coordinates in eight participant rows. The participant is the biological, assignment, and analysis unit; $t$ and $r$ index repeated visits and technical readings within it, as required by [F1]. The displayed $\psi$ is a function of $\theta$ into $\mathbb R$, so it is the stated estimand by [F11]. [given, F1, F11, algebra]

2.1 Let $$\mathcal X=\mathcal Z\times\mathbb R^{48},\qquad \mathcal A=\mathcal P(\mathcal X),$$ where the 48 reading coordinates are indexed by $(i,t,r)$. The full power set $\mathcal A$ is a sigma-algebra, so $(\mathcal X,\mathcal A)$ is a measurable space by [F3]. The assignment and response extractors $J:\mathcal X\to\mathcal Z$, $J(z,r)=z$, and $Q:\mathcal X\to\mathbb R^{48}$, $Q(z,r)=r$, are measurable to $(\mathcal Z,\mathcal P(\mathcal Z))$ and $(\mathbb R^{48},\mathcal P(\mathbb R^{48}))$: every preimage is a subset of $\mathcal X$ and hence belongs to $\mathcal A$ by [F6]. For $\theta=(u,d)\in\Theta$, the record map $H_\theta:\Omega\to\mathcal X$ sends $z$ to $(z,(u_{it}(z_i)+d_{itr})_{i,t,r})$. Every preimage under this map is a subset of $\Omega$, hence belongs to $\mathcal F$, so $H_\theta$ is measurable and is a random element by [F6] and [F7]. Define $P_\theta(B)=\pi(H_\theta^{-1}(B))$ for $B\in\mathcal A$; [F8] defines this law and [F9] makes it a probability measure. The extractors $J$ and $Q$ are therefore random elements under $P_\theta$ by [F6] and [F7], and their assignment and response values are recorded in the data object. Thus $(\mathcal X,\mathcal A,\Theta,(P_\theta))$ is a statistical experiment by [F2] and a parametric model by [F10]. [given, F2, F3, F6, F7, F8, F9, F10, step 1.1, construct]

3.1 Let $S_\theta=\{H_\theta(z):z\in\mathcal Z\}$. Since $\mathcal A=\mathcal P(\mathcal X)$, $S_\theta\in\mathcal A$; its preimage under $H_\theta$ is $\Omega$, so $P_\theta(S_\theta)=\pi(\Omega)=1$ by [F8] and step 1.1. This is the support field required by [F1]. The experiment averages over $\pi$ by construction; it makes no independence assertion about the readings. [given, F1, F8, step 1.1, construct] ∎

## Remarks

The construction is finite and choice-free. Here $\pi$ is a stipulated finite design law; no physical protocol or implementation is asserted. In an empirical contract, this assignment is design-controlled only if a protocol imposes it and implementation records confirm it. The deterministic measurement rule is empirically assessable with calibration or validation measurements, but none are supplied here, so the construction establishes no physical adequacy.
