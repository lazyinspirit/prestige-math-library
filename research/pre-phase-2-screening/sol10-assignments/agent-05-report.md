## Statement/Definition changes and direct consumers

1. `rem-normal-moore-space-conjecture`: **actual Statement change.** Before: “NMSC is not decided by ZFC.” After: “Relative to the consistency of ZFC with a strongly compact cardinal, NMSC is not decided by ZFC.” I also corrected its title and explanatory wording and added Fremlin's Theorem 8C/Corollary 8G citation. Fleissner's 1982 PNAS abstract constructs a counterexample under CH and says consistency of NMSC requires measurable-cardinal consistency. Fremlin p. 70 states `Con(ZFC + strongly compact) -> Con(ZFC + PMEA)` and `PMEA -> NMSC`. These give relative independence, not an unconditional positive consistency result. Direct item reference consumer: `rem-martins-axiom`, which cites this remark for orientation in its Remarks; its own Statement does not use the independence inference. The root should classify any wider published reference impact.
2. `def-universal-turing-machine`: **actual Definition change.** Before: “Encode a pair of binary words $(x,y)$ by the self-delimiting binary word”. After: “Encode a pair of binary words $(x,y)$ by the binary word”. The formula `1^{|x|}0xy` is unchanged: it parses as a complete input by reading the length of `x` and treating the remainder as `y`, but the set of pair codes is not prefix-free (the code for `(empty, empty)` prefixes that for `(empty, 0)`). Direct item consumers are `fs-universality-decides-halting`, `lem-clocked-machine-construction`, `thm-existence-of-a-universal-turing-machine`, and `thm-universal-simulation-with-logarithmic-overhead`. The last uses self-delimitation only for the separately defined output code `\widehat u`; no direct consumer use of pair-code prefix-freeness was found. The existing U-P row for this definition concerns its configuration prerequisite and remains open.
