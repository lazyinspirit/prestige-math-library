# Fatal-defect review of the 1,017 selected items

Each `agent-NN.jsonl` is an exclusive assignment. Review every listed `items/<id>.md` independently. The frozen candidate selection is a search priority, not a defect verdict. Read `CLAUDE.md` and repository `README.md` fully before editing. Check statement hypotheses, definitions, proof steps, declared and implicit prerequisites, citation accuracy and adequacy, and whether any cited result actually supports the inference. Consult the library and authoritative mathematical sources when needed; logical validity determines the outcome. Never claim to have read a source that was only found by search.

Repair your assigned item locally only when the full corrected mathematics is secure. Do not edit another agent's assigned item, the canonical ledger, pages, or build state. Do not mechanically add citations as a substitute for proof. Where uncertainty remains or a defect is substantial, propose U-P with the precise gap and the available supplier(s) or unresolved need. Report fatal defects beyond missing prerequisites. For any actual or expected change to the original Statement or Definition, report the item's direct and downstream published consumers, and the reason their use could be invalidated. The root reviewer will apply ledger classifications and resolve cross-shard dependencies. A body-only correction need not trigger downstream classification unless it changes the mathematical claim being used.

Write one JSONL receipt per assigned item to `agent-NN-receipts.jsonl` in this directory, in assignment order. Fields: `id`, `disposition` (`clear`, `repaired`, `propose_up`, `already_up`, `already_pending`), `existing_class` (if classified in the canonical index), `review_scope`, `evidence`, `sources_consulted`, `files_changed`, `statement_change` (`none`, `actual`, `expected`), `downstream_ids`, and `unresolved`. Use `already_up` for unresolved U-P/U-C; use `already_pending` for A-P. A conditional proof that reads correctly does not resolve an unavailable published prerequisite. Keep receipts brief but specific enough for independent verification. If work spans turns, append completed receipts promptly and continue from the first missing ID. Write `agent-NN-report.md` with actionable findings and mathematical justification. Do not mark an item reviewed based on metadata or a lexical match alone.

Run the repository's targeted validation/precheck for any changed item and record results. Check git diff for accidental edits and stale publication/certification fields. Preserve existing work and prior U-P classifications. Keep the parent informed of discovered statement changes or urgent defects as soon as they appear.
