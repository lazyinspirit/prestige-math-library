# Actual D0 grid admission

This note concerns only the new finite grid, not the frozen grid/Floer comparison or analytic suppliers. The input is the admitted standard positive Whitehead cable/clasp diagram at parameter t=0, generated by `whitehead-cable-clasp-code.py`. Its zero framing is part of that geometric input. Neither an Alexander polynomial nor a package-computed Floer invariant is used to identify the output.

The frozen count input is `small-grid-certificate.json`, grid number 13:

```text
O = [10, 8, 4, 7, 2, 5, 12, 11, 3, 9, 1, 6, 0]
X = [3, 12, 0, 1, 9, 11, 10, 6, 7, 4, 5, 2, 8]
```

The construction and finite evidence are as follows.

1. `initial-grid-certificate.json` records every orthogonal arrow as an ordered list of integer vertices, its original crossing labels and over/under incidences. The input raw quadruple lists clockwise ports starting on the outgoing overstrand; the library convention lists counterclockwise ports starting on an understrand. Keeping the raw tuple therefore changes the viewing direction: apply the ambient orientation-preserving halfturn R(x,y,z)=(x,-y,-z), which reverses the projected cyclic order and exchanges over/under. It is a rotation, not a mirror identification. The package also chooses a component orientation independently; that choice is accounted for below.

2. Rotate the orthogonal drawing in its plane by 90 degrees and scale its coordinates by 100. Eight crossings have horizontal overstrands. Replace each in its disjoint 20-by-20 square, in coordinates centered at the crossing, by these two polygonal arcs:

```text
old horizontal overstrand, left to right:
(-10,0), (2,0), (2,4), (10,4), (10,0)

old vertical understrand, bottom to top:
(0,-10), (4,-10), (4,2), (0,2), (0,10)
```

Reverse a list if its actual strand runs in the opposite direction. The two arcs have exactly one intersection, (2,2), where the overstrand is vertical. They meet the old strands at the same four boundary ports; no other segment enters this square. Their crossing cyclic order is unchanged. Thus the replacement is an isotopy of this marked crossing disk. All other crossings already have vertical overstrands. Remove collinear subdivisions. Give distinct horizontal segments distinct heights and distinct vertical segments distinct abscissae by lexicographic perturbations of size less than 1/100. Distinct old levels differ by at least two. No nonadjacent incidence changes. Ranking the new heights and abscissae gives the initial 45-grid. Each directed horizontal arc starts at O and ends at X; each directed vertical arc starts at X and ends at O.

3. The actual precrash coordinate execution, saved truthfully in `initial-coordinate-observation.json`, found exactly 20 grid crossings, with the same original labels and all 20 crossing signs as the cable/clasp input. Its directed Gauss word is the negative reverse of the input traversal. The minus sign is exactly the changed viewing direction in step 1; the reversal is the independently chosen component orientation. The unfinished suffix was completed after recovery without repeating that coordinate audit: `finish-admission.py` checked the exact negative-reverse cyclic-word identity, then checked all 3409 saved grid moves for the first time. Every row/column commutation is noninterleaving (or the permitted shared-endpoint switch); every cut is cyclic; every destabilization deletes the three-mark pattern in adjacent rows and columns, merging its two same-type marks. The final arrays equal the frozen 13-grid. See `admission-verification.json` for the actual suffix result. This is an explicit grid-move certificate, not a search outcome alone.

4. All these operations are supported diagram isotopies or the accepted geometric grid moves. Therefore the underlying knot is the positive zero-twisted Whitehead double of the trefoil, with the framing inherited from t=0. The grid writhe is never used as the companion framing. Its directed orientation is the reverse of the source script's selected traversal. This is the exact oriented junction, rather than an unproved claim that two signed Gauss words are identical.

The remaining orientation convention is separate from this completed integer admission certificate: if the standard Whitehead output knot is assigned the direction opposite the script's arbitrary start traversal, the certificate is immediately an oriented admission. If an externally fixed traversal must be retained, an actual orientation-reversal symmetry or an appropriate invariant symmetry must be supplied. The n13 arrays are unchanged, and no count is being silently moved to an O/X-swapped grid.
