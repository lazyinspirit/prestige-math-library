This is a research-only locator migration proposal. The final `ready-report.json` binds the root-adopted 210-source / 992-row snapshot: 204 entry mirrors, 880 existing template bindings, 57 contract documents and zero holds. `prepare-preview.mjs` reads candidate source pairs, exact conserved proof rows, and current per-batch contracts; it writes only into this research directory. It does not calculate digests, run gates, change sources/contracts, or apply a plan. Earlier preliminary directories are historical and are not the final apply input.

The source row map transports each existing routine/derivation argument and historical row ID, including routine classification. Actual new parsed claims and inputs supply the corresponding mirror. Citation source, section and quote remain unchanged; citation `uses` must match the old source and transport to the actual new source uses. Uses are emitted in actual new proof order. Reordering arguments can reorder this list without changing its set. A discrepancy is a hold, not permission to repair a proof.

Boundary reason/evidence and current review-reason locators change only when their actual syntax identifies a local proof/step/Verification/Counterexample/Construction reference, including its list/range, or an `in N.N` / `at N.N` reference. Explicit external Theorem/Lemma/Definition/Proposition/Section/Equation numbers and URLs remain unchanged. Other occurrences are holds with complete authored text, exact offset, and the conserved old/new argument rows. `grouped-ambiguous-holds.json` groups duplicates by item/case/old/new row while retaining each distinct field and text. No generic anchor is appended.

Root may supply exact case/field/offset/text-bound decisions to the preview using `--decisions FILE`.
