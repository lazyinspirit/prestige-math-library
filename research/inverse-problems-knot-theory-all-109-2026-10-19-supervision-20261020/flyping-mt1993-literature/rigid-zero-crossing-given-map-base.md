## Exact primary input read

Actual supplied images read: MT printed pp.116–117 Main Theorem, p.117 graph-extension/base paragraph, and pp.137–138 Section4 induction setup/Proposition4.1. Bibliography p.171 starts at [5]; the supplied final p.170 proof crop does not contain [1]–[4].

The original theorem factors the GIVEN orientation-preserving pair homeomorphism, not merely some map between the links. The inductive category consists of oriented four-valent rigid-vertex graphs with alternating, reduced, prime diagrams. Vertices are flat square disks and graph maps carry them isometrically. A diagram is alternating if replacing every vertex by a single crossing can make an alternating link diagram.

At crossing count zero, MT p.117 defines an extended flype to be an orientation-preserving pair map pairwise isotopic to one preserving the projection sphere. MT explicitly invokes Lemma1 of reference[4] to assert uniqueness of the sphere embedding and the resulting preservation of boundaries of regions. It then adjusts the GIVEN map by pairwise isotopy so that it carries each region disk in the source sphere into a target region disk.

This does not state that every abstract planar graph has a unique embedding, nor that arbitrary local rotation reversals are compatible. Neither such stronger assertion is used here as a supplier.

## Precise unearned base step

Write G_j=lambda(D_j) and let f:(S3,G_1)->(S3,G_2) be the given orientation-preserving rigid pair map. The required conclusion is an ambient isotopy H_t of (S3,G_2), through maps preserving the actual rigid graph structure, such that H_1 f(S2)=S2. The zero-crossing extended-flype definition then applies to the original f.

A graph isomorphism preserving an abstract list of faces does not yet establish this conclusion. A finite disk-system proof would need the following PHYSICAL interface: after pairwise collar normalization, the images under f of the source sphere's face collars match the target face collars on a common regular-neighborhood boundary, with the actual cyclic orders and normal framing. One may then compare the corresponding proper face-disk systems in the graph exterior. The missing embedding-uniqueness lemma must supply, or its local replacement must prove, that interface at the actual prime rigid-graph input. It is not assumed here.

In particular, rigidity at individual vertex squares does not by itself prove that all vertex rotations have the same plane-orientation sign, and arbitrary abstract planar-embedding uniqueness is false. No unconditional finite base proof is claimed in this pass.

## Collapse and expansion: what the given-map interface must retain

MT p.137 first permits a pairwise isotopy so f maps a neighborhood of each graph vertex isometrically; it then substitutes a semicircular overpass/underpass, or a more general alternating tangle, at corresponding vertices to obtain a NEW triple with the SAME ambient map f. This is an equivariant substitution statement.

For a local expansion at v, choose an embedded model tangle T in its actual vertex neighborhood B. At f(v), the compatible expansion is f(T) in f(B). Then f remains literally a map of the expanded pairs, while outside those neighborhoods it is unchanged. This assertion follows directly by substitution and needs no graph-isomorphism-to-map upgrade.

For a factorization f=g_k...g_1, transporting T successively to T_i=g_i(T_{i-1}) retains that same literal given-map identity at every stage. To turn each stage into the requisite expanded diagrammatic flype, one must ALSO check that these transported tangles agree with the selected alternating diagram decorations and the allowed flype supports. This extra compatibility cannot be inferred just from square rigidity.

Concrete reason: a ninety-degree rotation in the projection plane is a square isometry, but for a fixed crossing with the x-pair above the y-pair, its ordinary height-preserving extension exchanges the prescribed over/under pairs. Thus one cannot expand an arbitrary rigid-graph factorization by independently assigning a fixed crossing at every intermediate square. Either decorations are transported equivariantly or the actual allowed local symmetries are shown to preserve the chosen decoration. The supplied MT paragraph uses the former corresponding-substitution mechanism; it does not authorize the latter blanket assertion.

For the A/B induction interface, the smaller graph triple must therefore retain the matched actual ball, its rigid marking, and the original crossing decoration to be restored. For a C two-piece gluing interface, it must retain the common rigid boundary marking on BOTH smaller triples. These are concrete given-map bookkeeping obligations, not a new classification theorem.
