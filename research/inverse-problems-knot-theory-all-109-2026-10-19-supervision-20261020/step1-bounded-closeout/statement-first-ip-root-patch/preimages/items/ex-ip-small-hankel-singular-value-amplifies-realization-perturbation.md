## Example

Assume Countable Choice and use the exact block-Hankel realization procedure
with $q=d=m=p=1$. For any $0<\varepsilon\le1$, the scalar system
$A=0$, $B=\varepsilon$, $C=1$ has Markov data $M_0=\varepsilon$ and
$M_1=0$, and $H_0=[\varepsilon]$ has singular value $\varepsilon$. The exact
algorithm returns $\widehat A=0$. If only $M_1$ is perturbed to
$\widetilde M_1=\sqrt\varepsilon$, the pair $(M_0,\widetilde M_1)$ is itself
generated by the scalar system $\widetilde A=1/\sqrt\varepsilon$,
$\widetilde B=\varepsilon$, $\widetilde C=1$, so the exact algorithm returns
$\widetilde A$. Thus an absolute Markov-data perturbation $\sqrt\varepsilon$
can change the recovered transition value by $1/\sqrt\varepsilon$.

## Facts & Assumptions

**Given:** $0<\varepsilon\le1$, the two scalar Markov-data pairs, the exact block-Hankel procedure with $q=d=m=p=1$, and Countable Choice.

[A1] [[def-countable-choice]]: Countable Choice, written $\mathrm{AC}_\omega$, asserts that every sequence of nonempty sets has a choice function.

[F1] [[def-ip-discrete-linear-input-state-output-experiment]]: $M_k=CA^kB$ for scalar real state-space systems.

[F2] [[def-singular-values-of-an-endomorphism]]: singular values of a finite-dimensional endomorphism are the eigenvalues of $|H_0|=\sqrt{H_0^{\mathsf T}H_0}$.

[F3] [[alg-ip-exact-block-hankel-realization]]: for $q=1$, $H_0=[M_0]$, $H_1=[M_1]$, and the returned transition is $\widehat A=\widehat O^+H_1\widehat R^+$ for the exact rank-one factorization $H_0=\widehat O\widehat R$.

[F4] [[thm-ip-hankel-realization-recovers-controllable-observable-system]]: when $O_1$ and $R_1$ have rank $1$, exact Markov data yield a successful realization similar to the generating scalar system.

## Verification

1.1 For the first system, $M_0=CB=\varepsilon$ and $M_1=CAB=0$ by [F1]. Thus the $q=1$ blocks are $H_0=[\varepsilon]$ and $H_1=[0]$ by [F3], and [F2] gives the singular value of $H_0$ as $\sqrt{\varepsilon^2}=\varepsilon$. Here $O_1=[1]$ and $R_1=[\varepsilon]$ both have rank $1$. By [F4], the exact algorithm succeeds and its scalar transition is similar to $A=0$; scalar similarity leaves that transition equal to $0$. [given, A1, F1, F2, F3, F4, algebra]

1.2 For the perturbed data, the scalar system with $\widetilde A=1/\sqrt\varepsilon$, $\widetilde B=\varepsilon$, and $\widetilde C=1$ has $\widetilde M_0=\varepsilon$ and $\widetilde M_1=\sqrt\varepsilon$ by [F1]; [F3] identifies these as its $q=1$ Hankel blocks. Its $O_1=[1]$ and $R_1=[\varepsilon]$ again have rank $1$, so [F4] implies that the exact algorithm returns a scalar transition similar to $\widetilde A$. A one-dimensional similarity does not change a scalar, hence $\widetilde A$ is returned. [given, A1, F1, F3, F4, algebra]

2.1 Take $\varepsilon_n=1/n^2$ for positive integers $n$. The perturbation size is $\sqrt{\varepsilon_n}=1/n\to0$, while the change in transition value is $1/\sqrt{\varepsilon_n}=n\to\infty$ and the singular value of $H_0$ is $1/n^2\to0$. This is an exact finite example of unbounded sensitivity as the Hankel singular value approaches zero; it makes no claim of noisy rank-selection correctness. [given, step 1.1, step 1.2, algebra] ∎
