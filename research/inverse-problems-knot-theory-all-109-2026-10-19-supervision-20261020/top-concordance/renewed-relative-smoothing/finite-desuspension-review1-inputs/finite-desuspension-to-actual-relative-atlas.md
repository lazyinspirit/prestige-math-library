# Finite desuspension from an actual relative stable atlas

This records the exact consumer assembly; it is conditional on the separately
owned finite completion and CE-approximation operations. It does not turn their
remaining obligations into citations. In particular the relative tangent
O-lift, actual tube, matrix paths in the actual control-base dimension, and
two-ended smooth slab products remain inputs until independently supplied.

Let W be a TOP five-manifold near a compact C, with a specified actual smooth
germ on an open A containing the prescribed end collars and protected product.
Suppose the actual relative stable integration supplies a finite k and an
actual smooth atlas on W_0×R^k, where W_0 is a neighborhood of C, agreeing
with the prescribed product atlas on A∩W_0 times R^k. Here the whole Euclidean
factor is supplied by the actual normal product-tube parametrization, not by
asserting that an arbitrary neighborhood of C×{0} contains full vertical lines.
If only such an arbitrary neighborhood was supplied, first use compactness
of C to put W_0×(−δ,δ)^k inside it and pull back by a smooth coordinatewise
radial diffeomorphism R^k→(−δ,δ)^k that is the identity near zero.
For a prescribed germ near a closed protected set, first retain a smaller
open protected buffer whose closure lies in the supplied smooth germ and
localize all assertions to its compact intersection with the zero set.
Finite compactness then gives the required product box there as well.
The radial map is smooth on that protected product, so compatibility with
the prescribed germ is retained. No uniform product-radius claim on an
arbitrary nonclosed open protected region is needed.

For each actual dimension n≥6 used below, require the following two exact
operations near the compact zero set:

1. Given an actual smooth P^n and a product homeomorphism
   θ:P→B^(n−1)×R with the specified smooth product germ, produce an actual
   collared smooth completion at the positive end. Its extending map
   F:Pbar→B×(−∞,∞] is continuous, locally proper over an output neighborhood
   of the compact zero set, equals θ in the interior, and equals the given
   product on a protected open germ. The start/output buffers are distinct.
   This operation includes the actual finite approximate completion, matrix
   path realization in the actual base, and two-ended slab products.
2. A proper CE map from an actual smooth (n−1)-manifold to a TOP
   (n−1)-manifold can be approximated by an actual homeomorphism near that
   compact zero set, retaining the protected open homeomorphism germ. In
   dimension n−1=5 its boundary restriction must already be an actual
   homeomorphism. This follows here from exact agreement on the prescribed
   end collars, which contain the actual target boundary. No new side
   boundary is introduced by taking an arbitrary compact cutoff.

The accepted completed-product-end CE interface gives the hypothesis of
operation 2 from operation 1: the actual boundary D of Pbar has proper
surjective cell-like map β:D→B. It uses both properness and the actual
boundary collar, rather than the summable estimate alone.

Now take P=W_0×R^k with its supplied actual atlas and write its last factor
as the end coordinate. The literal base is B=W_0×R^(k−1), of dimension
4+k. Apply operation 1 locally over C×{0}, and then operation 2 to β.
If h:D_0→B_0 is the resulting actual homeomorphism, transfer the smooth
atlas of D_0 to B_0 by composing each smooth coordinate chart with h^{-1}.
The transition maps are exactly those on D_0, so this is an actual smooth
atlas, not merely a stable reduction or concordance class. On the protected
open region h agrees with the prescribed product identification, so the
transferred atlas is compatible with that specified smooth germ.

The output B_0 is a neighborhood of C×{0} in W_0×R^(k−1). If k>1,
compactness of C supplies W_1 and δ>0 with
W_1×(−δ,δ)^(k−1)⊂B_0. Pull back by the smooth radial parametrization just
described to obtain an actual atlas on W_1×R^(k−1). Thus the next completion
has an entire product end and the same protected product germ; an arbitrary
open neighborhood is not incorrectly treated as that product.

Repeat for j=k,k−1,…,1. At stage j the actual smooth total dimension is
5+j and the literal control-base dimension is 4+j. Therefore a base-five
matrix theorem suffices only at the final j=1 stage. Either the needed finite
matrix dimensions, or a separately proved exact parameter-control reduction,
must be supplied at every earlier stage. The ordinary CE approximation is
used in dimension 4+j≥5. The final output is an actual smooth atlas on a
neighborhood of C in W, compatible with both specified end germs and the
protected product. No h-cobordism theorem has been applied before its
ambient smooth structure was present.

The induction is finite. It needs no dependent-choice principle. At each
stage the independently chosen height-band data require Countable Choice;
a finite union of those countable selections still requires only Countable
Choice, provided every input operation has that exact scope. A full-AC input
would remain a full-AC restriction on the conclusion and cannot silently
enter the annular branch.

This is a conditional consumer assembly, with its actual atlas transport and
finite-dimensional bookkeeping spelled out. It does not certify the still
unearned absolute CE approximation, relative O-lift, finite completion, or
small relative handle presentation of the final W.
