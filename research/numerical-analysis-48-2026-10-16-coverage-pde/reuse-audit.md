# Reuse audit and final classification

The latest user direction explicitly excludes duplication of methods already in Statistics and Linear Algebra. No statistics method is introduced by this packet. Existing linear algebra, convex analysis, ODE and PDE primitives below must be linked, not reissued under PE-prefixed aliases. Classification means existing-covered for the old primitive, extend-existing for a substantial new numerical theorem consuming it, and genuinely-new for the missing PDE method. These labels are scope dispositions, not proof acceptance.
