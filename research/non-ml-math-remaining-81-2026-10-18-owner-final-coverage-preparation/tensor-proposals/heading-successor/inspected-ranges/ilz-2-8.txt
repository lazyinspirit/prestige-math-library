2. Semisimplicity and non-degeneracy.

converse is true except for one single case (see [7, Rem. 3.8, p.204]). It follows from

we have very precise information concerning the radical of the invariant trace form
(which we henceforth call the Jones form).

3. Representation theory of Qn.
We wish to understand the simple Qn-modules, and ultimately, a “fusion rule”,
which describes their tensor products. This will be approached through the cellular
theory, which applies to the algebra TLn.
3.1. Review of the representation theory of TLn at a root of unity. Let
|q2| = ℓ.
As noted in Remark 2.6 it suﬃces to consider ℓ≥4; further, since
Qn(ℓ) = TLn(q) for n < ℓ−1, we generally assume that n ≥ℓ−1.
Since TLn(q) is cellular, it has cell modules Wt(n), t ∈T (n) (cf. §1.3). These have
basis the set of monic diagrams : t →n, are generically simple, but occasionally have
two composition factors. As mentioned above, Wt(n) has an invariant form ( , )t;
let Lt := Wt/Radt, where Radt is the radical of the form ( , )t. Then the general
theory asserts that the Lt are simple, and represent all the distinct isomorphism
classes of simple TLn(q)-modules.
The following description of the composition factors of Wt = Wt(n) was given in
[7, Thm. 5.3], and in the formulation here in [1, Thm. 6.9].
Theorem 3.1. Let |q2| = ℓ, ﬁx n ≥ℓand let T (n) be as above. Let N′ = {i ∈N |
i ̸≡−1(mod ℓ)}. Deﬁne g : N′ →N′ as follows: for t = aℓ+ b ∈N′, 0 ≤b ≤ℓ−2,

4. Dimensions.
In this section we shall discuss the dimensions of the simple Qn(ℓ)-modules. To
begin with, we give explicit formulae for the dimensions of the cell modules of TLn.
4.1. Cell modules for TLn. Recall that the cell module Wt(n) has a basis con-
sisting of the monic TL-diagrams D : t →n. Since such diagrams exist only when
t ≡n(mod 2), we may write n = t + 2k, k ≥0.
Deﬁnition 4.1. For t, k ≥0, we write w(t, k) := dim Wt(t + 2k). By convention,
W0(0) = 0, so that w(0, 0) = 0.
Proposition 4.2. We have the following recursion for w(t, k). For integers t, k ≥0:
(4.1)
w(t, k + 1) = w(t −1, k + 1) + w(t + 1, k).
Proof. The proof is based on the interpretation of w(t, k) as the number of monic
TL-diagrams from t to t + 2k.
Consider ﬁrst the case t = 0. The assertion is then that w(0, k + 1) = w(1, k).
But all T-diagrams D : 1 →1+2k are monic, as are all diagrams 0 →2ℓ(any ℓ). It
follows that w(1, k) = dim(HomT(1, 1 + 2k)) = dim(HomT(0, 2 + 2k)) = w(0, k + 1).
Thus the assertion is true for t = 0 and all k ≥0. Similarly, if k = 0, the assertion
amounts to w(t, 1) = w(t −1, 1) + w(t + 1, 0). If t > 0, the left side is easily seen
to be equal to t + 1, while w(t −1, 1) = t and w(t + 1, 0) = 1. If t = 0, the left

recurrence is valid for k = 0 and all t.
