## Exact core, arithmetic contract, and bounded certification

The essential core below is an **exact arithmetic procedure on the returned computed Schur arrays**, not a floating-point backward-stability claim for a new implementation. Every swap really solves a small linear system and forms orthogonal/unitary changes of basis. Retain exact scalar/product representations. This is executable in finite exact algebraic arithmetic for rational/dyadic stored arrays: divisions, conjugation and positive square roots suffice; sign comparisons can use exact real-algebraic arithmetic. Algebraic bit complexity and enclosure cost are separate from the scalar-operation counts. Never silently charge arbitrary-precision exact algebraic computation as fixed-precision machine flops.

An implementation using only a bounded outward evaluator must terminate with `arithmetic-inconclusive` whenever a required zero/sign/division/normalization decision is unresolved within its supplied scalar/evaluator budget. This is an explicit alternate failure route, not an oracle for an ordered basis. Exact decisions on arbitrary abstract real inputs are part of the exact-real arithmetic model, not a bit-computability assertion. All loops over indices are explicitly finite. Inputs include a total scalar/evaluator work budget W as well as a swap-attempt budget K; decrement before each requested primitive or outward evaluation, and return `work-budget-exhausted` at zero. This provides finite status even when exact-expression evaluation is expensive.

Do **not** round exact transformed arrays and claim the proof still applies. A separate rounded extension must explicitly ledger its residual/zero writes and recertify diagonal blocks; that extension is not necessary for this supplier. Exact postprocessing of already rounded arrays fits the numerical candidate procedure, whose original unstructured reduction residual remains fully present.

## Proposed algorithm Definition

Inputs: order d>=0, a real or complex Schur form T, or a regular generalized Schur form (S,T), with declared ordered block partition; optional accumulated input factors; CARE half-plane or DARE disk selector; required selected dimension r; nonnegative integer budgets K,W; a positive separation threshold eta; and the exact arithmetic controller or bounded outward evaluator just described. All input factors are exact product representations; rounded dense copies are diagnostics. For QZ accept complex scalar blocks, or real blocks of sizes 1/2 as in `def-generalized-schur-form`; for ordinary Schur accept `def-real-and-complex-schur-forms`. Invalid block patterns/nonregular diagonal pairs return `invalid-form`. Carry any original residuals and backward-error certificates as data. They need not vanish.

1. Validate only the actual declared structure (one O(d^2) scan). Classify each entire block with a **strict outward-certified** selected or complementary predicate. CARE complex scalar: Re(tii)<0 or >0. CARE real2: verify discriminant<0, then use trace<0 or >0; both roots have real part trace/2. DARE scalar homogeneous pair [a:b]: verify nonzero pair; compare |a|^2 and |b|^2, selected for < and complementary for >. The infinite case b=0,a!=0 is complementary. Never divide by b. DARE real2: verify det(Tblock)!=0 and negative discriminant of det(Sblock-lambda Tblock); its conjugate roots have common squared modulus det(Sblock)/det(Tblock), a positive real number; compare this ratio with 1, or cross-multiply using the certified sign of det(Tblock). An exact boundary equality returns `boundary-spectrum`; an interval touching zero or unable to distinguish the boundary returns `separation-inconclusive`. Retain the certified strict comparison margins. No claim that a comparison margin is a Euclidean root-distance is needed; if a literal distance is reported, compute its correctly scaled formula outward. The declared r must equal the sum of selected block sizes, or return `dimension-mismatch`. Do not split a conjugate pair.
2. Attach an immutable selected/complementary label to each block. Locate the leftmost adjacent inversion (complementary block followed by selected block). If there is none, return `ordered` with first r columns of the updated Schur factor or **right** QZ factor. If K attempts were already made, return `swap-budget-exhausted` with current form and factors. Consume one attempt before starting the local construction. Never retry an unresolved swap indefinitely.
3. Let p,q in {1,2} be the two sizes (only1 over C), and let J be their contiguous p+q coordinates. Copy their local block(s). In ordinary Schur notation write TJJ=[[A,C],[0,B]]. In QZ notation write SJJ=[[A,C],[0,B]], TJJ=[[D,F],[0,E]]. Build the explicit coefficient matrix by column stacking:

   ordinary: H=I_q tensor A - B^T tensor I_p, h=-vec(C), unknown vec(R), dimension pq<=4;

   generalized: H=[[I_q tensor A,-B^T tensor I_p],[I_q tensor D,-E^T tensor I_p]], h=-[vec(C);vec(F)], unknown [vec(R);vec(L)], dimension 2pq<=8.

   Ordinary transpose in the Kronecker factors is intentional, including over C.
4. Solve Hx=h and HY=I using finite Gaussian elimination with complete pivoting: at stage j scan the finite remaining rows/columns, pick an entry of largest certified modulus (lexicographic ties), interchange rows and columns, eliminate lower entries, and back-substitute, undoing column permutations. An exact all-zero remaining submatrix returns `swap-singular`; an unresolved pivot/range problem returns `separation-inconclusive` or `range-failure`. Compute an outward upper bound nu>=||Y||F and verify H Y=I and Hx=h exactly, or obtain a usable approximate inverse certificate ||I-YH||2<=theta<1 and then **still solve exactly** for the exact-core x; the latter certificate supplies ||H^-1||2<=||Y||2/(1-theta). Let beta be this inverse-norm upper bound (nu suffices for exact inverse). Require eta*beta<=1. Failure returns `swap-separation-inconclusive` before committing any local changes. This is a check of a lower bound on sigma_min(H), not a claim based only on eigenvalue gap. Store eta,beta, all pivot/solve certificates and statuses. h=0 still requires the same separation certificate. Never replace a tiny denominator by a floor and call the equation solved.
5. Ordinary Schur: form V=[R;I_q]. Generalized: form V=[R;I_q] and Wleft=[L;I_q]. Form an orthonormal completion of V, and separately Wleft for QZ, by the following deterministic finite Gram-Schmidt instructions: process its q columns in order, subtract projections onto all previously retained orthonormal columns, normalize by the positive square root of the sum of squared moduli; then process e1,...,e(p+q), skipping exactly zero residuals and otherwise normalize; stop when p+q columns are retained. Full rank of [R;I] guarantees the first q normalizers are positive; standard-basis completion guarantees enough additional columns. Unresolved zero/normalizer decisions in bounded mode return `arithmetic-inconclusive`. Let V=Z1 Rv and Wleft=Q1 Rw, and let Zloc=[Z1,Z2], Qloc=[Q1,Q2]; ordinary Schur uses Qloc=Zloc from V alone.
6. Apply embedded Zloc* T Zloc (ordinary) or Qloc* S Zloc, Qloc* T Zloc (QZ). Apply to the **whole affected row and column panels**, including upper off-diagonal blocks; outside JxJ there are O(d) affected entries. The trailing p-by-q lower block is exactly zero by the proved identities; exact zeros may be represented as zero using that identity. No positive tolerance or unrecorded nonzero write is permitted. For real QZ, triangularize each new 2x2 diagonal block of T by the same explicit Gram-Schmidt QR of its two independent columns, multiply its corresponding rows in both arrays by the resulting 2x2 orthogonal factor's transpose, and append that left factor to Qloc. These diagonal T blocks are nonsingular because their roots are finite nonreal. Size1, including a zero T entry for an infinite root, needs no QR. The allowed real form does not require equal diagonal entries or LAPACK's stronger canonical normalization; no such extra standardization is claimed. Retain Zloc,Qloc as exact factors; update the input Schur factor by right multiplying Zloc, or input Q,Z by Qloc,Zloc, respectively.
7. Commit the provisional local panels/factors only after all required decisions and finite arithmetic have succeeded; swap the labels and sizes. On any failure retain the previous committed form plus an explicit failed-attempt diagnostic. Return to step2. For exact arithmetic, the block types/labels are preserved by the theorem; do not perform a fresh dense global scan per swap. Optionally output a rounded dense basis with its separately certified representation/evaluation error. Never present it as exactly unitary.

Outputs on every exit: current partial form, exact product factors, statuses, selected dimension and boundary/separation predicates, attempt/accepted-swap/primitive counts, original residual certificates, local inverse-norm certificates, and the affected original-to-final residual relation below. `ordered` is distinct from `Riccati-accepted`. Absence of required residual certification leaves the related certificate `inconclusive` even if exact reordering succeeds.

## Theorem statement to author

For this algorithm, every execution returns after the finite budgets or completes the finite index loops. Every committed exact swap preserves the appropriate Schur form over the original field and exchanges exactly the two diagonal block spectra, with exact orthogonal/unitary transformations; real conjugate pairs are retained. If all strict selector predicates hold, the total selected size is r, every required decision succeeds, the inverse-norm threshold passes, and K is at least the initial inversion count I, the return is `ordered` with the selected invariant/deflating subspace in its first r right-factor columns. I<=b(b-1)/2 for b blocks; each accepted swap decreases I by one. An execution can fail under small nonzero spectral gaps or insufficient certification/work budget; neither a boundary nor a budget exit proves nonexistence of a stabilizing Riccati solution. Disjoint ordinary/homogeneous spectra guarantee exact local linear-system invertibility; they do not guarantee a chosen positive quantitative threshold eta passes.

If the input single-matrix relation is Q0* A Q0=T0+R0 and cumulative reordering factor is V, then Qnew=Q0 V, Tnew=V* T0 V and Qnew* A Qnew-Tnew=V* R0 V, with identical Frobenius norm. If input Q0* A Z0=S0+RA and Q0* B Z0=T0+RB, then Qnew=Q0 U,Znew=Z0 V and new residuals are U* RA V,U* RB V with unchanged Frobenius norms. Thus exact reordering preserves existing unstructured reduction certificates but creates no structured Hamiltonian/symplectic error theorem and no forward spectral certificate for the original data.

The scalar-arithmetic core costs O(d^2+kd) for k attempted swaps, plus exact-algebraic/enclosure/bit costs; k<=min(K,I) until a failing final attempt, more precisely accepted swaps<=I and attempts<=min(K,I+1). On success k=I and work is O(d^3) worst case. Forming/evaluating dense final basis columns from an input product with L0 elementary factors has a separate O(L0*d*r + I*d*r) straightforward action bound when each old factor has bounded support; or form a dense initial factor using its actual supplier cost and update its O(d)-entry affected columns per swap. A blanket dense product per swap would cost O(d^3) per swap and is **not** the declared implementation. A final dense residual multiplication may cost O(d^3); direct action of L0+I bounded-support factors on all d columns is O((L0+I)d^2). Count whichever residual route is actually used; carry a valid original norm bound without recomputing a dense residual when that suffices.

## Complete proof

1. Small systems and spectral separation. Column stacking directly gives the two displayed H matrices: (AX)ij=sum_k Aik Xkj, (XB)ij=sum_k Xik Bkj, which proves the Kronecker formulas entrywise. The ordinary matrix is invertible for disjoint spectra by `thm-sylvester-unique-solvability-spectral-separation` applied to A and -B. For the generalized matrix take regular local pairs (A,D),(B,E) with disjoint homogeneous roots. Among p+q+1 distinct real integers choose zeta with A0=A-zeta D and B0=B-zeta E nonsingular; each determinant polynomial is nonzero of degree <=p or q, so at most p+q choices are excluded. In the kernel, A R=L B and D R=L E imply A0 R=L B0, hence R=A0^-1 L B0 and D A0^-1 L=L E B0^-1. The ordinary spectra of D A0^-1 and E B0^-1 are disjoint: determinant(D-mu(A-zeta D))=det((1+mu zeta)D-mu A) and the analogous identity for B,E show that finite eigenvalues mu are the injective projective transform mu=beta/(alpha-zeta beta) of the original homogeneous roots. The chosen zeta makes every denominator nonzero, including infinite roots [1:0], which map to0. Multiplication by A0^-1 changes this determinant only by a nonzero factor. Apply ordinary Sylvester uniqueness to L to get L=0, then R=0. The square generalized H is injective and hence invertible. Real H is invertible over R whenever its complexification is invertible: its nonzero complex determinant is its same real determinant. This proves exact solvability without invoking an ordered-QZ existence assumption. With exact Y=H^-1, ||H^-1||2<=||Y||F<=beta, so sigma_min(H)>=1/beta>=eta. With approximate inverse theta<1, Neumann gives the recorded beta instead. Near separation may legitimately fail the chosen threshold.

2. Completion. V=[R;I] has independent columns since its last q rows form I; likewise Wleft. Gram-Schmidt therefore never has a zero residual on those first q columns. When the retained span is proper, at least one standard basis vector lies outside it, so processing all e_j completes it. The finite resulting matrices are unitary/orthogonal; V=Z1 Rv and Wleft=Q1 Rw with invertible upper triangular Rv,Rw and positive diagonal. All operations preserve R versus C. These are local dimensions<=4, so this is constant scalar work per swap, apart from exact-arithmetic decision/evaluation overhead. It cannot be replaced by a rounded orthonormality assertion.

3. Ordinary exchange. The solved equation A R-R B=-C gives [[A,C],[0,B]] [R;I]=[R;I]B. Thus Tloc Z1=Z1 (Rv B Rv^-1). Taking Z2* annihilates the lower-left block. The new leading q block is similar to B. For the complementary p block, one can see similarity to A explicitly: the quotient map pi(x,y)=x-Ry has kernel ran V and satisfies pi Tloc=A pi by A R=R B-C. The columns Z2 give an isomorphism to the quotient, so its representing trailing block is similar to A. Hence old spectra and multiplicities are exchanged. Each size2 real block keeps its negative discriminant (similar matrices have the same characteristic polynomial); size1 remains scalar. Applying embedded factors to whole panels keeps every other below-block entry zero because a contiguous block pair only mixes coordinates in its own two adjacent blocks. This establishes preservation of the global Schur pattern.

4. Generalized exchange. The coupled equations give Slocal V=Wleft B and Tlocal V=Wleft E. Therefore Slocal Z1=Q1 Rw B Rv^-1, Tlocal Z1=Q1 Rw E Rv^-1, and both lower-left blocks vanish. The leading pair is strictly equivalent to (B,E), so its determinant polynomial is a nonzero constant times det(beta B-alpha E). The full local determinant is unchanged up to a nonzero constant by the invertible orthogonal/unitary transformations. Block determinant factorization and cancellation of the nonzero leading polynomial show that the trailing p-block determinant is a nonzero constant times det(beta A-alpha D). Thus its roots with multiplicities, including infinity, are exactly the original first block's roots; regularity is retained. A real2 block has the original finite nonreal conjugate pair, so its second matrix is nonsingular (the beta=0 coefficient det(Tblock) is nonzero). Local QR therefore makes that second block triangular by a real left change; it changes neither roots nor lower-left zeros. A complex scalar block is already triangular; an infinite scalar [a:0] stays regular without an inverse of0. Embedding these transformations and updating every affected whole panel preserves global block structure. In particular, the right basis Z gives the deflating subspace, not the left Q basis.

5. Selection and stopping. Real ordinary2 roots have common real part trace/2 from the negative-discriminant quadratic formula. A real generalized2 finite conjugate pair has product det(Sblock)/det(Tblock)=|lambda|^2 by the constant/leading coefficients of its quadratic determinant; scalar homogeneous selection is exactly |alpha|<|beta|. Thus the whole-block initial labels are correct for the input computed form. Steps3-4 preserve the spectra and labels exactly. Exchanging a neighboring complementary-selected inversion decreases the number of complementary-before-selected pairs by exactly1 and does not change any other pair's relative order. Therefore after exactly I accepted swaps there is no inversion and all selected blocks precede all complementary blocks. Every block's selected dimensions add to r. The first r columns of the accumulated ordinary factor are invariant for the represented matrix; the first r right QZ columns and left columns form its deflating pair. The exact core terminates through these finite steps; the enforced K and W budgets also force every bounded-certification execution to terminate with its named status. A final failure commits no partially updated pair. An initially ordered form with K=0 may succeed after validation and classification; an unordered one cannot. Boundary or certificate failures imply no nonexistence conclusion.

6. Residual and work. Associativity yields V* Q0* A Q0 V=V* T0 V+V* R0 V, or U* Q0* A Z0 V=U* S0 V+U* RA V and the same identity for B. Unitary invariance of the Frobenius norm gives the stated residual bounds. If only the computed form is ordered, its first columns certify the exact stable space of that represented nearby matrix/pencil, not automatically the original CARE/DARE stable graph. Each swap solves systems of dimension<=8, completes matrices of order<=4, and applies constant-width panels to O(d) entries; these are O(d) scalar operations. Initial structural validation is O(d^2), and labels may be maintained in O(b) scans per swap, within O(kd). Exact-algebraic/comparison/interval and final residual/basis costs were explicitly excluded and separately specified. With I=O(d^2) the swapping core is O(d^3). Original Francis/QZ reduction remains O(d^3+s d^2), so adding this reordering and the O(d^3) graph solve gives the same worst-case core order only when all these explicitly stated scalar-model and output-evaluation conventions hold. No unconditional finite-sweep convergence or automatic equation-level acceptance follows. QED.
