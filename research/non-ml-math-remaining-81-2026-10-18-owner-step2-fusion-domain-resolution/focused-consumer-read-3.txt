FILE items/def-qc-tqc-braid-action-from-fusion-data.md
Definition

Let $x$ be a simple charge in a unitary braided fusion category, let $n\ge2$,
and fix a total charge $c$ with nonzero multiplicity space
$V(x^n\to c)$. Use the left-associated fusion-tree basis. For the Artin
generator $\sigma_i$ that exchanges the $i$th and $(i+1)$st strands, let
$T_i$ be the specified sequence of $F$-moves that changes from the fixed tree
basis to a basis where those two charges fuse first, and let $R_i$ apply the
corresponding $R$-symbol on each pair-charge channel. Define
$$\rho_c(\sigma_i):=T_i^{-1}R_iT_i.$$
This defines the generator assignment. The next theorem proves that the
assignment descends from words to a well-defined group homomorphism. Word
products use matrix multiplication acting right-to-left on column vectors.
The abstract group in this definition is the Artin group
[[def-braid-group-by-the-artin-presentation]]; the positive crossing is the
generator convention used for the displayed $R$-symbols. If a motion is
described chronologically, its matrix product is written in reverse temporal
order.




FILE items/def-qc-tqc-f-symbol.md
Definition

Let $a,b,c,d$ be simple charges in a unitary fusion category, and put
$P_L=((a\otimes b)\otimes c)$ and $P_R=a\otimes(b\otimes c)$. The local
fusion-tree basis result [[lem-qc-tqc-fusion-tree-dimension]] identifies

$$\mathcal H_L:=\bigoplus_e V_{ab}^e\otimes V_{ec}^d \quad\text{with}\quad\operatorname{Hom}(P_L,d),$$

and

$$\mathcal H_R:=\bigoplus_f V_{bc}^f\otimes V_{af}^d \quad\text{with}\quad\operatorname{Hom}(P_R,d),$$

by the corresponding tree compositions. These direct sums carry the
orthonormal left- and right-tree bases. If $\mu:a\otimes b\to e$ and
$\nu:e\otimes c\to d$ are vertex basis maps, write
$L_{e,\mu,\nu}:=\nu\circ(\mu\otimes\operatorname{id}_c):P_L\to d$. If
$\rho:b\otimes c\to f$ and $\sigma:a\otimes f\to d$ are vertex basis maps,
write $R_{f,\rho,\sigma}:=\sigma\circ(\operatorname{id}_a\otimes\rho):P_R\to d$.
Let $\alpha_{a,b,c}:P_L\to P_R$ be the associator. Define the **F-symbol
matrix** $F_d^{abc}$ by

$$L_{e,\mu,\nu}\circ\alpha_{a,b,c}^{-1} =\sum_{f,\rho,\sigma}F_d^{abc}[(f,\rho,\sigma),(e,\mu,\nu)]R_{f,\rho,\sigma}.$$

Rows index target-tree labels and multiplicity indices; columns index
source-tree labels and multiplicity indices. The sums retain every fusion
channel and every multiplicity coordinate.
If the fixed-total fusion space is zero-dimensional, the F-symbol is the unique
empty $0\times0$ matrix.



FILE items/def-qc-tqc-fixed-charge-encoding.md
Definition

Let $V=V(x^n\to c)\ne0$ be the finite-dimensional fixed-total-charge fusion
space for $n$ identical charges $x$, equipped with the unitary fusion-tree
inner product from [[def-qc-tqc-fusion-tree-basis]]. Let
$\mathcal C=\mathbb C^k$ with its ordered orthonormal computational basis,
where $k\ge1$. A **fixed-charge encoding** is an isometry
$J:\mathcal C\to V$, so $J^*J=I_{\mathcal C}$. Its code subspace is
$J\mathcal C$, and its code projector is
$$P:=JJ^*:V\to V.$$
An encoding records a chosen subspace of a fusion space; it does not identify
that subspace with an object of the fusion category.



FILE items/def-qc-tqc-fusion-tree-basis.md
Definition

Let $\mathcal C$ be a unitary fusion category and fix a set
$\operatorname{Irr}(\mathcal C)$ of representatives for the simple
isomorphism classes. Throughout this definition, the ordered input charges
$a_1,\ldots,a_n$, total charge $d$, and all internal edge charges are labels
in $\operatorname{Irr}(\mathcal C)$. Also fix a parenthesized binary fusion
tree. At each internal vertex with incoming charges $x,y$ and outgoing charge
$z$, choose one vector from an orthonormal basis of $V_{xy}^z$. An
**admissible labeling** assigns a representative charge to each internal edge
so that each chosen vertex basis is nonempty; a separate multiplicity-basis
index is retained at every vertex. Compose the vertex morphisms, inserting the
associators required by the chosen tree, to obtain a morphism from the
parenthesized input tensor to $d$. These composite morphisms are the
**fusion-tree vectors**. The family is called a **fusion-tree basis** when it
is an orthonormal basis of the fixed-input, fixed-total fusion space. For the
empty input list the tensor is $\mathbf1$ and its empty tree vector is
$\operatorname{id}_{\mathbf1}$ when $d=\mathbf1$; for one input $a_1$, the
only tree vector is $\operatorname{id}_{a_1}$ when $d=a_1$. The next local
lemma proves the basis property for every finite input list and includes the
dimension recursion ([[lem-qc-tqc-fusion-tree-dimension]]).



FILE items/def-qc-tqc-ising-majorana-interface.md
Definition

Let $m\ge2$ and let $\mathcal H=(\mathbb C^2)^{\otimes m}$. A **Majorana
system of length $2m$** is a family of operators
$\gamma_1,\ldots,\gamma_{2m}\in\operatorname{End}(\mathcal H)$ satisfying
$$\gamma_j^*=\gamma_j,\qquad \gamma_j^2=I,\qquad \gamma_j\gamma_k=-\gamma_k\gamma_j\quad(j\ne k).$$
Its parity operator is $\Pi=i^m\gamma_1\cdots\gamma_{2m}$. For each adjacent
pair, put
$$Q_1(j)=\frac{I-i\gamma_j\gamma_{j+1}}2,\qquad Q_\psi(j)=\frac{I+i\gamma_j\gamma_{j+1}}2,\qquad U_j=\exp\!\left(-\frac\pi4\gamma_j\gamma_{j+1}\right).$$

A **Majorana–Ising exchange interface** on a fixed parity sector consists of
such a system, a choice $\eta\in\{1,-1\}$ and the sector
$\mathcal H_\eta=\ker(\Pi-\eta I)$, together with the following explicit
model-identification hypotheses for every $1\le j<2m$: the Ising pair-charge
projections are identified with $Q_1(j),Q_\psi(j)$, and the exchange is
$R_1Q_1(j)+R_\psi Q_\psi(j)$ with the same relative phase
$R_\psi/R_1=i$. The last identity is required for all adjacent pairs as part
of the interface; the three-anyon supplier below establishes it only in its
stated sector and does not prove this all-$m$ identification.



FILE items/def-qc-tqc-logical-error-and-leakage.md
Definition

Let $J:\mathcal C\to V$ be a fixed-charge encoding, $P=JJ^*$ its code
projector, $U\in U(\mathcal C)$ a logical target, and $W\in U(V)$ an ambient
unitary. Its zero-on-the-complement target extension is
$\widetilde U:=JUJ^*:V\to V$. Define the **logical block error** and
**leakage amplitude** by
$$\epsilon_{\mathrm{log}}(W,U):=\|PWP-\widetilde U\|_{\mathrm{op}}, \qquad \epsilon_{\mathrm{leak}}(W):=\|(I-P)WP\|_{\mathrm{op}}.$$
Both are finite operator norms. The first measures the compressed block
against the target; the second measures transfer from the code into its
orthogonal complement. They diagnose different errors.



[F1] $P$ is the orthogonal projection onto $J\mathcal C$.

FILE items/def-qc-tqc-projective-gate-and-metric.md
Definition

Let $V\ne0$ be a finite-dimensional complex inner-product space and let
$U(V)$ be its unitary group. Two unitaries are **projectively equivalent**
when $A=zB$ for some $z\in\mathbb C$ with $|z|=1$; write $[A]\in PU(V)$ for
the equivalence class. Define
$$d_P([A],[B]):=\min_{|z|=1}\|A-zB\|_{\mathrm{op}}.$$
This is the distance after quotienting by one common scalar phase. The phase
is minimized over the unit circle; it is not chosen independently in
different charge blocks.



FILE items/def-qc-tqc-six-anyon-encoded-subspace.md
Definition

Assume the Fibonacci fusion rules
$1\otimes x=x\otimes1=x$ and $\tau\otimes\tau=1\oplus\tau$, with each
listed summand of multiplicity one. For six ordered $\tau$ charges, let
$W_a$ be the fixed-input, fixed-total fusion space of total charge
$a\in\{1,\tau\}$ in the tree that first fuses leaves $1,2,3$ and $4,5,6$
separately, then fuses those triple outputs. Let
$V_a$ be the same fixed-charge space in the left-associated tree.

To identify these spaces, write
$A=((\tau_1\otimes\tau_2)\otimes\tau_3)$. Use the object associator
composite
$$g=(\alpha^{-1}_{A\otimes\tau_4,\tau_5,\tau_6}) \circ\alpha^{-1}_{A,\tau_4,\tau_5\otimes\tau_6} \circ(\operatorname{id}_A\otimes\alpha_{\tau_4,\tau_5,\tau_6})$$
from the triple-grouped input tree to the left-associated tree. On a fusion
morphism $f$ into $a$, define $G_a(f)=f\circ g^{-1}:V_a$; this is a unitary
change of fusion-tree coordinates.

For one triple of total charge $\tau$, its two orthonormal path vectors are
indexed by the charge $x\in\{1,\tau\}$ after the first two anyons: both
$x\otimes\tau\to\tau$ channels have multiplicity one. Write these vectors as
$|x\rangle$. For $x,y\in\{1,\tau\}$ and $a\in\{1,\tau\}$, let $|x,y;a\rangle$
be the grouped-tree vector with first triple path $x$, first triple total
$\tau$, second triple path $y$, second triple total $\tau$, and final vertex
channel $\tau\otimes\tau\to a$. The last channel has multiplicity one. Define
$$\mathcal C_a:=G_a\bigl(\operatorname{span}\{|x,y;a\rangle: x,y\in\{1,\tau\}\}\bigr)\subseteq V_a.$$
In the ordered basis
$(G_a|1,1;a\rangle,G_a|1,\tau;a\rangle,
G_a|\tau,1;a\rangle,G_a|\tau,\tau;a\rangle)$, the inclusion
$J_a:\mathbb C^4\to V_a$ is an isometry; its code projector is $P_a=J_aJ_a^*$.
The same ordered local triple paths are used for $a=1$ and $a=\tau$; only
the final pair-charge coordinate differs. The orthogonal complements are
called leakage spaces.



[A1] Assume the Fibonacci fusion rules stated in the Definition. The actual
Fibonacci data carrier states $1\otimes x=x\otimes1=x$ and
$\tau\otimes\tau=1\oplus\tau$ with multiplicity one in each channel.
[[ex-qc-tqc-fibonacci-data]]

its vertex multiplicity-basis maps. [[def-qc-tqc-fusion-tree-basis]]
