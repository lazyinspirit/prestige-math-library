## Scope and model boundary

All class statements are promise-problem statements over disjoint `Y,N ⊆ {0,1}*`, with no behavior required off `Y∪N`. Reuse root `def-promise-problem`; do not define a QC or QA duplicate. Quantum classes inherit the QC14 model: a deterministic polynomial-time generator on `1^n` emits the complete self-delimiting gate list for `C_n`, with binary wire labels, clean ancillas, explicit input/output registers and predicate, and fixed exact gate alphabet `{H,T,T†,CNOT}` over `Q(ζ₈)=Q(i,√2)`. This model is not silently identified with P/poly or the root indexed logspace-uniform Boolean model. Acceptance is the exact finite-circuit Born probability. QC14 owns `def-qc-promise-computation-model`, `def-qc-uniform-circuit-family`, `def-qc-quantum-acceptance-probability`, `def-qc-circuit-cost-model`, `def-qc-bqp-promise-class`, `alg-qc-bounded-error-amplification`, and `thm-qc-bounded-error-amplification-correct`; QA consumes these exact stems.

The conventional root inner product is linear in its first argument. QC01 `def-qc-dirac-notation-conversion` is required for every ket/bra formula: `<x|y>_D=<y,x>_root`, the bra is linear in its argument, and `|x><y|` has matrix `xy†`. No `physics/` item, measurement postulate, state-preparation postulate, or empirical claim is a logical premise in a QA proof. Physical items were inspected only for scope and convention auditing.

## QA32 — promise classes, containments, amplification and Simon oracle separation

Define PromiseBPP locally by one fixed worst-case polynomial-time PTM using fresh independent fair bits, with acceptance at least `2/3` on `Y` and at most `1/3` on `N`. The root PTM interface supplies the branch clock and finite random-bit cube; root BPP is a language class, so it cannot replace this promised wrapper. Define EQP by exact acceptance 1 on `Y` and 0 on `N`. Define ZQP using output labels `{YES,NO,?}`: on every promised input the wrong definite label has probability zero, and the correct definite label is output with probability at least `2/3`. The `?` label is failure. The ZQP family uses the same full-list uniformity contract. The containments are

\[
\mathrm{PromiseP}\subseteq\mathrm{EQP}\subseteq\mathrm{ZQP}\subseteq\mathrm{BQP},\qquad
\mathrm{PromiseP}\subseteq\mathrm{PromiseBPP}\subseteq\mathrm{BQP}.
\]

`PromiseP⊆EQP` follows by compiling the deterministic solver; `PromiseP⊆PromiseBPP` is deterministic execution. `PromiseBPP⊆BQP` is the random-tape simulation below and retains bounded error, so it does not imply membership in zero-error ZQP. For `ZQP⊆BQP`, map `?` to NO: a YES input still outputs YES with probability at least `2/3`, and a NO input never outputs YES with probability more than `1/3`. Do not state `ZQP=EQP` or `ZQP=BQP∩coBQP` without a separate proof. QC14’s independent fresh-run/majority construction amplifies an initial gap `γ=a−b` using `r=O(γ⁻² log(1/δ))` repetitions; with thresholds `2/3,1/3` this is `O(log(1/δ))`. The repetition algorithm and its correctness theorem remain separate items.

The classical-to-quantum simulation needs an explicit uniform circuit conversion. For each input length, the PTM transition table and polynomial branch clock define a polynomial-size Boolean computation on input `x` and a finite random tape. The root machine-to-indexed-circuit supplier yields a logspace-indexed Boolean family; enumerate its polynomially many gate records by querying every binary gate index. This takes polynomial total time and emits the entire gate list. Convert AND/OR/NOT into compute-copy-uncompute gates, charge QC10’s fanout-sensitive reversible resources, and implement the finite reversible gates exactly over QC14’s alphabet; Hadamards prepare the independent uniform bits. Preserve clean work and the designated output predicate. This indexed-to-full-list conversion is a required proof step, not a uniformity synonym.

After that compiler proof, state `PromiseP⊆PromiseBPP⊆BQP`, `PromiseP⊆EQP⊆ZQP⊆BQP`, and `BPP⊆BQP`, with the QC14 error-reduction theorem. BQP⊆PP and BQP⊆PSPACE are recognized targets with complete source routes for related gate encodings, but remain authoring holds for the frozen QC14 basis. For PP, define the promise inclusion through a total PP language agreeing on `Y∪N`; encode amplitudes/probabilities as coefficient vectors over `Q(ζ₈)`, express the sign test by GapP coefficient functions, and prove exact or certified polynomial-precision comparison to `1/2` using the `1/3` gap. Naive rational path counting is false because probabilities can contain `√2`. For PSPACE, recursively evaluate sums with exact field representations or certified precision and state bit-length and space bounds for every arithmetic and threshold step. Do not promote either containment until those proofs are local.

Simon’s decision promise is an oracle-query separation, not an ordinary gate-time separation. An oracle is `f:F₂ⁿ→{0,1}ⁿ`; YES means injective, and NO means a nonzero `s∈F₂ⁿ` satisfies `f(x)=f(y)` exactly when `y=x` or `y=x⊕s`. The oracle query is `U_f|x,z>=|x,z⊕f(x)>`, counted as one call independently of any gate implementation. In each sample, prepare a uniform input register, query, apply `H^⊗n`, measure the function register, then the input register. If NO, the sample `y` is uniform in `s⊥`, since its amplitude is proportional to `1+(-1)^{s·y}`; if YES, it is uniform in all `F₂ⁿ`. With `m=n+2` independent samples, accept YES iff they span `F₂ⁿ`. NO samples always have rank at most `n−1`. In the YES case, rank failure means some nonzero `t` is orthogonal to every sample; the union bound gives `(2ⁿ−1)2^{−m}<1/4`. The algorithm uses `O(n)` oracle queries.

For the matching classical randomized query lower bound, draw equally from a uniformly random permutation (YES) and a uniformly random valid nonzero-mask 2-to-1 table (NO). A randomized algorithm with average success at least `2/3` has a deterministic fixing with that average success. Repeated queries by a deterministic `T`-query algorithm can be removed. On YES, the answer sequence is a uniform ordered sequence of `T` distinct outputs. On NO, until a collision occurs, the transcript distribution is the same; a collision reveals `s`. Conditional on `k−1` distinct outputs, at most `binom(k−1,2)` masks are excluded and the next query collides with probability at most `(k−1)/(2ⁿ−1−binom(k−1,2))`. For `T≤c·2^{n/2}`, the total collision probability is `O(T²/2ⁿ)`, made less than `1/3` by choosing `c` small. The average success is then at most `(1+Pr[collision])/2<2/3`, forcing `T=Ω(2^{n/2})`. This is a query separation only; it proves no unrelativized BQP-versus-P/BPP gate-time separation and uses no classical oracle diagonalization theorem as a quantum result.

## QA33 — QMA verifier, amplification and local Hamiltonian completeness

A QMA promise verifier is a polynomial-time uniform quantum circuit receiving classical input `x`, a polynomial-qubit witness state `ρ`, and clean initialized verifier ancillas, then measuring an accept effect `E_x` on the witness. For completeness `c` and soundness `s<c`, YES requires some `ρ` with `Tr(E_xρ)≥c`; NO requires `Tr(E_xρ)≤s` for every witness density operator. The default gap is `c=2/3,s=1/3`. A mixed witness is a convex combination of pure eigenstates, so linearity of trace implies that if one mixed witness passes a threshold, one pure eigenvector does too. Reductions are total polynomial-time maps preserving YES and NO under root `def-promise-preserving-reduction`.

QMA amplification has a different soundness proof from BQP amplification. On YES, use `r` copies of a good witness; disjoint verifier registers give independent acceptance indicators, so a Chernoff bound controls the midpoint threshold `(c+s)/2`. On NO, an arbitrary input may entangle all `r` witness blocks. Let `A_j` be the acceptance effect on block `j`; the no-case hypothesis gives `0≤A_j≤sI`. The effects act on disjoint tensor factors and commute. For every `t>0`, the moment-generating operator is
\[
\prod_{j=1}^r(I+(e^t-1)A_j)\preceq(1-s+se^t)^r I,
\]
so the Chernoff/Markov argument bounds a majority of false accepts by the same binomial Chernoff tail even on entangled witnesses. This is the required local proof; the proof must not assert independent verifier outcomes for an entangled witness. The Chernoff tail gives `r=O((c−s)⁻² log(1/δ))` repetitions for both sides. The midpoint threshold is rounded to an integer; witness-copy, width, and gate costs remain explicit.

For `k`-Local Hamiltonian, input `H=Σ_j H_j` on `n` qubits, with `m=poly(n)` terms, each Hermitian and supported on at most a fixed `k` qubits. Encode each local matrix by rational or effectively represented algebraic entries and give a polynomial norm bound `||H_j||≤B`. YES means `λ_min(H)≤a`; NO means `λ_min(H)≥b`, with gap `b−a≥1/poly(n)`, and off-promise behavior is free. Local measurements are not free instructions: the fixed-arity synthesis item must generate a QC14 circuit for `E_j=(I−H_j/B)/2` from its encoded matrix, to precision small compared with the inverse-polynomial gap. Until QC12’s effective bit-time compiler contract is reconciled, keep matrix-only membership explicitly conditional; supplying test circuits as part of the input would define a separate circuit-annotated variant.

For membership, Merlin sends a ground-state witness `ρ`. Arthur chooses `j` uniformly, measures `E_j=(I−H_j/B)/2`, and accepts on outcome 1. Since `0≤E_j≤I`, `p_acc=(1/m)Σ_j Tr(E_jρ)=1/2−Tr(Hρ)/(2mB)`. The promise gives an inverse-polynomial acceptance gap `(b−a)/(2mB)`; generate the local measurement circuits from the matrix encodings, keep their error below a fixed fraction of this gap, then apply QMA amplification.

The fixed-arity measurement-synthesis route is a finite-dimensional Naimark dilation. For `E=(I−H_j/B)/2`, the block matrix `U=[[√E,√(I−E)],[√(I−E),−√E]]` is unitary, and a flag measurement after `U` realizes effect `E`. At fixed `k`, approximate both square roots uniformly on `[0,1]` by Bernstein polynomials; Hölder continuity gives error `O(d⁻¹ᐟ⁴)` at degree `d`, so degree `O(η⁻⁴)` suffices. Evaluate the fixed-size matrix polynomials with certified bit arithmetic, polar-correct the near-unitary, then compile through QC12 at the allocated precision. Prove the measurement-probability error and uniform generator bit cost. This step still depends on QC12’s effective bit-time compilation contract, so matrix-only membership remains an authoring hold.

For reductions using exact QC14 algebraic gate entries, rationalize each local matrix so `Σ_j||H_j−H̃_j||≤τ`. The Rayleigh-quotient characterization gives `|λ_min(H)−λ_min(H̃)|≤τ`. If the original gap is `Δ=b−a`, take `τ≤Δ/8` and move the thresholds inward by `Δ/8`; the rational instance retains gap at least `3Δ/4`. Fixed local dimension makes the required polynomial-bit rounding schedule explicit.

For QMA-hardness, start with a verifier circuit `U_T…U_1` on `m` witness qubits and initialized ancillas; the time-zero product is the identity. Amplify first if needed to create the stated gap. Use the normalized history state
\[
|\eta_\psi\rangle=(T+1)^{-1/2}\sum_{t=0}^T U_t\cdots U_1(|\psi\rangle|0^a\rangle)\otimes|t\rangle .
\]
The Feynman–Kitaev Hamiltonian is the sum of positive input, clock, propagation, and output penalties. The propagation term is the path-Laplacian form
\[
H_{prop}=\tfrac12\sum_{t=1}^T(I\otimes|t\rangle\langle t|+I\otimes|t-1\rangle\langle t-1|-U_t\otimes|t\rangle\langle t-1|-U_t^\dagger\otimes|t-1\rangle\langle t|).
\]
Its zero space is exactly the valid computation-history subspace: conjugating by `W=Σ_t(U_t…U_1)⊗|t><t|` turns it into the half-weight path Laplacian tensored with identity. The path Laplacian has the uniform clock state in its kernel and first nonzero eigenvalue `1−cos(π/(T+1))=Θ(T⁻²)`. The input term penalizes nonzero initialized ancillas at time 0; the output term penalizes rejection at time `T`. A unary clock replaces binary-clock terms with local transition checks and a local illegal-clock penalty. Each Feynman–Kitaev term has support on at most five qubits.

Completeness is direct: a witness accepted with probability at least `1−ε` has a valid history with zero input, propagation, and clock energy; the output penalty contributes at most `ε` under the `(T+1)`-scaled convention. For soundness, apply the geometric lemma to `S₁=ker(H_in+H_out)` and `S₂=ker(H_prop)`. The first operator has nonzero spectrum at least 1, while propagation has gap `Ω(T⁻²)`. On a NO verifier, soundness `s<1` bounds the squared projection of a valid history onto `S₁` by `1−(1−s)/(T+1)`, so `sin²θ≥(1−s)/(T+1)`. The geometric lemma then gives ground energy `Ω((1−s)/T³)` for this normalization. The local item must prove this overlap estimate and state the exact geometric inequality; the illegal-clock penalty must preserve the inverse-polynomial gap. The item DAG keeps the path gap, input/output penalties, geometric lemma, and clock-locality proof separate.

The stronger 2-local QMA-hardness route in Kempe–Kitaev–Regev is a separate theorem and proof DAG. First amplify the verifier to completeness at least `3/4` and soundness at most `1/4`. Normalize its gates to one-qubit gates and controlled phase, pad so controlled-phase gates occur at regular intervals, and surround each with cancelling one-qubit `Z` gates. On computation plus unary clock, use `H_out+J_in H_in+J_2 H_prop2+J_1 H_prop1+J_clock H_clock`: the clock term penalizes illegal `01` pairs; `H_prop1` enforces one-qubit propagation; `H_prop2` checks two-qubit gates through phase/parity relations at separated unary-clock positions; `H_in` checks clean ancillas at time zero; `H_out` checks rejection at the final clock value. Each summand has support on at most two qubits. Apply the projection lemma successively to legal clocks, correct one-qubit propagation, full propagation, and valid initial states. Choose polynomial weights `J_in≪J_2≪J_1≪J_clock`, each large enough that its error `||H_1||²/(J−2||H_1||)` is below its allocated share of the remaining inverse-polynomial gap; write a recursive integer choice, polynomial norm bounds, and total error. KKR proves this projection-lemma route and a separate perturbative-gadget route; this plan uses the former and will not skip its penalty hierarchy or locality checks. The proposed 5-local and 2-local matrix-only QMA-completeness items remain conditional on closing the local measurement-synthesis and rational-encoding proof obligations above.

## QA34 — composition, precision, verification and dequantization limits

Use one end-to-end error convention. For channels `Φ,Ψ`, define normalized diamond distance `d⋄(Φ,Ψ)=½||Φ−Ψ||⋄`, with the supremum over reference ancillas. Use QC06 `def-qc-diamond-norm`, its ancilla-dimension theorem, the channel-composition hybrid theorem, and the tensor-error theorem. If exact stages are `Φ₁,…,Φ_L` and implemented stages are `Φ̃_i`, then
\[
d_\diamond(\widetilde\Phi_L\cdots\widetilde\Phi_1,\Phi_L\cdots\Phi_1)\le\sum_i d_\diamond(\widetilde\Phi_i,\Phi_i).
\]
This is a telescoping sum: replace one stage at a time, apply complete trace-norm contractivity to the channels before/after it, then triangle inequality. Tensor products have the corresponding additive bound from QC06. Final measurement changes the classical output law by total variation at most the final state trace distance (and at most the channel diamond distance). The factor (1/2) is part of the chosen metric; do not silently switch to an unhalved trace/diamond norm. A state-only trace-distance proof suffices only for an unconditional fixed-input run; entangled/adaptive channel calls require the diamond interface.

Allocate local errors `ε_i` with `Σ_i ε_i≤ε_tot`, and separately charge input preparation, every query/gate/controlled inverse, classical preprocessing, ancillas, output measurement, and postselection. If stage `j` has conditional failure probability at most `δ_j` after every successful prior history, a union bound gives total failure at most `Σ_jδ_j`; independence is unnecessary. With independent fresh trials of success probability at least `p>0`, repeat-until-success has expected count `1/p`; a fixed cap `r≥p⁻¹ln(1/δ)` misses success with probability at most `δ`. State conditional output accuracy separately from failure probability. Reusing correlated bits or witness blocks does not justify an independence-based tail bound.

Distinguish a classical result from a quantum state output. Writing `N` classical output bits costs at least `Ω(N)` bit operations/output positions in the stated model; a state-preparation theorem does not print its amplitudes. QC24's `def-qc-state-preparation-cost-model` and `alg-qc-state-preparation` define the preparation interface; `thm-qc-state-preparation-cost` gives an `O(D)`-rotation, `O(nD)`-bounded-arity-gate upper bound with `O(n)` clean ancillas when exact continuous rotations are available. Table encoding, precision, and access remain explicit. This is not a finite-gate-set cost claim. With a finite gate set, account separately for approximation precision and synthesis resources under QC12's `alg-qc-solovay-kitaev-unitary-compiler` and `thm-qc-solovay-kitaev-error-and-resource-bound`. Tomography, amplitude lists, QRAM, coherent controlled access, and inverse access are charged only when separately supplied. A final distribution or observable precision bound does not give a full classical description of an unknown state.

For a proved dequantization example, state Tang’s recommendation theorem narrowly. Input is `A∈R^{m×n}` with entry queries and row/column `ℓ₂`-norm sampling, a row index, singular threshold `σ`, and accuracy parameters. ModFKV outputs a succinct description `D=ASᵀÛΣ̂⁻²ÛᵀS` satisfying `||D−A_{σ,η}||_F≤ε||A||_F` under the paper’s parameter restrictions; the routine samples within total variation `ε` of the normalized squared-entry distribution of row `D_i`. The exact paper bounds are `Õ(||A||_F^{18}/(σ^{18}ε^8η^4))` queries and `Õ(||A||_F^{24}/(σ^{24}ε^{12}η^6))` time, with final accuracy conversion multiplying runtime by `Õ(||A_i||₂²/||D_i||₂²)`. Require `||D_i||₂>0`; suppressed logarithmic factors include access overhead and failure reduction. The theorem assumes the same efficient `ℓ₂` sample/query data structure that makes quantum state preparation efficient; it does not output the full matrix or simulate arbitrary QML. ModFKV’s low-rank proof invokes external FKV concentration/sampling details, so a local FKV helper item is still needed before promotion.

QA34 examples should include (i) a three-stage hybrid calculation with `ε₁+ε₂+ε₃`, (ii) a failure branch versus conditional output, (iii) a state-output problem where printing all amplitudes removes the claimed sublinear cost, and (iv) a Tang input without `ℓ₂`-sampling access.

## QA35 — communication protocols, fingerprints and lower bounds

Define a finite communication problem and protocol before stating costs: finite input sets and promise, local inputs, message order/rounds, message spaces and dimensions, local computation, referee measurement, worst-case promised-input error, and whether shared randomness or entanglement is available. A one-way or simultaneous-message protocol cannot assume a shared resource unless declared. Communication counts transmitted bits/qubits; local computation is separate.

For Equality on inputs `x,y∈{0,1}ⁿ`, choose a binary code `E:{0,1}ⁿ→{0,1}ᴺ` with `N=O(n)` and relative distance at least a fixed `δ>0`. Alice sends `|h_x>=N^{-1/2}Σ_i|i>|E_i(x)>` and Bob sends `|h_y>=N^{-1/2}Σ_i|i>|E_i(y)>`. Their overlap is the codeword agreement fraction: 1 for equal strings and at most `1−δ` otherwise. The antisymmetric swap-test outcome has probability `(1−|<h_x|h_y>|²)/2`, which is zero for equal inputs and at least `[1−(1−δ)²]/2>0` otherwise. Repeat on `r=O(log(1/ε))` fresh pairs and declare unequal if any test is antisymmetric; error is at most `ε`, using `O(log n·log(1/ε))` qubits per sender. No shared entanglement or randomness is used. A uniform protocol needs an explicit efficiently generated code family with a proved distance bound. Random-code existence gives a nonuniform codebook unless construction and description costs are included.

The deterministic simultaneous-message classical Equality lower bound is local: if two distinct Alice inputs share a message, fix Bob input `y` to one of them. The referee sees the same transcript on equal and unequal inputs but must answer differently, a contradiction. Alice’s map must be injective, requiring at least `n` bits up to variable-length framing.

For the quantum fingerprint lower bound in the simultaneous model with no shared entanglement or randomness, fix Bob’s input `y`. The referee’s equality effect separates Alice’s state `ρ_y` from each `ρ_x`, `x≠y`, by an acceptance-probability gap at least `1/3`; QC06 `thm-qc-measurement-variation-at-most-trace-distance` gives pairwise trace distance at least `1/3`. Quantize the real and imaginary entries of each `d×d` density matrix to mesh `Θ(d⁻³ᐟ²)`. Since `||M||₁≤√d||M||_F`, choose the mesh so each trace-distance approximation is below `1/12`. There are at most `exp(O(d²log d))` cells, so `2ⁿ≤exp(O(d²log d))`; with message dimension `d=2^q`, this forces `q=Ω(log n)` qubits per sender.

The standard bounded-error private-coin SMP Equality lower bound `Ω(√n)` is attributed to Newman–Szegedy. The official ACM endpoint returned HTTP 403 and no open full text was retrieved, so this remains a bibliography note and proof-authoring hold, not a proved item. It is not replaced by deterministic `Ω(n)` (a different randomness model) or public-coin `O(1)` hashing (shared randomness changes the model). QA35 excludes QC17: fingerprints use no Bell pairs, teleportation, dense coding, or shared entanglement.
