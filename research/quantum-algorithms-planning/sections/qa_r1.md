## QA01 — Computational problems, promises, and cost models

A decision task is a root promise pair `(Y,N)` of disjoint subsets of binary strings. A search task names a relation `R(z,w)` and asks for a witness on every promised input. The task must state an encoding, the input-length convention, and the behavior required on the promise; no correctness is imposed outside it. For a fixed input length `n`, an encoded instance `z` selects a total function

`f_z : {0,1}^{a(n)} → {0,1}^{b(n)}`.

The promise restricts which `z` are legal, not the domain on which `f_z` is defined. Its standard quantum query is exactly the QC coherent XOR oracle `U_f |x⟩|y⟩ = |x⟩|y xor f_z(x)⟩`. A matrix or black-box description does not provide a gate decomposition, state preparation, or controlled access at a cheaper cost.

A `T`-query quantum algorithm is a finite specified QC circuit with at most `T` designated calls on every execution branch, an explicit initialization, any allowed measurements and classical feed-forward, and a final classical output rule. Query cost is the maximum number of oracle calls over promised instances of the same input length and all measurement branches. Exact correctness means success probability one on every promised input. Bounded-error correctness means at least `2/3` success on each promised input; this is a per-instance guarantee, not an average over an input distribution. Uniformity is claimed only when the supplied QC family definition establishes it.

A classical query algorithm chooses each address from the encoded input, earlier answers, and—when randomized—its random bits. One oracle reply is one query regardless of output width. Query cost is the maximum over promised inputs and random tapes; expected-query bounds are reported separately. For a sequential procedure with finite outcome sets per step, define expected query cost as the supremum over `M` of the finite-prefix expectations of the actually executed prefix query count `C_M`; idle extensions after halting preserve the count. This definition also covers unbounded stopping procedures without applying finite-space probability theorems to an unbounded random variable. Classical bit cost uses multitape Turing transitions over a fixed finite alphabet, counting random-bit generation, address formation, reading/writing replies, and output processing. Quantum nonoracle gate cost counts the declared circuit gates outside query calls, including preparation, ancilla work, and inverse gates; measurements and classical branch work are reported according to the selected QC resource convention. Non-input registers start in |0>; any supplied nonzero state must name an access or preparation model, and its preparation or access cost is charged rather than treated as free. These are distinct resource coordinates.

Promise-preserving composition transfers correctness through a many-one reduction. Query cost transfers without extra calls only when the target query oracle is directly supplied after reduction. Otherwise the source must state and count a simulation of each target query; a promise map alone cannot make an unrelated oracle free.

The B companion compares decision and search promises, gives a small promise-preserving reduction, and tabulates a query-only example next to its gate and bit costs.

## QA02 — Reversible arithmetic and oracle conversion

For a Boolean function `f`, the standard bit query is its coherent XOR action and the phase query is `P_f|x⟩=(-1)^{f(x)}|x⟩`. Starting the target at `|0⟩`, applying `X` then `H` prepares `|−⟩=(|0⟩−|1⟩)/sqrt(2)` using two nonoracle gates. One standard query then implements `P_f` on the address and returns the target unchanged, including on superpositions by linearity. The query and the two preparation gates are charged separately; this fixed state uses an explicit circuit, not generic amplitude-table loading. The reverse conversion is conditional: if controlled `P_f` access is supplied, Hadamards on a control bit before and after that call implement the XOR action, since `H Z^{f(x)} H = X^{f(x)}`. Bare uncontrolled phase access does not imply this controlled resource.

If a Boolean circuit for `f` has a clean reversible embedding with gate count `G` and output width `b`, compute the output, copy its bits with `b` CNOTs into a fresh target, and run the exact inverse embedding. The embedding workspace returns to zero, and the resulting standard query uses `2G+b` gates in addition to its abstract query count. QC10’s reversible-embedding construction gives `O(S+E+b)` gates with explicit wire-edge count `E` (bounded fan-in gives E=O(S)) from Boolean circuit size `S`; its depth is not inherited from the classical DAG without the separately stated fanout schedule.

For the later inner-product promise, define `a·x = XOR_i (a_i AND x_i)`. The explicit clean circuit uses one work bit `r`, applies Toffoli gates to accumulate each conjunction by XOR into `r`, copies `r` to the target, and reverses the Toffolis. It implements `|a⟩|x⟩|z⟩|0⟩ ↦ |a⟩|x⟩|z xor (a·x)⟩|0⟩` with `2n` Toffolis and one CNOT. The cost is in the stated reversible gate model.

For constant `f=c`, `P_f=(-1)^c I` has no standalone measurement effect by QC’s global-phase theorem. Under control, its two control sectors acquire different scalars when `c=1`; QC’s controlled-phase theorem supplies an explicit state and measurement distinguishing it from identity. This is why replacing a unitary by a phase-congruent one inside controlled access requires tracking the phase.

The B companion checks one- and two-bit XOR functions, demonstrates compute-copy-uncompute with clean versus dirty workspace, and computes the controlled relative phase explicitly.

## QA03 — Exact oracle algorithms

For Deutsch, the two-point oracle is promised constant or balanced. Starting from `|0⟩|0⟩`, apply `X` then `H` to the target and `H` to the address, query once, then apply `H` to the address and measure. The target preparation costs one `X` and one `H`; the address gets two `H` gates. The output is `0` for constant and `1` for balanced with probability one. One classical query cannot distinguish a constant oracle from a balanced oracle agreeing at that queried point; two distinct queries solve the task exactly.

For Deutsch–Jozsa, let `N=2^n`, `n≥1`, and promise the Boolean function is constant or exactly balanced. The same construction uses one target `X`, a target `H`, and `H^{⊗n}` on the zero address before the query, then `H^{⊗n}` after it. It uses one query and `2n+1` Hadamards plus the one `X` preparation gate; it returns `y=0^n` with certainty in the constant case. The zero amplitude is `2^{-n} sum_x (-1)^{f(x)}`, so it vanishes in the balanced case. An exact deterministic classical solver needs `floor(N/2)+1` queries: up to `N/2` identical replies have both constant and balanced completions. This is an exact deterministic lower bound, not an exponential bounded-error separation. Indeed, for `n≥2`, three distinct uniformly sampled points classify every balanced function correctly with probability at least `3/4`, because the all-equal-reply probability is `2 binom(N/2,3)/binom(N,3) ≤ 1/4`; for `N=2`, two queries solve exactly.

For Bernstein–Vazirani, promise `f_a(x)=a·x` with no additive offset and unknown `a∈F_2^n`. From zero registers, prepare the address with `n` Hadamards and the target with `X` then `H`; one phase query and a second layer of address Hadamards returns `a` with certainty, since the output amplitude at `y` is `2^{-n} sum_x(-1)^{x·(a xor y)}`. Any classical algorithm needs `n` queries for exact recovery and, under a uniform secret, a randomized `q`-query decision tree succeeds on average with probability at most `2^{q-n}`. Thus worst-case success at least `2/3` requires `q≥n`; the standard basis queries attain `n`.

All three correctness proofs reduce to the finite F2 Hadamard character sum. The randomized sample proof is without replacement, and the `n=1` DJ case is handled separately. The B companion lists the truth tables for the two-bit DJ and BV instances and checks zero-frequency output.

## QA04 — Simon’s algorithm and finite-field recovery

For `n≥1` and output width `m≥n−1`, Simon’s promise is a total function `f:{0,1}^n→{0,1}^m` with a unique unknown nonzero `s` such that `f(x)=f(y)` iff `y=x xor s`. Each fiber is exactly one pair `{x,x xor s}`; the width condition permits distinct labels for all `2^{n−1}` fibers. The `F_2` carrier is the root residue field `Z/2Z`. Since 2 is prime, the root prime-modulus field theorem supplies its field laws; the QA item is only the specialization and notation bridge, not a second field proof or a general finite-field classification.

One sample prepares a uniform address, calls the standard oracle once, applies Hadamards to the address, and measures. Measuring the output first gives the normalized pair state `( |x_0⟩+|x_0 xor s⟩ )/sqrt(2)`. The final amplitude at `y` is zero unless `s·y=0`, and is `2^{-(n-1)/2}(-1)^{x_0·y}` otherwise. Hence every sample is uniform on the `(n−1)`-dimensional hyperplane `s^perp`, independently of the observed coset. Repeating with fresh initialized registers gives independent samples.

If the current span has rank `k<n−1`, exactly `2^k` of the `2^{n-1}` equally likely hyperplane samples lie in that span. The next sample increases rank with probability `1−2^{k-(n-1)}≥1/2`; the waiting time for the next independent equation has mean at most two. Collecting `n−1` independent rows therefore terminates almost surely with expected query count at most `2(n−1)`. Row reduction over `F_2` takes `O(n^3)` bit operations. Rank-nullity makes the kernel one-dimensional, and its two members are zero and the unique nonzero mask `s`.

For a finite bounded-error procedure, take `d=n−1` and a supplied rational `δ∈(0,1)`. If `d=0`, return the unique nonzero one-bit mask with no query. Otherwise run at most `M=ceil(2d/δ)` samples, maintaining an echelon basis and retaining only rank-increasing rows; solve if rank `d` is reached and return `FAIL` otherwise. Each stage waiting time is geometric with mean at most two, so the unbounded process has expected query cost at most `2d` under the finite-prefix definition above. For the capped procedure, `T_M=min(T,M)` is a finite random variable determined by the first `M` samples. Finite-space Markov gives `Pr(T>M)≤Pr(T_M≥M)≤E[T_M]/M≤2d/M≤δ`. The maximum query count is `O(n/δ)`; for constant `δ=1/3` this is `O(n)`. Reducing each incoming row against at most `n−1` pivots costs `O(n²)` bit operations per sample; final row reduction is `O(n³)`, for `O(Mn²+n³)` bit operations plus the bit cost to compute the rational cap. The proof does not apply the finite-space Markov theorem directly to the unbounded stopping count.

For the classical lower bound, choose `s` uniformly among nonzero masks and assign distinct random output labels to the `2^{n−1}` cosets; require output width `m≥n−1`. Under a collision-free adaptive transcript, the posterior mask is uniform over all nonzero masks except the pairwise address XORs already queried. Let `N=2^n`, `S=N−1`, and `B=binom(q,2)`. At the `j`th fresh query, at most `j−1` remaining masks produce a collision with a prior address, while at least `S−binom(j−1,2)` masks remain possible. Summing these conditional bounds gives collision probability at most `B/(S−B)`. After a collision-free transcript, guessing success is at most `1/(S−B)`. Therefore average success is at most `(B+1)/(S−B)`. For `n≥8` and `q≤floor(2^{n/2}/4)`, `B≤N/32` and this is strictly below `2/3`. Averaging over random tapes proves the worst-case randomized classical query lower bound `Ω(2^{n/2})` with an explicit constant cutoff.

The B companion works the `n=1` no-query case and the `n=2` hyperplane rows, rank-growth probability, and unique kernel by hand.

## QA05 — Finite abelian Fourier analysis

For a finite abelian group `G` in additive notation, let `G-hat` be the characters `χ:G→C^×`, with pointwise multiplication. The cyclic decomposition shows that a cyclic group of order `r` has exactly `r` characters: a character is determined by the image of a generator, which is one of the `r` roots of unity. Characters of a direct product factor coordinatewise. Therefore `|G-hat|=|G|`, and the pointwise operations make `G-hat` a finite abelian group.

The transform convention is fixed as

`F_G f(χ) = |G|^{-1/2} sum_{x∈G} f(x) conjugate(χ(x))`.

Its matrix has entries `|G|^{-1/2} conjugate(χ(x))`. Root character orthogonality gives row orthogonality; the separate dual-index identity

`sum_{χ∈G-hat} χ(x) conjugate(χ(y)) = |G|` if `x=y`, and `0` otherwise

is proved from cyclic root sums over the invariant-factor coordinates. It is not inferred from `|G-hat|=|G|` or from row orthogonality. Together the two identities give unitarity. The inverse uses the positive character, and Parseval preserves the counting inner product under the first-argument-linear convention.

With unnormalized convolution `(f*g)(z)=sum_x f(x)g(z−x)`, the transform law is `F_G(f*g)=sqrt(|G|)(F_G f)(F_G g)`. The square-root factor follows directly from the one `|G|^{-1/2}` normalization in the transform.

For a subgroup `H≤G`, define `H^perp={χ:χ(h)=1 for every h∈H}` and dually for a subgroup of the character group. A character in `H^perp` factors uniquely through `G/H`; dual cardinality and Lagrange’s theorem give `|H^perp|=|G|/|H|`. An explicit cyclic-coordinate character detects each nonzero group element, making evaluation `G→G-hat-hat` injective; finite dual cardinality makes it an isomorphism. Under this evaluation identification, the double annihilator of `H` is `H` itself.

For `x_0+H`, the transform of the **indicator** is `|H|/sqrt(|G|) conjugate(χ(x_0))` on `H^perp` and zero elsewhere. Consequently, the normalized uniform coset vector has amplitude `sqrt(|H|/|G|)=1/sqrt(|H^perp|)` on each character in `H^perp` and zero elsewhere, so its Fourier measurement is uniform on that annihilator. The boundary case `H=G` gives amplitude one at the trivial character. Keeping the indicator and normalized-state coefficients distinct prevents a factor-of-`sqrt(|H|)` error.

The B companion tabulates characters of `Z/4Z`, `Z/2Z×Z/2Z`, and their subgroups to check the dual-size, orthogonality, convolution, and annihilator formulas.

## QA06 — Quantum Fourier-transform circuits

Define the positive-sign cyclic QFT by `QFT_N=F_N^{-1}`. On a basis state it is `|x⟩ ↦ N^{-1/2} sum_{y=0}^{N−1} exp(2πixy/N)|y⟩`; this is the inverse of the root negative-sign cyclic DFT. For `N=2^n`, the exact binary circuit acts on ordered wires `q_{n−1},…,q_0`: for `j=n−1` down to zero, apply `H` on `q_j`, then apply controlled `R_{j−i+1}=diag(1,exp(2πi/2^{j−i+1}))` from `q_i` to `q_j` for each `0≤i<j`; finally reverse the wire order with `floor(n/2)` swaps. The gate order fixes the endian convention. For basis bits `x_0,…,x_{n−1}`, immediately before the swaps the factors on ordered wires are `R_{n−1}⊗⋯⊗R_0`, where `R_j=(|0⟩+exp(2πi·0.x_jx_{j−1}…x_0)|1⟩)/sqrt(2)`; after the swaps the factors on `q_{n−1},…,q_0` are `R_0⊗⋯⊗R_{n−1}`. Reversing the list and taking adjoints gives the negative-sign inverse QFT at the same ideal gate count.

On a computational-basis input, each Hadamard contributes one binary phase bit and each controlled rotation contributes the corresponding binary cross term. Their product is the positive-sign Fourier amplitude, with the final swaps returning the bit-reversed intermediate order to the standard order. Linearity proves circuit correctness on every state. The ideal count is `n` Hadamards, `n(n−1)/2` controlled phases, `floor(n/2)` swaps, and no ancillas. Expanding each swap into three CNOTs changes only the swap count convention.

For cutoff `1≤m<n`, omit every controlled rotation with denominator index `s>m` and retain all Hadamards and swaps. There are `n−s+1` rotations at index `s`. Since `|1−e^{iθ}|≤|θ|`, each omitted factor differs from identity in operator norm by at most `2π/2^s`. Telescoping the product of unitary gates gives

`||QFT_{2^n}−QFT^{(m)}_{2^n}|| ≤ sum_{s=m+1}^n (n−s+1)2π/2^s ≤ 2π n·2^{-m}`.

For `m≥n` the error is zero. Thus `m=min(n,ceil(log₂(2πn/ε)))` gives operator error at most `ε`. The ideal truncated gate count is `n + sum_{s=2}^m(n−s+1) + floor(n/2) = O(nm)` for `m≤n`; at inverse-polynomial error it is `O(n log n)`. For every unit input state, operator error `ε` changes the computational-basis output distribution by at most `ε` in total variation, using the finite Cauchy–Schwarz bound on squared amplitudes.

The finite-alphabet compilation claim uses separate error budgets. For rational `0<η<1`, set `m=min(n,ceil(log₂(4πn/η)))`, so truncation has operator error at most `η/2`. Let `L=O(nm)` count the Hadamard and controlled-phase blocks; expand each final swap into three exact CNOTs. Compile each one-qubit block and each **complete** controlled-phase block to projective operator error at most `δ=min(η/(2L), ε₀/2)`, where `ε₀` is QC12’s fixed compiler threshold. The full-block fixed-arity QSD/Solovay–Kitaev result gives total projective error at most `η/2` from compiling the truncated circuit, and therefore at most `η` from the exact QFT. The projective-distance output theorem bounds total-variation error of every computational-basis output law by `η`. The finite gate count is `O(nm log^{3.97}(2nm/η))` including the `O(nm)` exact CNOTs in the fixed-arity decompositions and the `O(n)` swap CNOTs. Per-block scalar phases remain tracked as QC12 metadata; they are irrelevant to this standalone output law but become relative under outer control, and this claim gives no outer-controlled compilation cost. The gate-count result uses QC12’s exact-arithmetic compiler interface; it makes no finite-precision target-angle bit-time claim.

The B companion traces the `n=2` circuit in both wire orders, compares the exact and one-level truncated rotations, and verifies the error and gate-count formulas for small cutoffs.

- `def-qa-expected-query-cost`: A sequential procedure has finite outcome sets and a specified normalized transition law at each elementary step. Its first M elementary steps give a finite experiment; let C_M be the number of oracle calls executed by that prefix, with a halted branch extended by deterministic idle steps. Define expected query cost as sup_M E[C_M] in [0,∞]. Define total query count pathwise as sup_M C_M; an infinite execution can have finite query count. No finite-prefix experiment is claimed to determine min(total queries,M) when arbitrarily many nonquery steps intervene.
- `alg-qa-reversible-binary-dot-product`: Input registers |a>|x>|z> and one clean ancilla r=0. For i=1,…,n apply the exact reversible Boolean gate (a_i,x_i,r)↦(a_i,x_i,r xor (a_i and x_i)); then apply CNOT(r,z); reverse the n gates; output |a>|x>|z xor (a·x)>|0>. This explicit bounded-arity circuit uses exactly 2n Toffoli gates and one CNOT, and has no failure branch.
- `thm-qa-reversible-binary-dot-product-correct-and-cost`: The stated sequence maps every computational basis input to |a>|x>|z xor(a·x)>|0> and therefore implements that map on superpositions by linearity; its exact abstract gate count is 2n Toffolis and one CNOT, with one clean work bit.
- `alg-qa-f2-gaussian-elimination`: Input a binary d×n matrix, d=n−1, n≥1. Set pivot row k=0. For columns j=0,…,n−1 find the least row i≥k with entry 1; if none, continue to next column. Otherwise swap rows i,k, XOR row k into every other row with entry 1 in column j, record pivot j, and increment k. If k≠n−1 return FAIL. Set the sole nonpivot variable to 1 and solve each pivot variable from its reduced row. Return the resulting n-bit vector. Every search, row XOR and loop is bounded; n=1 returns vector 1.
