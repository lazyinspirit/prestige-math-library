## Conventions and shared quantum interfaces

The mathematical contracts use finite-dimensional complex registers and exact circuit semantics. Inner products are linear in the first argument, following the root/QC convention and reserved `def-qc-dirac-notation-conversion`. When a source writes Dirac notation, translate its bra as `⟨x|y⟩_D = ⟨y,x⟩_root`; thus `|x⟩⟨y|` maps `z` to `⟨z,y⟩_root x`. None of the physics-library items below is a logical dependency.

QA07 consumes the reserved QC register, ordered-bit, tensor, pure-state, projective-measurement, controlled-unitary, circuit-syntax/semantics, and classical-control interfaces: `def-qc-register-and-computational-basis`, `def-qc-ordered-bitstring-encoding`, `def-qc-tensor-register-and-permutation`, `def-qc-pure-state-and-ray`, `def-qc-projective-measurement`, `def-qc-controlled-unitary-access`, `def-qc-circuit-syntax-and-register-order`, `def-qc-circuit-denotational-semantics`, and `def-qc-classical-control-and-measurement-circuit`. It uses QA06’s positive-sign cyclic-QFT definition `def-qa-cyclic-quantum-fourier-transform` and exact binary-QFT circuit theorem `thm-qa-exact-binary-qft-circuit-correct`; the negative-sign inverse-QFT stage is obtained by reversing that explicit finite gate list and negating each rotation angle, at equal gate count. A superposition-of-eigenvectors theorem additionally needs the root finite-dimensional spectral theorem and QC’s conditional-state instrument interface. These are reservations, not yet written proof suppliers. QPE does not require inverse access to the input unitary.

For the phase register, let `Q=2^m`. The phase convention is `U|ψ⟩ = exp(2πiθ)|ψ⟩`, `0≤θ<1`. With the positive-exponent eigenvalue and the negative-sign inverse QFT convention, output `y` has probability

`Pθ(y) = Q^-2 |Σ_{j=0}^{Q−1} exp(2πi j(θ−y/Q))|²`.

The unnormalized exact law follows from the circuit amplitude and the finite geometric sum. It gives probability one at `y=Qθ` when `Qθ` is integral. For a nearest integer modulo `Q`, write `δ=Qθ−y` with `|δ|≤1/2`; the geometric-sum formula and `sin(π|δ|)≥2|δ|`, `sin(π|δ|/Q)≤π|δ|/Q` give probability at least `4/π²` (the `δ=0` value is the continuous limiting value 1). For circular distance `d=‖θ−y/Q‖`, `sin(πd)≥2d` gives `Pθ(y)≤1/(4Q²d²)`. There are at most two grid points in each distance annulus `[k/Q,(k+1)/Q)`, so for `K=⌊Qη⌋≥2`, `Pr[d≥η]≤(1/2)Σ_{k≥K}k^-2≤1/(2(K−1))`. The statement will record this explicit tail rather than an unnamed “high probability” estimate.

Access and cost are separate. If a device supplies one controlled `U^(2^j)` operation for each `j<m`, one run costs exactly `m` controlled-power queries. If only one controlled-`U` black-box gate is available, repeated application costs `Σ_j2^j=Q−1` controlled-`U` queries; phase estimation does not make powers cheap. In the explicitly supplied power-circuit model the gate cost is `Σ_j C_j + O(m²)` for the controlled powers and exact inverse QFT. The `O(m²)` QFT count assumes the ideal continuous-rotation submodel of the QC cost interface, with exact arbitrary-angle controlled phases. It does not imply a fixed finite gate alphabet or a uniform circuit family. A later finite-gate approximation would need QA06's truncation/synthesis error theorem and a local hybrid argument adding that error to the QPE outcome law. State preparation and measurement are counted under the QC interfaces.

## QA07 — Quantum phase estimation

The procedure takes a unitary `U`, an `m`-bit phase register, and a normalized eigenstate `|ψ⟩`; its access contract lists the controlled powers. It prepares the control uniformly, applies the controlled powers, applies the inverse QFT, and measures `y`; it returns `y/Q` as a phase estimate. It does not assume that the `m`-bit estimate is an exact binary expansion. For a general input vector, the spectral decomposition gives a mixture over eigenphases with weights equal to squared projection norms, and the conditional system vector is `K_y ψ/√p_y`, where `K_y=Σ_θ a_y(θ)Π_θ`; finite-precision conditioning generally retains coherent contributions from several eigenspaces; this is a separate theorem from the eigenvector outcome law.

The correctness route is: write the state after controlled powers as `Q^-1/2 Σ_j exp(2πijθ)|j⟩|ψ⟩`; reverse QA06’s positive-sign QFT gate list and negate its rotation angles; use the projective-measurement outcome law to get the displayed Dirichlet-kernel probability. The success route is the nearest-grid and tail calculation above. The gate/query route is the explicit access split above, plus `m` Hadamards, inverse QFT, and any supplied uniform state preparation. Childs explicitly gives the nearest-grid constant; de Wolf states controlled powers and their cost but leaves the probability estimate unproved. The full local tail proof is therefore an authoring obligation, not borrowed from either text.

## QA08 — Order finding and rational reconstruction

For coprime integers `x,N`, `N≥3`, let `r=ord_N(x)` and `U_x|z⟩=|xz mod N⟩` on valid residues. Extend this permutation to the full bit register by the identity on invalid encodings. With `Q=2^m>4N²`, run QPE on `U_x` from `|1⟩`. The orbit basis `|1⟩,|x⟩,…,|x^(r−1)⟩` has Fourier eigenvectors with eigenvalues `exp(2πik/r)`; `|1⟩` is their equal-norm superposition. Thus the hidden phase index `k` is uniform in `0,…,r−1`.

Rational reconstruction takes the measured `y`, reduces `y/Q` to `A/D`, forms its normalized finite continued fraction by the Euclidean algorithm, and searches all its reduced convergents `p/q`, including the terminal one, with `1≤q≤N` for the unique one satisfying `2|yq−pQ|≤q`. If no candidate exists, that sample is discarded. It then tests `x^q≡1 (mod N)`. The order output after `t` independent phase samples is the smallest accepted denominator; if none is accepted it returns `FAIL`. This minimum rule matters: every accepted denominator is a multiple of the true order, so no accepted denominator is smaller than `r`; if any sample recovers `r`, the minimum is exactly `r`. A wrong larger multiple remains a possible error and is included in the failure event.

On a nearest-grid sample for phase `k/r`, `|y/Q−k/r|≤1/(2Q)<1/(2r²)`. If `gcd(k,r)=1`, the reduced target is `k/r`. The published Legendre theorem only has irrational real input, while `y/Q` is rational. QA08 therefore proposes a separate finite-rational Legendre bridge, proved directly from the finite continued-fraction recurrences: for a rational `A/D` in lowest terms with `D>2q`, a reduced `p/q` with `|A/D−p/q|<1/(2q²)` is a convergent of the normalized finite expansion. One must not simply set `D=Q`, since `y/Q` need not be reduced. If the reduced sample equals `k/r`, it is already the terminal convergent. Otherwise the determinant bound `|A/D−k/r|≥1/(Dr)` and the strict approximation imply `D>2r`, so the finite-rational criterion applies. Its proof adapts the best-approximation determinant argument before the terminal convergent, allowing equality in the terminal complete quotient. This is an explicit local proof obligation; the irrational-only theorem is not imported by citation. Uniqueness of the denominator-bounded rational within `1/(2Q)` follows because distinct reduced fractions with denominators at most `N` differ by at least `1/N²`, whereas two candidates in that interval differ by at most `1/Q<1/N²`.

For each phase sample, the phase is uniform `k/r`, and the nearest-grid event has probability at least `4/π²`. The chance that `k` is coprime to `r` is `φ(r)/r`. A local bound derived from the published Euler product is `φ(r)/r=∏_{p|r}(1−1/p)≥1/(1+log₂r)`: order distinct prime divisors increasingly, use `p_i≥i+1`, telescope the product lower bound to `1/(ω(r)+1)`, and note `ω(r)≤log₂r`. Thus one phase sample returns the exact order with probability at least `4/[π²(1+log₂N)]`. For target failure `δ`, `t=⌈(π²/4)(1+log₂N)ln(1/δ)⌉` independent samples give exact order with probability at least `1−δ` by `(1−p)^t≤e^(−pt)`.

The gate route for modular order finding is conditional on a real arithmetic supplier. For `n=⌈log₂N⌉`, precompute constants `x^(2^j) mod N` by classical repeated squaring. Each `U_x^(2^j)` is multiplication by that constant, not `2^j` iterations of `U_x`. The proposed reversible circuit computes `az mod N` with schoolbook multiplication and long division, with explicit valid-residue handling, reversible embedding, inverse cleanup, and clean/dirty ancilla accounting. A conservative construction has `O(n²)` Toffoli/CNOT gates and `O(n²)` workspace per controlled modular multiplication; there are `m=O(n)` stages, yielding `O(n³)` arithmetic gates plus `O(n²)` QFT gates per QPE. This is a cost proof obligation for `alg-qa-modular-multiplication-circuit` and `thm-qa-modular-arithmetic-cost`; no published root or QC item currently supplies modular exponentiation circuitry or that gate bound. With `t=O(n(1+ln(1/δ)))` phase samples, order finding costs `O(n²(1+ln(1/δ)))` modular-multiplier calls, `O(n⁴(1+ln(1/δ)))` gates, and `O(n⁴(1+ln(1/δ)))` classical bit operations under schoolbook arithmetic: each sample uses a `2n+3`-bit numerator/denominator continued-fraction computation and, for a candidate, an `n`-bit modular exponentiation verification. If only bare controlled `U_x` access is supplied, the corresponding query bound is `t(Q−1)`, not polynomial in `n`.

## QA09 — Shor factoring

Input is a promised composite integer `N≥4`; output is a proper divisor, or `FAIL` after a declared finite repetition cap. If `N` is even, return 2. Detect a perfect power `N=a^e`, `e≥2`, by integer-root tests and return the proper factor `a`. For remaining odd composites, draw `a` uniformly from `1,…,N−1`; if `1<gcd(a,N)<N`, return that divisor, and otherwise `a` is a uniform unit modulo `N`. Run the bounded-error QA08 order finder with internal failure at most `1/4`. For the returned candidate order `r`, require it to be even, set `z=a^(r/2) mod N`, and compute `gcd(z−1,N)` and `gcd(z+1,N)`. Return a gcd only after checking it is strictly between 1 and `N`; otherwise repeat. Any incorrect or nonminimal order candidate can therefore cause only a missed attempt, never an incorrect factor.

For correctness of the conversion, an accepted period `q` satisfies `a^q≡1 mod N`; if q is even, then `z²≡1 mod N`. If `z` is neither `1` nor `−1` modulo `N`, the two gcds are proper nontrivial factors: each odd prime-power CRT component has `z≡1` or `−1`, and the two excluded global cases are exactly when all components choose the same sign. The classical reduction success route uses the published finite unit group/CRT decomposition. For `N=∏p_i^e_i` with `k≥2` distinct odd primes and uniform `a∈(Z/N)^×`, the `2`-adic valuations of the true component orders are independent; the failure case is that they all agree. For each component, each valuation class has probability at most `1/2`, so the probability that all agree is at most `2^{-(k−1)}`. Hence conversion succeeds with probability at least `1−2^{-(k−1)}≥1/2`. This is the local proof route behind Shor’s reduction.

An odd composite that survives the perfect-power test has at least two distinct prime factors. A uniform draw from `1,…,N−1` either immediately returns a proper gcd or, conditional on gcd one, is uniform in the unit group. The order finder succeeds with probability at least `3/4` for every unit; combined with the classical reduction bound this gives a factor on the unit branch with probability at least `3/8`. Including the immediate nonunit branch leaves per-attempt factor success at least `3/8`. Repeating `T=⌈ln(1/δ)/(-ln(5/8))⌉` attempts gives failure probability at most `δ`. Even and perfect-power cases are exact.

For input bit length `n`, even/perfect-power prechecks and Euclidean gcd use polynomial bit operations. One explicit perfect-power test loops over exponents `2,…,n`, uses binary search for each integer root, and compares by repeated squaring; schoolbook accounting gives the conservative bound `O(n⁵)` bit operations. Each order call at confidence `3/4` takes `O(n)` phase samples, each `O(n³)` gates and `O(n³)` verification bits; the factor conversion adds `O(n³)` bits. Therefore the conservative end-to-end upper bounds are `O(n⁴(1+ln(1/δ)))` gates, `O(n⁵+n⁴(1+ln(1/δ)))` classical bit operations, and `O(n²(1+ln(1/δ)))` calls to a controlled modular-multiplier primitive. The gate count combines the explicit finite reversible-arithmetic gate model with the ideal continuous exact-rotation QFT submodel; it gives no finite-alphabet compiler or uniform-family result. Under an explicit arithmetic circuit these multiplier calls are gates, so external black-box query count is zero. Under a bare controlled-unitary oracle the per-QPE cost becomes `Q−1`; no polynomial-time statement is made in that access model. The source citations’ more refined expected gate bounds are not imported because their arithmetic/gate-count details are not all proved in the local library.

## QA10 — Finite abelian hidden subgroup

Input is a finite abelian group in explicit invariant-factor coordinates `G=Z_(n1)×…×Z_(nd)`, a coherent hiding oracle `F` with `F(g)=F(h)` exactly when `g−h∈H`, and exact uniform-state, product-QFT, measurement, and oracle circuits. For `|G|=1` return `G` directly. Otherwise the procedure prepares the uniform state, evaluates `F` into an output register, discards the output (equivalently measures it), applies the normalized QFT over `G`, and records the sampled character. It repeats a fixed number of times and outputs the common-kernel presentation `K=∩ ker χ_j`. This is a concrete subgroup encoding; the algorithm does not pretend to have performed a free classical conversion to a list of generators. A separate generator-reconstruction extension would require an explicit Smith-normal-form bit-cost proof and is not a logical supplier here.

The sample-law proof writes each coset state as `|g+H⟩=|H|^-1/2Σ_{h∈H}|g+h⟩`. QA05's coset-transform theorem gives the normalized amplitude `sqrt(|H|/|G|) conjugate χ(g)=1/sqrt(|H^⊥|)` for `χ∈H^⊥` and zero outside; equivalently, the unnormalized indicator has coefficient `|H|/sqrt(|G|)`. Dual-character orthogonality and `|H||H^⊥|=|G|` therefore give the uniform measurement law. The reconstruction proof maintains `H⊆K`. If `K>H`, choose `g∈K\H`; nondegeneracy/double annihilator gives a character in `H^⊥` nontrivial on `g`. Among uniformly sampled characters of `H^⊥`, the restriction to `g` is a homomorphism with image size at least two, so the probability of a nontrivial value is at least `1/2`; such a sample reduces `K` by index at least two. Couple the successive cut indicators, until the process reaches `H`, from below by independent Bernoulli(1/2) variables using fresh uniforms. With `s=⌈log₂|G|⌉`, after `M=4s+16 ln(1/δ)` samples, the published independent-Bernoulli Chernoff bound gives probability at least `1−δ` of at least `s` cuts; if `H` was reached earlier, it remains reached. The output is always a common-kernel presentation containing `H`; “failure” means this presentation is strictly larger than `H`.

The query bound is exactly `M` coherent hiding-oracle evaluations. Gate cost is stated with access parameters: `M` times the cost of uniform preparation, coherent evaluation, product QFT, and measurement, plus `O(M log|G|)` bits to store the sampled characters. For invariant-factor coordinates and supplied uniform circuits and exact cyclic QFT circuits, a polynomial gate upper bound follows from those local suppliers; the HSP correctness theorem itself does not make arbitrary black-box function evaluation, QFT, or state preparation free. The classical implicit output has polynomial length. If users instead require generators for `H`, the local proof obligation must add the full construction and polynomial bit-complexity proof for the finite congruence system; the published Smith-normal-form termination proposition alone does not establish a polynomial bit bound.

Nonabelian scope: the finite abelian argument uses one-dimensional characters and annihilators. The cited notes describe information-theoretic query bounds for general finite groups but do not turn them into efficient postprocessing. No general polynomial-time nonabelian HSP algorithm or polynomial-time generic finite-abelian hidden-shift algorithm is claimed here.

## QA31 — Discrete logarithm, hidden shift, and number-theoretic extensions

The required discrete-log core is a finite cyclic group `G=⟨g⟩` of known order `q≥2`, with a unique fixed-length encoding, a reversible multiplication operation, identity, and an element `x`; the promised output is the unique `a∈{0,…,q−1}` with `g^a=x`. No efficient implementation is asserted for every abstract cyclic group. Form `F(u,v)=g^u x^v` on `Z_q×Z_q`; if `x=g^a`, its hidden subgroup is generated by `(-a,1)`. A finite-abelian Fourier sample is a uniform annihilator character `(c,d)` satisfying `d=ac mod q`. If `c` is a unit modulo `q`, compute `a=d c^{-1} mod q` using extended Euclid and verify `g^a=x`. A sample has success probability `φ(q)/q≥1/(1+log₂q)`; with `t=⌈(1+log₂q)ln(1/δ)⌉` independent samples, verification returns the exact answer with probability at least `1−δ`. Each sample uses one coherent `F` query; implementing `F` from a group-operation oracle takes `O(log q)` group multiplications by repeated squaring. The modular inverse, classical verification, QFT, uniform preparation, and controlled group-operation circuits have separate costs. If a multiplication circuit costs `C_G` gates and supplied cyclic QFT/uniform preparation cost `O(log²q)`, total gates are `O((log²q C_G+log³q)(1+ln(1/δ)))`; group-operation queries are `O(log²q(1+ln(1/δ)))`, while direct function-oracle queries are `O(log q(1+ln(1/δ)))`. If group operation bit-time is `T_G` on the encoding, classical costs are `O((log²q T_G+log⁴q)(1+ln(1/δ)))`: the O(log q) sample count multiplies O(log q·T_G) group operations and O(log³q) schoolbook extended-Euclid work per sample. The bit/gate claim is polynomial only when the encoding and operation circuit are efficiently supplied.

For a finite abelian hidden-shift instance, require injective functions `f,g:A→S` and a unique `s∈A` such that `f(a)=g(a+s)`. Define `D_A=A⋊Z₂` with `(a,b)(a',b')=(a+(-1)^b a',b+b')` and `F(a,0)=f(a)`, `F(a,1)=g(a)`. Right multiplication by `(s,1)` pairs `(a,0)` with `(a+s,1)`; injectivity and the shift condition show that these are exactly the equal-value pairs. Thus `F` hides the reflection subgroup `⟨(s,1)⟩`, giving a fully specified reduction to generalized-dihedral HSP. The direct reduction proof is local and does not depend on a classical extraction being free.

Kuperberg’s Theorems 1.1 and 3.1 give a subexponential sieve for `D_(2^n)`: `O(8^{√n})` quantum queries and `~O(8^{√n})` computation time, with comparable exponential-in-√n quantum space, hence `2^{O(√log N)}` in the group size. The source gives the full power-of-two list-size/Chernoff argument, but the machine inventory specifies a local final-width variant: set `m=⌈√(n−1)⌉` once for the original exponent and retain it through recursion; at modulus `2^r`, take `t_r=⌈(r−1)/m⌉` and matching widths `w_j=min(m,r−1−mj)` for `0≤j<t_r`, so the widths sum exactly to `r−1` without overshooting the parity label. Its proof must check that the source’s list-size recurrence and per-sieve bound continue to hold for that shortened final matching width, then union-bound the at most `n` recursive stages; it must also state the circuit/query model. The machine theorem remains a draft proof obligation, not an active library result. The paper’s general-`N` algorithm is proved only by outline and its arbitrary finitely generated abelian hidden-shift theorem is sketched; these remain extension obligations. The work is subexponential, not polynomial. Lattice/number-field applications and the cited number-field/Pell discussion are contextual only unless their representation, arithmetic, and classical output procedures are separately proved.

Elliptic-curve discrete logarithm is an optional extension and is excluded from the core item dependencies and cost claims. Proos–Zalka gives the two-dimensional Fourier algorithm and explicit point-addition formulas, but directs associativity to an external algebraic-geometry proof; Childs also says its associativity proof is omitted. No elliptic-curve group-law supplier currently exists in the audited root plan. If the extension is later authored, it needs a local proof of the nonsingular cubic’s identity/inverse/chord-tangent law and associativity, explicit field/point encodings, reversible group addition and inversion, subgroup-order hypotheses, and bit/gate cost proof. The article’s appendix sketches rather than fully supplies all success details. This omitted branch is an authoring obligation, not an open mathematical problem.
