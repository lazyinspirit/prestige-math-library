## Pair carriers and proofs

- `alg-bagged-random-forest` — A, level 3. Defines the fixed-data bootstrap count law, independent nodewise feature subsets, finite CART growth, class/regression aggregation, and OOB availability. It includes an explicitly explained TikZ data-flow diagram; no proof relies on it.
- `thm-infinite-forest-vote-limit` — A, level 4. For each fixed test pair, applies the IID strong law to each of finitely many class indicators. Strictly positive or negative margin forces eventual finite-vote decisions. Fubini transfers randomization-a.e. convergence to test-a.e. convergence for almost every sequence; dominated convergence yields the conditional-risk limit. Zero-margin mass is excluded exactly as required.
- `thm-random-forest-strength-correlation-bound` — A, level 4. Identifies the independent raw-margin covariance average with `Var_P(m)`, bounds raw-margin variance by `1-s^2` using Cauchy–Schwarz, applies Chebyshev, and proves the `d=0` branch directly.
- `thm-regression-forest-risk-under-unbiased-randomized-trees` — A, level 4. Centers each residual under the per-tree unbiasedness condition, expands forest risk using an independent randomization pair and Fubini, bounds `d^2` by tree risk, and proves the `d=0` branch directly.
- `ex-random-forest-zero-margin-vote-limit` — B, level 5. For `D=(((0,1),0),((1,0),1))` and a point-mass test pair, mixed bootstraps split in opposite feature directions; exact class-1 probability is `1/2`. For odd `B`, symmetry gives expected finite-forest conditional risk `1/2`; bounded dominated convergence rules out almost-sure convergence to strict-margin risk zero. The two possible CART splits are shown by TikZ; the proof recomputes their outputs and does not rely on the diagram.
- `ex-random-forest-out-of-bag-diagnostic` — B, level 4. With two observations and two depth-zero trees, the event of pure opposite bootstrap samples has probability `1/16`; the full forest tie returns class 0 while the OOB rule for observation 1 returns class 1.
- `ex-random-forest-strength-correlation-tradeoff` — B, level 5. The two-point test law gives `s=1/4`, `PE*=1/4`, `d^2=3/4`, expected covariance `3/16`, `rho=1/4`, and bound `15/4`. All arithmetic is checked in the local verification.
