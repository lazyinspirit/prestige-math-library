Run `node research/non-ml-math-remaining-81-2026-10-18-owner-step5-actual-work-admission-requests/prepare.mjs` from any working directory. It binds all original 81 report/stable/immutable native inputs, all current 81 manifests, exact root scientific records, full unchanged current before archives and actual proposed sources. It fails on source/read-record/initial/baseline drift or inputs changing during generation.

DMC/MAC dates normalize their actual recorded root confirmation time; no new reading time is invented. `missing-explicit-root-fields.json` lists the remaining individual native correspondence fields and independent root classifications. These fields were not inferred from scientific confirmation or original native severity.

The proposed text has pending-root language and is not itself confirmation. Then `prepare.mjs --root-completion research/ACTUAL_ROOT_RECORD.json` emits the ROOT-CONFIRMED request; ordinary recorder validation and actual paused/drained boundary remain mandatory. Request generation time is actual generation time, never a reading claim. Refresh every current manifest binding after any later metadata change.
