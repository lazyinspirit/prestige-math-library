## Definition

Let $(\mathcal X,\Sigma)$ be a measurable instance space, equip $\{0,1\}$ with its full discrete sigma-algebra $2^{\{0,1\}}$, and let $\mathcal Z=\mathcal X\times\{0,1\}$ carry the product sigma-algebra $\Sigma\otimes 2^{\{0,1\}}$. Let $\mathcal H$ be a nonempty class of measurable functions $c:\mathcal X\to\{0,1\}$. For $d\in\mathbb N$, a **deterministic sample-compression scheme of size at most $d$** consists of a compression map $\kappa_m$ for each sample length $m\in\mathbb N$ and fixed reconstruction maps $G_k$ for $0\le k\le d$. On any length-$m$ labeled sequence $S=(z_1,\ldots,z_m)$ consistent with some $c\in\mathcal H$, $\kappa_m(S)$ returns an index subset $I\subseteq[m]$ with $|I|\le d$. For each $1\le k\le d$, $G_k:\mathcal Z^k\times\mathcal X\to\{0,1\}$ is jointly measurable, and $G_0:\mathcal X\to\{0,1\}$ is measurable. If $I=\{i_1<\cdots<i_k\}$, write $S_I=(z_{i_1},\ldots,z_{i_k})$ and define the reconstructed classifier by $g(S_I)(x):=G_k(S_I,x)$; for $I=\varnothing$, use $G_0$.

The scheme is **consistent** if, for every $c\in\mathcal H$, every $m\in\mathbb N$, and every $S=((x_1,c(x_1)),\ldots,(x_m,c(x_m)))$, writing $I=\kappa_m(S)$ gives $g(S_I)(x_j)=c(x_j)$ for all $j\in[m]$. The reconstruction map uses only the ordered selected labeled entries and no other side information; the reconstructed classifier need not belong to $\mathcal H$.
