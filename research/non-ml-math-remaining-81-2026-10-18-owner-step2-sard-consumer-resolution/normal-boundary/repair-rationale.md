## Empty bundles: the actual definitions used

The library explicitly allows the empty space as an `n`-manifold for every **nonnegative** `n`. The empty map `∅→∅` is a smooth surjection, and the empty open cover gives smooth local trivializations with any specified finite model fibre `R^r`. The fibre-dimension conditions are vacuous. Thus a fixed rank `r` supplied by the target bundle may be retained over an empty pullback; rank is not claimed uniquely determined by empty fibres.

The pullback set along `∅→B` is literally empty. The normal-bundle set is a coproduct of tangent quotients over its base; over the empty base it is literally empty as well. Their unique map and its inverse are smooth bundle maps over the empty identity, with all fibre-linear conditions vacuous. For expected dimension `n−r≥0`, the empty preimage can have that dimension. For `r>n`, the proposals use the empty zero-dimensional structure and the empty quotient set with the specified rank-`r` bundle model; they make no codimension-`r` claim. No quotient theorem with a negative rank is applied.

The Thom definitions also explicitly give `Th(0_B)=B_+`, and for an empty base the Thom space consists of its quotient basepoint while its zero-section image is empty. Both cases remain covered. At nonempty rank-zero fibres the normal isomorphism is simply the map between zero bundles.

## Downstream interface changes for the parent

1. A consumer asserting the expected preimage dimension/codimension must establish the codimension bound, or work at an actual point (whose normal-surjection rank bound establishes it). A consumer with excessive codimension obtains an empty set, not a negative-dimensional embedded object.
2. A consumer using only the pulled-back normal-bundle isomorphism retains the all-rank statement, including an empty normal structure. Over an empty base it must not infer an ambient dimension equation from the rank of that empty bundle.
3. Boundary consumers keep the same neatness, tangent, boundary identity and normal restriction in the nonempty/allowed-dimensional cases; `r=n` misses the boundary. The empty cases carry the corresponding unique empty restriction map. No existing corner domain was removed, and no new corner/stratum-transversality theorem is added: these three current carriers concern manifolds with boundary, as the parent confirmed.
4. No broader choice hypothesis is introduced. The boundary slice construction remains choice-free. The stated countable-choice assumption on the normal constructions is retained with its existing normal-bundle use.
