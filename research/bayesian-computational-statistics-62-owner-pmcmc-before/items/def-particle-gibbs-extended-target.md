## Definition

Use the finite-horizon state path model and proposal support conditions in
[[def-feynman-kac-path-targets-and-normalizers]],
[[thm-feynman-kac-path-radon-nikodym-weight]], and
[[alg-sequential-importance-resampling]]. Let $\pi_0$ be a proper parameter
prior, $\gamma_{\theta,T}$ the Feynman–Kac path measure at parameter $\theta$,
$L_\theta=\gamma_{\theta,T}(1)$, with $0<L_\theta<\infty$ for
$\pi_0$-almost every $\theta$, and
$$C=\int L_\theta\,\pi_0(d\theta),\qquad 0<C<\infty.$$
For a fixed particle count $N\ge2$, write
$$U=(X_0^{1:N},A_1^{1:N},X_1^{1:N},\ldots,A_T^{1:N},X_T^{1:N})$$
for the full particle system and ancestor indices generated by
[[alg-sequential-importance-resampling]]. Its forward probability law at
parameter $\theta$ is $\psi_\theta(du)$. The algorithm defines the product
normalizer estimate $\widehat Z_T(U)$ and final normalized weights
$W_T^1(U),\ldots,W_T^N(U)$; $K$ is a terminal particle index. The path
$X_{0:T}^{K}$ means the states on the ancestral lineage of particle $K$,
traced through the arrays $A_1^{1:N},\ldots,A_T^{1:N}$.

More explicitly, relative to counting measure on ancestor arrays and the
ordered SIR proposal-kernel integrals for the states,
$$\psi_\theta(du)=\prod_{i=1}^N\nu_{\theta,0}(dx_0^i)\prod_{t=1}^T\prod_{i=1}^N\left[W_{t-1}^{A_t^i}(U)R_{\theta,t}(X_{t-1}^{A_t^i},dx_t^i)\right].$$
Each factor $W_{t-1}^{A_t^i}(U)$ is the categorical mass of that ancestor
choice; no state transition density is assumed for the genealogical variant.

The genealogical particle Gibbs extended target is the measure
$$\varphi_N(d\theta,du,k)=C^{-1}\pi_0(d\theta)\,\psi_\theta(du)\,\widehat Z_T(u)W_T^k(u),\qquad k\in\{1,\ldots,N\}.$$
The selected state is $(\theta,X_{0:T}^{K})$. The zero-weight fallback in the
particle algorithm defines $W_T$ everywhere; when $\widehat Z_T=0$ the extended
target assigns the configuration zero mass.

The measure is a probability and has the exact joint smoothing posterior as
its selected $(\theta,X_{0:T}^{K})$ marginal by
[[thm-particle-gibbs-selected-path-marginal]].
