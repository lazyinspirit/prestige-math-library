# Evidence draft: a bounded §5 arithmetic and internal-size radius

This audits only the §5 facts needed in the local reconstruction of Malliaris–Shelah Claim 8.2. It does **not** certify all of §5, Corollary 5.7, Theorem 8.5, or `p=t`. Primary source: [Malliaris–Shelah, *Cofinality Spectrum Theorems*](https://math.uchicago.edu/~mem/Malliaris-Shelah-CST-new.pdf), Definitions 2.3/2.11 (printed pp. 9–12), Convention 5.1 and Lemma 5.3 through Convention 5.16 (pp. 20–24), and Claim 8.2 (pp. 30–31). ## Normalize the formulas before using them

Fix a nontrivial `a∈Or(s)` whose pair product `c=a×a` is nontrivial (Definition 2.3(5)–(6)); later applications may choose `a` coverable as a pair. The local ESTT statement must explicitly include the empty node and all standard finite concatenations in `T_a,T_c`: the printed closure clause (7)(c)(i) only extends an existing node, while the paper uses finite nodes throughout. Use an **exclusive** sequence length: a node of length `S(k)` has coordinates `0,…,k`. This agrees with the evaluation and concatenation clauses of Definition 2.3(7), although its printed clause (7)(b)(ii) calls `lg` the maximum of the domain. The source's printed addition formula uses length `y` and last index `y−1`, which computes `x+y−1` for positive `y`; normalize it to

`Add(x,y,z) :⇔ ∃η∈T_a [lg(η)=S(y) ∧ η(0)=x ∧ η(y)=z ∧ ∀i<y (η(S(i))=S(η(i)))]`.

For `y=0`, the one-point node witnesses `z=x`. Define `Double(x,z):⇔Add(x,x,z)`. Define `Iter₂(k,x,z)` by a node `η∈T_a` of length `S(k)` with `η(0)=x`, `η(k)=z`, and `Double(η(i),η(S(i)))` for each `i<k`. Every displayed quantifier is first-order over `M_1^+`; `y,k` must be below the tree-length ceiling for the formulas to apply. We make no assertion that `Double:X_a→X_a` is total on the whole pseudofinite order: it cannot be ordinary doubling at its last point. Multiplication and exponentiation in the printed Lemma 5.3 likewise need zero cases and output variables checked; Claim 8.2 requires only the corrected doubling/iteration fragment.

For bounded intervals `I=[u,v)_a`, write `|I|≤_s|J|` **exactly** as Convention 5.1 does: an existential node in the pair tree `Par(a,a)⊆T_c` whose graph is injective, whose domain includes every point of `I`, and whose range lies in `J`. Write `<_s` for this direction together with negation of the reverse coded injection. The source supplies no general permission to turn an arbitrary *external* injection into a `Par` node. For a **standard finite** interval, however, an explicit finite list of pairs is a `Par` node: Definition 2.3(7)'s one-step concatenation builds it in finitely many steps, and `d_c` is above every standard finite length.

## One first-order safe-radius formula

Let `R(w)` be the finite conjunction of the following first-order assertions, with all `x,y,u,v,u',v',k` quantified over `X_a` and bounded by `w` where shown. Its terms are predicates just defined, not an appeal to all standard natural numbers inside the language.

1. **Margin and deterministic arithmetic.** For every `k≤w`, there is a successor-iteration node from `w` of length `S(k)` whose last value is `<d_a`; thus `w` has an internal margin through `w` steps. Require `∀x,k≤w ∃!z∈X_a Iter₂(k,x,z)` and `∀x,y≤w ∀z,z′∈X_a (Add(x,y,z)∧Add(x,y,z′)⇒z=z′)`. State the exact bounded order laws as `∀x<y≤w ∀k≤w ∀z,z′≤w [(Iter₂(k,x,z)∧Iter₂(k,y,z′))⇒z<z′]` and `∀x,y≤w ∀k<w ∀v,z≤w [(Double(x,v)∧v<y∧Iter₂(k,y,z))⇒∃z′≤w (Iter₂(S(k),x,z′)∧z′<z)]`. Also require `∀x<w Add(x,1,S(x))`. All unbounded output variables in the definitions range over `X_a`; a bound `≤w` is asserted only where the displayed implication needs it. These are finite first-order clauses, not a claim that all outputs stay within `[0,w]`.
2. **Coded finite pigeonhole on intervals.** For all `x<y≤w`, `|[0,x)|<_s|[0,y)|`. More generally, for all `u≤v≤w` and `u'≤v'≤w`, if corrected `Add` computations witness lengths `r=v−u`, `r'=v'−u'` with `r<r'≤w`, then `|[u,v)|<_s|[u',v')|`. The forward code for a standard interval pair is the finite translation list; the reverse code cannot exist by ordinary finite pigeonhole. No closure of arbitrary nonstandard `Par` codes under surgery is assumed.
3. **A bounded growth-chain law.** For all `1≤x≤w`, `k≤w`, and `z≤w`, if `Iter₂(S(k),x,z)`, there exists a node `h∈T_a` of length `S(k)` such that `h(0)=x`, `h(S(i))=S(2h(i))` for `i<k`, every `h(i)≤w`, and `h(k)<z`. Read `2h(i)` through the unique `Double` graph. Externally, for standard inputs the recurrence gives `h(j)=2^j(x+1)−1<2^{j+1}x=z` at `j=k` when `x≥1`; the sequence is built by finitely many concatenations. This one uniform implication is what the Claim 8.2 limit step needs; it does not claim every nonstandard arithmetic computation exists.

For each **standard finite successor** `w=S^n(0_a)`, every element at most `w` is one of the first `n+1` successors. All quantified arithmetic inputs and interval endpoints in `R(w)` are therefore standard finite. Corrected `Add`/`Double`/`Iter₂` witnesses and the finite translation graphs exist by finitely many applications of tree concatenation; any witness to a reverse injection between unequal standard finite intervals would be an actual injection of larger finite set into smaller, impossible externally. The familiar finite arithmetic inequalities establish the remaining clauses. Thus `M_1^+⊨R(S^n(0_a))` for every standard `n`.

The set `{w∈X_a:R(w)}` is definable and contains every standard successor of `0_a`. Pseudofiniteness gives it a greatest point `w_*`; this point cannot be a standard successor, since its next standard successor also satisfies `R`. Thus `w_*` is nonstandard and `R(w_*)` holds. This is the same bounded-overspill pattern used in Lemma 5.3/Claim 5.14, but with the **needed finite pigeonhole and calculation laws included in the single formula**. It avoids claiming that arbitrary pseudofinite intervals throughout `X_a` obey full arithmetic or full internal cardinality.

## Exact use and boundary

Restrict the Claim 8.2 tree predicate to values `≤w_*`. Standard finite successors give its base finite chains. If a node value `u>0` and every standard iterate `2^{k+1}u` lies below a later bound `d_∞≤w_*`, clause 3 yields, for each standard `k`, a `k`-step chain `u=h(0)<h(1)<⋯<h(k)≤w_*` with `2h(i)<h(i+1)`. Clause 2 turns each order increase into strict internally coded interval-size growth. Clause 1 justifies comparing the iterates that occur in the limit-stage `m_k` predicate. The successor-stage countable `Or`-type and the index pre-cut still require Theorem 4.2 and Lemma 2.15, as detailed in [the Claim 8.2 addendum](frontier-35-pt-csp-claim-8-2-primary-audit-addendum.md). No total doubling on all of `X_a` is used.

This gives a locally authorable **bounded** arithmetic/PHP route for Claim 8.2, conditional on the standard finite-node clause just named, writing the single formula `R` in the repository's exclusive-length convention, and checking it against the actual `Par(a,a)` code definition. It does not prove the full §5 coding bridge. The first unverified general source step is Lemma 5.3's uniform prime/Gödel coding of every `T_a` node into a larger `X_b`; later Corollary 5.7's uniform representation of bounded pair-valued function graphs inside its chosen cover `X_d`, and closure of those codes under restriction/composition, also remain open. Lemma 5.3's displayed arithmetic formula and Lemma 5.11's multiplication display cannot be copied literally; their corrections and the prime-code/bounded-radius construction need a separate full proof to support Theorem 8.5's six-coordinate tree. This draft establishes no selected local supplier and changes no scope, plan, manifest, receipt, or engine state.
