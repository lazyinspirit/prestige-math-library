## Definition

Inputs are a transcription record from [[alg-ctrl1-runge-kutta-shooting-and-collocation-transcription]], a primal initial iterate $z_0$ and multiplier iterate $\mu_0$, an optional strict primal/slack/dual start in canonical QP coordinates, an SQP model builder, and finite nonnegative tolerances $\tau_p,\tau_d,\tau_c,\tau_{stage},\tau_{quad}$. The stage and quadrature tolerances must match those bound into the transcription record. Also supply an SQP update cap $K\ge0$, QP update cap $N\ge0$, positive penalty/backtracking caps $R,J_{max}\ge1$, merit parameters $\rho_0>0$, $\gamma>1$, $0<\beta,\sigma<1$, and the finite-budget exact-Hessian branch selector and identified active set when that branch is requested. The IVP estimator uses its own declared controller tolerances; its status is not treated as an error certificate.

The SQP model builder is a deterministic finite procedure which, at each queried $z_k$, returns either a failure status or the finite NLP data $f_k,h_k,g_k,Dh_k,Dg_k$, its objective gradient, a symmetric positive-definite SQP model matrix $W_k$, and the exact Lagrangian Hessian when the exact-Hessian branch is selected. It must use $g_i\le0$ and nonnegative inequality multipliers. The associated quadratic subproblem is exactly $\min_p \nabla f_k^Tp+\tfrac12p^TW_kp$ subject to $h_k+Dh_kp=0$ and $g_k+Dg_kp\le0$. The builder also supplies the active equality/inequality row data required by [[alg-sqp-merit-globalization-with-finite-budgets]]. Solver tolerances are used as follows: $\tau_p$ bounds the norm of equality and positive inequality violations, $\tau_d$ bounds the stationarity residual, and $\tau_c$ bounds multiplier-feasibility and complementarity residuals. The stage and quadrature tolerances are passed to the transcription's corresponding residual and certified-error checks. The IVP estimator uses its own declared controller tolerances and has a separate status; its embedded difference is not a certified error bound. Any called builder, evaluator, canonicalizer, or solver returns a value or failure status in finite time.

First audit the transcription dimensions, sampled domains, and data status fields. If stage construction failed, return the partial record with its stage and NLP statuses and do not call a solver. If the model satisfies [[lem-ctrl1-lqr-transcription-is-a-convex-quadratic-program]], map its finite quadratic objective and affine constraints to canonical LP/QP form: replace each free variable $z_i$ by $z_i^+-z_i^-$ with $z_i^+,z_i^-\ge0$; for each affine inequality $a_i^Tz+d_i\le0$, add a slack $s_i\ge0$ and equality $a_i^Tz+s_i=-d_i$; retain existing equalities; and transform the quadratic objective by substitution. The transcription record supplies finite stored coefficient arrays. Canonicalize using exact rational arithmetic on their dyadic values, then round each resulting coefficient once to the nearest normal representable value under [[def-operationwise-real-complex-floating-point-model-with-sqrt-and-fma]], preserving exact zeros; any range failure makes the QP route inapplicable. Check the resulting equality matrix by exact rational row elimination; if it is rank deficient or the conversion is otherwise inadmissible, mark the QP route inapplicable and proceed to SQP. The optional start is in these converted coordinates and is checked constructively: require the primal and slack coordinates strictly positive and a finite dual vector of the right dimension. If it is absent or fails this check, record `strict-start-unavailable` and proceed to SQP; do not infer infeasibility or decide whether some other strict start exists. If it passes, call [[alg-primal-dual-newton-residual-method-for-lp-qps-and-symmetric-cones]] once with tolerances $\tau_p,\tau_d,\tau_c$ and cap $N$. If it returns `invalid-input` or `strict-start-unavailable`, record that QP status and proceed to SQP. Return every other status and audited residuals. `certified-gap` certifies the resulting stored canonical floating-point QP, interpreted as exact dyadic rationals, under [[thm-fraction-to-boundary-and-primal-dual-gap-certificates]]; it is not a certificate for the unsampled continuous problem. A `residual-candidate` remains a candidate. No other QP status is reinterpreted as success.

If the QP route is inapplicable or lacks a supplied strict start, run the SQP branch only when the transcription status is solver-ready `constructed`; otherwise return its `not-smooth-nlp` or model-construction status without an SQP call. For $k=0,1,\ldots,K$, in order, evaluate the model builder at the current iterate, compute
$$r_p=(h_k,[g_k]_+),\quad r_d=\nabla f_k+Dh_k^T\nu_k+Dg_k^T\lambda_k,\quad r_\lambda=[-\lambda_k]_+,\quad r_c=(\lambda_{k,i}g_{k,i})_i,$$
where positive parts are componentwise. If $\|r_p\|\le\tau_p$, $\|r_d\|\le\tau_d$, $\|r_\lambda\|\le\tau_c$, and $\|r_c\|\le\tau_c$, return `kkt-residual-met` with the current decision and residual record; this is an approximate KKT candidate unless all residuals are exactly zero. If $k=K$, return `budget-exhausted`. Otherwise, if the exact-Hessian branch is selected and an active set has been identified, call [[alg-sqp-exact-hessian-newton-step]] and update to its returned full Newton pair; any failure stops with that status. In the merit branch, call [[alg-sqp-merit-globalization-with-finite-budgets]] with $W_k$, $\rho_0,\gamma,\beta,\sigma,R,J_{max}$. An `accepted` or `accepted-soc` result updates the primal iterate and multipliers from its returned QP multipliers; any other status stops the loop. The exact-Hessian local branch has only the conditional convergence guarantee in [[thm-sqp-exact-hessian-local-quadratic-convergence]].

Every return is a result record with the last available decision variables, defect residuals, path/endpoint constraint residuals, KKT residuals, objective value, and separate `nlp_status`, `implicit_stage_status`, `ivp_status`, `quadrature_status`, `mesh_status`, and `budget_status` fields. Fields not reached are marked `not-run`; failed evaluations carry their failure status and do not supply a candidate value. The finite caps bound the procedure. It does not guarantee a start, solver success, a global solution of a nonconvex problem, continuous-path feasibility from sampled constraints, or a certified approximation error for the continuous ODE problem.
