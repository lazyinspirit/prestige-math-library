## 2. The line I drew, and why

Nearly every rejection in this sweep belongs to one class: a step tags `[F1]`
when the move is licensed by `[F3]`, or a fact restates only part of its source.
The owner's step-8 framing is a dichotomy — an *inflated* restatement is fatal,
a *faithful* fact needing 30 seconds of reader work is not — so the whole
adjudication turns on where "inflated" begins. I applied this and state it here
so the reasoning is recoverable and can be overruled:

**Fatal** when the item contains a false claim; when a proof step is invalid or
its constructed witness does not work; or when a fact's extra strength over its
source is itself false, or unavailable in the library, and the proof leans on it.

**Nonfatal** when the fact is true and either published in the library or
derivable in seconds from what the item already carries, and the only defect is
that the pointer is imprecise — a missing step tag, a partial restatement whose
source carries the omitted clause, an uncited definitional unfolding, a dropped
side condition that is visibly satisfied where it is used.

The test I applied at the boundary: **would a reader be led to believe something
false?** A wrong internal justification for a true claim fails that test and is
nonfatal; a sentence whose plain reading is false passes it and is fatal. The
owner's "even when the underlying mathematics is true" clause targets the case
where the inflation *manufactures* the licence — where the proof would not close
on the true statement. Where the true statement plus a published sibling closes
it immediately, the proof does close and only the pointer is wrong.

I am aware this reading closes 109 rows without an edit. Section 6 lists, by id,
every nonfatal finding that is nevertheless a real quality defect, so that R1
buys a stable text without also burying what should have been caught at step 6.

### 3.1 `def-path-polygonal-length-and-rectifiability-in-rn` — Terra, `other`

**Terra:** "The singleton clause incorrectly calls there being a unique path on
`[a,a]`. There are infinitely many continuous maps from a singleton to `R^n`."

**Confirmed.** The clause read *"On a singleton interval $[a,a]$, define
$L_{[a,a]}(\gamma):=0$ and call the unique path rectifiable."* There is one path
on $[a,a]$ for each point of $\mathbb R^n$, so the definition asserted a false
uniqueness. This is not a gap a reader closes — the sentence says something
false, in a `landmark` definition, and the same wrong idea propagated into
§3.3's Statement, which is independent evidence that it was a real error and not
a slip of phrasing.

**Repair.** The clause now reads *"…and call every path with that domain
rectifiable. There is one such path for each point of $\mathbb R^n$, namely the
map sending $a$ to that point."* The convention it defines — $L_{[a,a]}=0$, every
such path rectifiable — is unchanged, which is why all ten consumers that quote
it stay licensed (§7).

### 3.2 `thm-rectifiable-iff-coordinate-functions-have-bounded-variation` — Terra **and** DeepSeek, `other`

**Terra:** the Statement uses $\gamma_1,\ldots,\gamma_n$ and $\max_{1\le j\le n}$
where the library indexes $\mathbb R^n$ by $0..n-1$, so $\gamma_n$ is undefined
and $\gamma_0$ omitted; at $n=1$ it names the nonexistent $\gamma_1$.
**DeepSeek:** the proof uses $e_j$ for $j=1..n$ while the cited definition
supplies $e_i$ only for $i<n$.

**Confirmed — I checked the convention on disk first, as instructed.** It is not
a matter of taste in this library: `def-euclidean-inner-product` defines
$\mathbb R^n$ as the function space on the von Neumann natural $n$ and writes
"$x_k := x(k)$ for $k<n$"; `lem-standard-basis-of-f-n` defines $e_i$ for $i<n$ and
states in its own Statement "**Every index runs from $0$**, so the coordinates of
an element of $F^{n}$ are $x_0,\dots,x_{n-1}$". So $\gamma_j(t)=\gamma(t)(j)$ is
undefined at $j=n$, and the Statement's display summed over exactly that index.
This is the only item in the run that writes an explicit index range for
$\mathbb R^n$ coordinates, so the defect is isolated and mechanical.

**Repair.** Coordinates re-based to $j<n$ in the Statement (with the coordinate
convention named and linked to `def-euclidean-inner-product`, already a
dependency), in `[L1]`, and in step 1.2. The proposition, both displayed bounds
and the proof are otherwise untouched; all three consumers restate the criterion
without an index range, so none moves.

### 3.3 `thm-arc-length-is-invariant-under-monotone-reparametrization` — DeepSeek, `logic`

**DeepSeek:** "The statement's claim about the singleton case is false: if the
target interval is a singleton, the domain interval need not be; a constant map
on a non-singleton interval is continuous surjective monotone."

**Confirmed.** The clause read *"If one parameter interval is a singleton,
surjectivity forces the other image interval to be a singleton and both lengths
are zero."* Read over the unordered pair, as "one … the other" requires, it
asserts both directions and one of them is false: $\varphi\equiv a$ on $[0,1]$ is
continuous, surjective onto $[a,a]$ and monotone, with a nondegenerate domain.
Terra passed this item.

The theorem's displayed equality is true and proved. But the proof's step 3.1
discharged "the singleton case" from the singleton *convention* alone, which does
not cover $a=b$ with $c<d$ — there $L_{[c,d]}(\gamma\circ\varphi)$ is a genuine
supremum over partitions, not a convention. So the false clause was covering a
real hole in the case analysis.

**Repair.** The clause now states the true implication in each direction and
names the constant-map witness. Step 3.1 now discharges $c=d$ from the convention
and $a=b<c<d$ from the vanishing of every polygonal sum of a constant path. The
displayed equality is unchanged, so
`thm-every-rectifiable-path-has-an-arc-length-parametrization`, its one consumer,
is strictly better licensed than before: its step 4.1 applies the theorem to
$s|_{[u,v]}:[u,v]\to[r,q]$ including $r=q$ with $u<v$, which is exactly the case
the old clause got wrong.

### 3.4 `thm-extremal-graph-supersaturation` — DeepSeek, `logic`

**DeepSeek:** "In the case $\pi(H)+\varepsilon>1$ the proof sets $N=1$ and
$\delta=1$, but for $n=1$ the hypothesis $e(G)\ge(\pi(H)+\varepsilon)\cdot0$ holds
while the graph contains 0 embeddings of $H$ (since $h\ge2$)."

**Confirmed, and it is exactly right.** Step 1.1 read "take $\delta=1$ and $N=1$;
no graph satisfies the edge hypothesis." At $n=1$, $\binom12=0$, so the hypothesis
$e(G)\ge(\pi(H)+\varepsilon)\binom n2$ holds vacuously for the one-vertex graph,
while the conclusion demands $\delta n^h=1$ injective embedding of an $h\ge2$
vertex $H$ into it. The sentence "no graph satisfies the edge hypothesis" is
false and the constructed witness $(\delta,N)=(1,1)$ does not work — an invalid
witness, not a citation quirk. Terra passed this item. The theorem itself is
true; only the constants are wrong.

**Repair.** The branch now takes $N=2$ and derives the impossibility from
$\binom n2\ge1$ for $n\ge2$, and records why the threshold cannot be lowered to
$1$. The Statement is unchanged and no consumer moves.

### batch 4 — `the-determinant-of-a-linear-operator` (+ examples)

The five-item cluster the dispatch asked me to look at hardest is one issue:
both lanes read `\det(T):=\det([T]_{\mathcal B})` as fixing one basis, which makes
