## Definition

**Inputs:** a finite episodic MDP with nonempty finite state set $S$, finite nonempty action sets $A(s)$, finite reward set $\mathcal R$, joint transition-reward law $p$, terminal set $S_\dagger\subseteq S$, and initial state $s_0\in S$; a discount $0\le\gamma<1$; a differentiable stationary policy family $\pi_\theta$ with fixed positive support on an open set $U\subseteq\mathbb R^d$; a value approximation $\widehat V_w:S\to\mathbb R$ differentiable in $w$ on an open set $W\subseteq\mathbb R^m$; initial parameters $(\theta_0,w_0)\in U\times W$; and step sizes $\alpha,\beta\ge0$.

**Admissible conditions:** assume AC for the adaptive episode law; every proposed actor and critic update remains in $U$ and $W$, respectively, and the episode generated by this procedure, including its within-episode parameter updates, reaches $S_\dagger$ after finitely many transitions almost surely.

For the sampling instruction, condition on the complete finite transition history and use the current parameters computed from that history. The successive-draw law uses these history-dependent kernels on discrete transition-record spaces, with a fixed stop symbol padding the records after termination.

**Output:** the final actor and critic parameters $(\theta_{\mathrm{out}},w_{\mathrm{out}})$ after one episode.

Set $(\theta,w)=(\theta_0,w_0)$, $S=s_0$, and $I=1$. If $S\in S_\dagger$, return $(\theta_0,w_0)$. Otherwise, while $S\notin S_\dagger$, using the current pre-update parameters $(\theta,w)$:

1. Sample $A\sim\pi_\theta(\cdot\mid S)$ and then sample $(S',R)$ with joint law $p(S',R\mid S,A)$.
2. Set $C=0$ if $S'\in S_\dagger$ and $C=\widehat V_w(S')$ otherwise. Compute the temporal-difference error $\delta=R+\gamma C-\widehat V_w(S)$.
3. Compute both updates from these pre-update parameters: $\theta'=\theta+\alpha I\delta\nabla_\theta\log\pi_\theta(A\mid S)$ and $w'=w+\beta\delta\nabla_w\widehat V_w(S)$. Replace $(\theta,w)$ by $(\theta',w')$.
4. Set $I\leftarrow\gamma I$ and $S\leftarrow S'$.

When the loop ends, return the current $(\theta,w)$ as $(\theta_{\mathrm{out}},w_{\mathrm{out}})$.

The critic uses a one-step bootstrapped target; the actor uses the current TD error and the accumulated start-state discount $I=\gamma^t$. The procedure itself asserts no convergence result.

## Remarks

Replacing the full Monte Carlo return by a bootstrapped critic target can change the expected actor direction when the critic is inaccurate. This definition supplies no convergence guarantee for tabular, nonlinear, or deep function approximation.
