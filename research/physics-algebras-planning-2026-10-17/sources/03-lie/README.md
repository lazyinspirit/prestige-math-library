# Lie-theory source set

This folder holds the Lie/representation-theory source material used for the associated dossier, dossiers/03-lie.md. Its **Source-reading manifest** is the exact read log: it gives source versions and the sections/theorem statements inspected, distinguishes selected reading from full-text reading, and records the theorem limits and retrieval gaps.

PDF companions have extracted .txt files for search; the PDF is the authority where extraction loses symbols or page layout. The official PMC Borcherds article is retained with its four scanned page images because the PDF route was unavailable. Official course metadata pages and author bibliography pages are retained as HTML when they identify the source edition. Some extracted files contain OCR/layout artifacts.

The Hall-algebra source set is shared with lane 06 rather than duplicated here:

- research/physics-algebras-planning-2026-10-17/sources/06-other-physics-algebras/schiffmann-2006-hall-algebras.pdf
- research/physics-algebras-planning-2026-10-17/sources/06-other-physics-algebras/schiffmann-et-al-2023-cohas-quivers-yangians.pdf

The source log does not claim full-text access to Beilinson–Bernstein (1981), Kac (1977), Frenkel–Ben-Zvi’s book, or Wigner (1939). The 18.757 localization theorem is a lecture-note statement without its global-equivalence proof; the Wigner APS request returned HTTP 401. These remain explicit proof/source obligations. The downloaded 1994 Kac–Wakimoto number-theory version was not relied on.

SHA256SUMS.txt records hashes for the source PDFs, extracted text, HTML metadata/article, and scan images in this folder; it excludes this README and the checksum file itself.
