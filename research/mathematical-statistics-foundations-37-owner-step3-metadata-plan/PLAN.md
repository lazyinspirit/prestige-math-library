## Ordered root procedure

1. Wait for every native dispatcher and descendant writer to drain, pause the exact run, and verify final native outcomes. Merely finding no dispatcher is insufficient evidence of descendant drain. The draft checks pause/dispatcher absence; root supplies the remaining writer attestation.
2. Before ANY manifest/contract edit or native decision stamping, review then use the capture-only phase of `reconcile-after-drain.draft.mjs` with the explicit root flag and `--capture-only`. It archives exact accepted-decision documents, native result/report/assignment/post snapshot and original per-batch manifests/contracts/aggregate. It archives a complete accepted source only when its raw bytes hash to the immutable post-reader source hash. A mismatch is recorded as blocked; current bytes are never passed off as an accepted preimage. Preserve this capture directory.
3. Review then use `project-metadata-only.draft.mjs` with the root flag, `--capture-dir <that directory>`, and `--reviewed-quote-sources <JSON array file>`. The allowlist must name only actual suppliers whose current repaired claims root has independently accepted, including the relevant published MCT/R6 suppliers if applicable. It copies current full designated source claims into manifest.statement while preserving every other manifest field. It archives every metadata file before changing it. Missing designated headings are reported, not silently synthesized. It does not edit source or dependency levels.
4. The same projection draft reads every existing citation in its existing source_section using the checker’s actual sourceSectionText and whitespace normalization. If the old quote still occurs, leave it exactly alone. If stale and the supplier is allowlisted, change ONLY citation.quote to the complete actual text of that same section. Preserve fact/source/source_section/uses, all derivations/routine_steps/boundaries/risk_review and every other field. Stale quotes outside the allowlist remain explicit pending rows. Missing/invalid sections need focused owner review, never a guessed section or proof. Do not run regen-contract-entries.mjs: it replaces citations and derivations and can duplicate existing routine-step coverage.
5. Finish all per-batch projections before aggregate projection. Then review/run the integration phase of `reconcile-after-drain.draft.mjs`. It refuses YAML/id/kind/title/dependency/numeric inconsistencies, copies WHOLE actual per-batch contract entries into the aggregate, preserves aggregate noncontract fields and unrelated entries, and adds only entries accepted by the real runtime continuity guard. It archives the aggregate and any preexisting owner-evidence document first. Every denied continuity remains explicitly ineligible; successful unrelated entries do not conceal it. A frozen/current-identical carrier needs no exception.
6. Root handles all blocked rows/page mismatches through their actual owner/native route, performs the ordinary authorized mechanical subject-seal stamping only after preserving originals, then fresh root recertification and the full battery. Neither draft edits verdicts, native decisions, snapshots, readiness records or state, and neither grants worker coverage. The real continuity guard itself invokes strict proof-contract validation during root execution; the preparer has not invoked it.

The capture phase is mandatory before metadata projection even though integration also takes fresh archive copies. Do not mistake a post-edit copy for the pre-edit capture. If a source must later receive a justified metadata-only edit, use its previously captured complete post-reader-bound source, not a reconstructed frontmatter fragment. Current drafts deliberately refuse numeric source edits; root must separately authorize/archive any newly necessary ones.

## Actual continuity schema and guards

Authoritative implementation: `tools/step3-owner-source-identical-continuity.mjs`, export `sourceIdenticalAcceptanceContinuity(root,run,decision,target,before,current,entry)`. The guard is called from `tools/step3-scope.mjs` for decision-not-applied handling. Its schema examples are in `tools/step3-owner-source-identical-continuity.test.mjs`; these were read, not run. WORKFLOW.md documents source-identical acceptance continuity under independent review/closeout.

Append only genuinely eligible records to `research/RUN-step3-owner-repair-evidence.json` → `source_identical_acceptance_continuities`. Preserve all existing owner evidence. Each version1 record has policy `step3-source-identical-acceptance-continuity-v1`, run/id/obligation, post_reader_carrier_sha256, target_sha256, current_carrier_sha256, historical_manifest_delta_unknown:true, independent_execution_coverage_adopted:false; hash-bound `{path,sha256}` refs for post_reader_snapshot/native_result/native_report/native_assignment/accepted_decision_archive, and accepted_decision_sha256. Optional source_metadata_before is the complete, independently hash-bound accepted-source archive.

Actual eligibility is accepted_repair + touched, non-added, non-stabilized obligation with authentic completed successful Alpha result, correct assignment, immutable version2 post snapshot, actual archived accepted decision and matching carrier hashes. Guard checks current source, actual current-home manifest row (including __step4_page_id), ordered deps, designated full claim mirror and current native per-batch contract. It invokes the real strict contract checker for the exact item. Null contracts are narrowly permitted only for definition/algorithm/remark with no numbered proof steps and both frozen/current null contracts. It does not waive a missing proof contract.

Source must be raw-identical to post-reader, or have an exact archived source whose raw hash matches post-reader and whose body is unchanged, with parsed frontmatter differences restricted to dependency_level/verification/provenance. Protected verification audited/verified/sources_checked/repair cannot be added/changed. Title/id/status/run/deps/axioms/proof-strategy changes are not this route. A previous YAML parse error cannot be hand-waved as parsed metadata equality. Authenticated same-ID rehome is a separate real guarded branch. Absence of a full bound preimage means blocked, not fabricated continuity.

The guard does not update a stale current decision.subject_sha256. `tools/step3-scope.mjs` native stamp handling is separate; root archives originals BEFORE any authorized mechanical stamp. Existing riskReviewOnlyDelta is narrower: unchanged source+manifest and addition of risk_review only, with its deletion exactly restoring the frozen contract. Do not stretch that shortcut to quote/derivation changes.
