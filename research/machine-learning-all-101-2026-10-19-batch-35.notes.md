## Conventions and unresolved theorem obligations

- State vectors are columns; SSM output is `C* x` over `C`. The direct term `D u` is omitted from the S4 kernel and is a separate skip term. `x_{−1}=0`; the impulse kernel is `(C*B̄,C*ĀB̄,...,C*Ā^{L−1}B̄)`.
- Rank `r` is fixed as `N` grows. The rank-one source algorithm uses four scalar Cauchy products. The fully stated fixed-rank count is `(r+1)^2`; rank two uses nine. No rank-two case is mislabeled as four products.
- The root grid is padded to `M=2^q≥L`; the output kernel is the first `L` coefficients. The root `−1` is evaluated by the exact limiting formula `K̂(−1)=Δ C̃*B/2`. Other root-grid resolvents and the low-rank Woodbury corrections must be invertible; a resonant parameter returns a status rather than an undefined quotient. The scope plan does not state a proof for this resonance boundary, so it is recorded with the filter theorem.
- HiPPO-LegS uses the matrix in an ODE multiplied by `1/t`; the NPLR result concerns that finite matrix and does not identify the time-varying ODE with a time-invariant S4 SSM. The current source formulas are also recorded separately from the fixed-time S4 parameterization.
- The bilinear recurrence requires `I−ΔA/2` to be invertible. If the diagonal base `I−ΔΛ/2` is invertible, the small Woodbury correction must also be invertible. The local recurrent algorithm separately handles a singular diagonal base when the full bilinear matrix is invertible, using a bordered system of size at most `2r`.
- Exact Cauchy arithmetic is locally supplied by a balanced product-tree rational numerator/denominator and radix-two polynomial evaluation. The finite-precision Cauchy routine and its condition/accuracy hypotheses are the smallest unresolved supplier obligation. Proposed supplier placement: A page, before `thm-s4-convolution-filter-complexity`; candidate supplier ID `thm-cauchy-root-grid-matvec-numerical-cost`. A complete proof and exact normwise accuracy convention are required before that theorem or its cost example can be ready.
