## Confirmed defects and repairs

The old losslessness theorem encoded b=floor(log2(m))+1 using “b-1 zeros followed by the b-bit binary expansion of b.” That uses the value b where the bit length of b is required. For m=4, b=3, so the claimed construction begins 00+011, whose asserted third bit is not 1. Its claimed Elias-delta parsing and logarithmic redundancy proof therefore did not follow.

The algorithm now specifies the exact serialization itself. For parent i, set m=i+1, b=bitlength(m), d=bitlength(b). Emit d-1 zero bits, the d-bit binary expansion of b, and the final b-1 bits of m; then append the fixed-width symbol field for the augmented alphabet. The losslessness theorem proves how the first 1 determines d, how the header determines b and suffix length, and how the suffix reconstructs m and i. The header remains nonempty for m=1. Codes for m=1,2,4 are 1,0100,01100. The exact index length is b+2 floor(log2 b). At record j, i<j and hence m<=j; the proof gives the all-index upper bound log2(j+1)+2 log2 log2(j+2)+3. Summing over N output records adds the fixed symbol width and yields the stated N log N leading term with O(N log log(N+2)) redundancy. No asymptotic constant is obtained by incorrectly dropping the extra length header.

The local prefix definition previously claimed arbitrary concatenation decoding while allowing the empty codeword for a singleton message set. Different repetition counts have the same empty encoding. The corrected clause separates injective one-codeword decoding from arbitrary-list decoding: nonempty prefix words determine the list; the empty singleton requires a known message count, including one known block. The zero-bit fixed-block optimum is preserved exactly. The LZ serializer uses nonempty index headers and symbol fields, and its unique marker stops decoding without source length or record count, so this framing qualification is not silently borrowed for LZ.
