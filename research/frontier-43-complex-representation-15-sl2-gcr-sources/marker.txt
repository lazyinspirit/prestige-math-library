These are informal notes for a course in Descriptive Set Theory given at
the University of Illinois at Chicago in Fall 2002. While I hope to give a fairly
broad survey of the subject we will be concentrating on problems about group
actions, particularly those motivated by Vaught’s conjecture. Kechris’ Classical
Descriptive Set Theory is the main reference for these notes.

f : N →A, then f|n is the sequence (f(0), . . . , f(n −1)).
If X is any set, P(X), the power set of X is the set of all subsets X.
If X is a metric space, x ∈X and ϵ > 0, then Bϵ(x) = {y ∈X : d(x, y) < ϵ}

Deﬁnition 2.1 If X is any set, a σ-algebra on X is a collection of subsets of X

Deﬁnition 2.2 If X is a topological space, the class of Borel sets B(X) is the
