## Example

Let $\mu=\delta_1$ be the Dirac mass at the point $1\in\mathbb T$. Then $\mu$ is
a finite positive measure singular with respect to $m$ and the associated
function is the singular inner function
$$S(z)=\exp\Bigl(-\frac{1+z}{1-z}\Bigr)\qquad(z\in\mathbb D),$$
because $K(z,1)=\frac{1+z}{1-z}$. One has
$|S(z)|=e^{-P(z,1)}=e^{-(1-|z|^2)/|1-z|^2}\le1$, $S(0)=e^{-1}>0$, $S$ has no
zeros in $\mathbb D$, and $|S^*(\zeta)|=1$ for every $\zeta\ne1$; in particular
$|S^*|=1$ $m$-almost everywhere. The nontangential limit of $S$ at $\zeta=1$
is $0$, because $P(z,1)\to+\infty$ along every cone at $1$. Thus $S$ is inner,
nonconstant, and its boundary modulus fails to be $1$ only on the null set
$\{1\}$.

## Facts & Assumptions

**Given:** The point $1\in\mathbb T$, the Dirac measure $\mu=\delta_1$, and the associated function $S=\exp(-H)$ with $H(z)=\int_{\mathbb T}K(z,\zeta)\,d\delta_1(\zeta)=K(z,1)$.

[F1] The Dirac measure $\delta_1$ is a probability measure and a finite positive Borel measure with $\delta_1(\{1\})=1$, and $m(\{1\})=0$, so $\delta_1\perp m$ ([[def-dirac-measure]], [[prop-dirac-measure-is-a-probability-measure]], [[def-the-one-dimensional-torus-and-normalized-haar-integral]]).

[F2] $K(z,\zeta)=(\zeta+z)/(\zeta-z)$ and $\operatorname{Re}K(z,\zeta)=P(z,\zeta)=(1-|z|^2)/|\zeta-z|^2$; for $z=re^{i\phi}$ and $\zeta=e^{it}$ one has $P(z,\zeta)=P_r(t-\phi)>0$ with $\frac{1}{2\pi}\int_0^{2\pi}P_r(\theta)d\theta=1$ ([[def-inner-singular-inner-and-outer-functions]], [[def-poisson-kernel-on-the-disc]], [[lem-poisson-kernel-properties-on-the-disc]]).

[F3] For a finite positive measure $\nu$, the function $S_\nu=\exp(-\int K\,d\nu)$ is holomorphic and zero-free with $|S_\nu|=e^{-P[\nu]}\le1$ and $S_\nu(0)=e^{-\nu(\mathbb T)}$; it is a singular inner function exactly when $\nu\perp m$, and then $|S_\nu^*|=1$ $m$-almost everywhere with nontangential limits existing a.e. ([[thm-singular-inner-function-properties]], [[def-inner-singular-inner-and-outer-functions]]).

[F4] The nontangential region at $1$: for $A>1$, $\Gamma_A(1)=\{z\in\mathbb D:|z-1|<A(1-|z|)\}$, so along $\Gamma_A(1)$ one has $|1-z|\le A(1-|z|)$ ([[def-circle-maximal-function-and-nontangential-region]]).

## Verification

1.1 The measure and the kernel value. By [F1], $\delta_1$ is a finite positive measure singular with respect to $m$; evaluating the kernel at $\zeta=1$ gives $K(z,1)=\frac{1+z}{1-z}$, so $S(z)=\exp(-K(z,1))=\exp(-\frac{1+z}{1-z})$. [given, F1, F2, algebra]

2.1 Modulus, value at the origin, zero-freeness. By [F2], $\operatorname{Re}K(z,1)=P(z,1)=\frac{1-|z|^2}{|1-z|^2}$, hence $|S(z)|=e^{-P(z,1)}\le1$ and $S(0)=e^{-P(0,1)}=e^{-1}>0$; $S$ is an exponential, hence zero-free. [step 1.1, F2, algebra]

3.1 Cones at $1$. Let $A>1$ and $z\in\Gamma_A(1)$. By [F4], $|1-z|\le A(1-|z|)$, so $$P(z,1)=\frac{1-|z|^2}{|1-z|^2}\ge\frac{(1-|z|)(1+|z|)}{A^2(1-|z|)^2}=\frac{1+|z|}{A^2(1-|z|)}\longrightarrow+\infty$$ as $|z|\to1$; therefore $S(z)=e^{-P(z,1)}\to0$ along every cone at $1$. Combined with the a.e. boundary values of [F3] (which give $|S^*|=1$ a.e. because $\delta_1\perp m$) and the fact that $S^*(\zeta)=1$-modulus for every $\zeta\ne1$ (where the exponent $-\frac{1+z}{1-z}$ has a finite limit), the boundary modulus of $S$ fails to be $1$ exactly on the null set $\{1\}$. [step 1.1, step 2.1, F3, F4, algebra] ∎
