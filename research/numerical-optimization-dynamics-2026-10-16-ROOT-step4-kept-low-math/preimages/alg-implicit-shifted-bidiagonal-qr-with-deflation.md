## Definition

Input the original $A\in\mathbb F^{m\times n}$, the successful output record of [[alg-householder-bidiagonalization]] for $C=A$ if $m\ge n$ and $C=A^*$ otherwise, a deflation tolerance $\tau\ge0$, and a finite nonnegative integer sweep budget $N$. The reduction record supplies the upper bidiagonal work matrix $B_0$, dense accumulators $U_B,V_B$, and ordered stored local transformation data. Initialize $B=B_0$, the sweep accumulators $U_\Sigma,V_\Sigma$ to identities of order $p=\min(m,n)$, empty ordered left/right transformation lists, an empty deflation record, a pass counter $t=0$, and a sweep counter $s=0$. Write the diagonal as $d_i$ and superdiagonal as $e_i$, and set $e_0=0$.

At the start of each pass, set $t\leftarrow t+1$, set $e_i$ to zero and append $(t,i,e_i^{old})$ to the deflation record whenever $|e_i|\le\tau(|d_i|+|d_{i+1}|)$. The corresponding additive matrix change has entry $-e_i^{old}$ at $(i,i+1)$ and zero elsewhere. Record any later non-target sparsity cleanup the same way with its row, column, and old value. The zero entries split the active blocks. If every active block has size one, stop with `converged`. Otherwise process the active blocks in increasing order of $\ell$, skipping singleton blocks. Before each block sweep, if $s=N$, stop with `budget-exhausted`; otherwise form only the tridiagonal entries of $T=B^*B$ on that block: $T_{ii}=|d_i|^2+|e_{i-1}|^2$ and $T_{i,i+1}=\overline{d_i}e_i$. Choose $\mu$ to be the eigenvalue of the trailing Hermitian block $\begin{bmatrix}T_{r-1,r-1}&T_{r-1,r}\\T_{r,r-1}&T_{rr}\end{bmatrix}$ closest to $T_{rr}$, resolving a tie by the smaller eigenvalue. If the leading pivot $d_\ell$ is zero or has magnitude at most $\tau\max(|e_{\ell-1}|,|e_\ell|)$, use the zero-shift branch $\mu=0$ and choose the initial right Givens factor $G_\ell$ so that $(d_\ell,e_\ell)G_\ell=(\rho,0)$, avoiding division by the small or zero diagonal.

In the ordinary branch choose the first right Givens factor $G_\ell$ so that $G_\ell^*(T_{\ell\ell}-\mu,T_{\ell+1,\ell})^T=(\rho,0)^T$, where $T_{\ell+1,\ell}=\overline{e_\ell}d_\ell$. In either branch, apply $B\leftarrow BG_\ell$, update columns $\ell,\ell+1$ of $V_\Sigma$ by right multiplication by this same stored rotation, and append its exact unitary representative to the right list. For $j=\ell,\ldots,r-1$, choose a left Givens factor $H_j$ so that $H_j^*(B_{j,j},B_{j+1,j})^T=(\rho,0)^T$; apply it to rows $j,j+1$, update columns $j,j+1$ of $U_\Sigma$ by right multiplication by this same stored rotation, and append its exact unitary representative to the left list. If $j<r-1$, choose a right Givens factor $G_{j+1}$ so that $(B_{j,j+1},B_{j,j+2})G_{j+1}=(\rho,0)$; apply it to columns $j+1,j+2$, update the corresponding columns of $V_\Sigma$ by right multiplication by this same stored rotation, and append its exact unitary representative to the right list. Continue until the bulge reaches the active block endpoint. A zero annihilation vector uses the identity rotation. In finite precision each Givens formation/update uses [[alg-scaled-complex-householder-and-givens-updates]], conjugate-transposed as needed for the stated left/right orientation; accumulator multiplications use the same stored local data but omit all target-zero writes. The dense accumulator multiplications follow the operationwise arithmetic model, while the ordered lists retain the exact unitary representatives used in analysis. Target zero writes to $B$ are included in their local error bounds. The initial shift-vector rotation does not zero an unrelated entry of $B$. Each Givens factor is chosen using [[def-real-and-complex-givens-transformations]] and its annihilation guarantee in [[thm-householder-reflectors-and-givens-transformations-are-unitary-and-annihilate-targeted-entries]].

After each processed block, increment $s$ by one. Once all current active blocks have been processed, start a new pass. If any operation, norm or pivot is invalid or nonfinite, or a nonzero exact intermediate is outside the normal range, return `range-failure` with the partial $B$, accumulators, transformation lists, deflation record, and available residual reports. On `budget-exhausted`, return the current $B$, accumulators, transformation lists, deflation record, triplet residuals, and orthogonality residuals. On `converged`, set $B_{\mathrm{final}}=B$ and return it with both dense accumulators, both transformation lists, the deflation record, triplet/orthogonality residuals, and its tall embedding $\overline B_{\mathrm{final}}=\begin{bmatrix}B_{\mathrm{final}}\\0_{M-p,p}\end{bmatrix}$.

For every exit other than `range-failure`, let $B_{\mathrm{out}}$ be the current work matrix, and let $d_i=(B_{\mathrm{out}})_{ii}$. Obtain each candidate value as $\widehat\sigma_i=|d_i|$ by the scaled two-component modulus evaluation (real absolute value is exact). On `converged`, the active-block condition makes $B_{\mathrm{out}}=B_{\mathrm{final}}$ diagonal; after `budget-exhausted`, the diagonal values are estimates only and carry no accuracy claim.

Let $W_B=\operatorname{diag}(U_\Sigma,I_{M-p})$. In exact arithmetic the tall-orientation accumulated factors are $U_C=U_BW_B$ and $V_C=V_BV_\Sigma$. In finite precision form each dense product by row-by-column multiplication, with six-real-operation complex products and sequential componentwise rounded additions under the operationwise model; return `range-failure` if any required intermediate is invalid, nonfinite, or outside the normal range. Their exact theoretical factors are the products represented by the ordered local transformation lists together with the bidiagonal-reduction lists. If $m\ge n$, set $\widehat U=U_C$ and $\widehat V=V_C$; for each nonzero $d_i$, multiply column $i$ of $\widehat U$ by $d_i/|d_i|$ in exact arithmetic, using componentwise division by the successful scaled modulus readout in finite precision. If $m<n$, set $\widehat U=V_C$ and $\widehat V=U_C$; in this wide orientation multiply column $i$ of $\widehat V$ by $d_i/|d_i|$ instead. Sort the candidate values in nonincreasing order, breaking ties by their original diagonal index, and permute the corresponding columns of the returned triplet vectors in the same way; leave $B_{\mathrm{out}}$ and the transformation lists in their algorithmic order. For every candidate triplet $(\widehat\sigma_i,\widehat u_i,\widehat v_i)$, report $\|A\widehat v_i-\widehat\sigma_i\widehat u_i\|_2$ and $\|A^*\widehat u_i-\widehat\sigma_i\widehat v_i\|_2$. Also report $\|\widehat U^*\widehat U-I\|_F$ and $\|\widehat V^*\widehat V-I\|_F$. The reports expose finite-budget and rounding behavior; they do not certify convergence by themselves. Matrix residuals use the Frobenius norm defined in [[def-frobenius-matrix-norm]]. Any additional sparsity cleanup is recorded separately in the deflation record with its discarded-entry perturbation.
