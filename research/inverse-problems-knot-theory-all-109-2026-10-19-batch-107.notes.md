The Morse nonemptiness helper likewise originally depended on the definition it supported.
- The cycle is removed by making `lem-knot-admits-morse-height-representative` independent of the bridge definition, adding `thm-descending-diagram-is-unknot` and `thm-every-knot-has-unknotting-sequence`, and making the definition depend only on these existence results. The assigned finite-bound theorem is now a consumer of the definition and the independent descending-diagram theorem.
- The descending lift uses the equatorial sphere in the fixed unit `S^3` height model. The long based arc has height `a cos(πt)` and the crossing-free base subarc has height `−a cos(πs)`, for `a=1/2`. This makes the long arc strictly descending, the base arc strictly ascending, and the closed height function have exactly one maximum and one minimum. The upper/lower arcs then use the one-extremum disk lemma with the same level arc and yield a spanning disk.
- The finite rational-code lemma now states how rational crossings and graph arcs are chosen, preserves the transverse branch sectors, interpolates within disjoint graph neighborhoods, and uses isotopy extension to identify the knot type. This is the explicit local argument needed for the nonempty definition of `u(K)`.
