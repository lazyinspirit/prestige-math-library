Run it after each category consolidation, queue extension or repair batch; pending work stays visible. `watch-ready-repairs.mjs` is a root-owned mechanical recorder only. It runs detached with repository-local logs and status, processes ready guarded repairs, and skips active continuations and mathematical-acceptance holds. Structured correction descriptions are normalized to strings for the receipt schema, preserving original adjudication bytes.
