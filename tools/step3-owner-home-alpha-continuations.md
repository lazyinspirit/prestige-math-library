# One fresh native home Alpha for registered foreign-refuter findings

This opt-in normal-planner adapter reopens one already completed standalone
home Alpha unit once. It grants no old acceptance, extra mathematical cycle,
source permission, native observation, state reset or gate waiver. Existing
foreign-refuter registration and the separate origin refuter coverage
continuation remain required. Nothing edits the original native reports.

Root registers `research/RUN-step3-home-alpha-continuations.json`:

```
{
  "version": 1,
  "run": "RUN",
  "policy": "owner-step3-foreign-refuter-home-alpha-continuation-v1",
  "authorized_by": "owner",
  "authorization": "Concrete genuine root authorization, at least 40 characters",
  "continuations": [ENTRY]
}
```

- `version:1`, exact `run`, `owner_identity:"/root"`, positive string `unit:"30"`,

- `mathematical_acceptance:false`, `previous_acceptance_inherited:false`,
  `historical_artifact_basis:"owner-captured current completed-native artifacts; no structured-output byte attestation"`;

  the successful old native completion and relevant actual writer drain;
- own-run raw SHA256 `{path,sha256}` references `previous_result`,
  `previous_attempt`, `previous_prompt`, `previous_report`,
  `previous_decisions`, `previous_scope`, `registration_manifest`,
  `owner_capture`, `task`;
- `current_inputs:[{path,sha256},...]`, exactly the initial actual source/carrier
  path set described below;
- `foreign_refuter_routes:[{path,entry_sha256},...]`, exactly every registered
  foreign-refuter entry targeted at this home unit, without duplicates.

`research/RUN-dispatch/alpha-3a-batch-30.result.json`; previous attempt and prompt
