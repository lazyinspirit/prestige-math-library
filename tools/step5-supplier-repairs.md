# Same native reviewer supplier repair evidence

`step5-workflow.mjs collect` optionally reads the immutable owner supplement
`research/RUN-step5-v2/PHASE-ROUND-owner-supplier-repairs.json`. This is a narrow
bridge for a confirmed defect in an unchanged consumer whose actual remedy was
completed in its direct definition or algorithm supplier by the same successful
native adjudicator. It supplies no mathematical review or new worker coverage.
Original reports, decisions, verdicts and fatal counters remain unchanged.

The owner writes this receipt only after independently inspecting the actual
repair, at a paused, drained initial/repeat collection hold. Archive the exact
runtime state under the run's research evidence; never edit native reports or
manufacture a source preimage. Collection binds the supplement and every listed
immutable input in its ordinary evidence map; later evidence verification rejects
changes. There is no mutable correction or overwrite route.

The version-1 object has these fields:

- `kind: "same-native-reviewer-supplier-repairs"`, `version: 1`, `run`, `phase`
  (`initial` or `repeat`), integer `round`, `pack_sha256` (the existing JSON
  object digest), `authorized_by: "owner"`, `owner_identity: "/root"`,
  `native_coverage_adopted: false`, ISO `recorded_at`.
- `owner_review_evidence`: a bound absolute research path to the focused owner
  inspection explaining why this exact native supplier remedy resolves the defect.
- `creation_state`: absolute path to the archived exact paused/drained native
  state at the held `step5-wave-evidence` gate.
- `bindings`: absolute research paths to raw-byte SHA256 hashes. Required paths
  are the focused owner review, frozen pack, creation state, original report, successful native dispatch
  result, its exact successful attempt result, and that attempt's original prompt.
  All bindings must exist unchanged. The original successful worker must be
  GPT-6.1 Sol/high with a native session ID; the attempt/result objects must agree.
- Nonempty `entries`, each containing `unit` (string), `decision` (the exact full
  unchanged native consumer decision), `consumer_review_sha256` (existing JSON
  object digest), `consumer_raw_sha256` (actual current raw source bytes),
  `reason` (at least 80 characters identifying the exact remedy), and
  `native_remedy_excerpt` (at least 40 characters appearing literally in both
  the original consumer decision and original consumer review).
- Each entry has one `supplier` object: `id`, `decision_sha256`, `review_sha256`
  (existing JSON object digests), `before_guard_sha256`,
  `before_statement_sha256` (exact frozen pack values), `post_guard_sha256`,
  `post_statement_sha256`, `post_raw_sha256` (actual current values),
  `native_remedy_excerpt` (at least 40 literal characters shared by its own
  original decision and review), and `current_interface_excerpt` (at least 20
  literal characters in its current `## Definition`).

Both subjects must be assigned in that same report. The consumer must have an
`unaffected` review and its frozen guard must still match. The supplier must have
its own confirmed adjudication and `repaired` review. Both original reviews must
match the actual current source and review contexts. The supplier must be a
current canonical direct `deps` entry, written in ordinary block-list form
`  - ID`; aliases, indirect ancestors, references and `justified_by` do not
qualify for this narrow receipt. Both the supplier guard and its frozen/current
Statement/Definition digest must differ. A contract quote refresh, dependency
metadata change, or proof-only edit cannot qualify. Missing, stale, uncertain,
duplicate or unbound evidence fails closed; no downstream-list membership grants
an exception.

The receipt records the owner's exact attribution of an already explicit native
remedy. Hashes establish source currency and changed interfaces; they do not
prove that an arbitrary supplier edit resolves an arbitrary defect. The owner
must reject a proposed receipt if the preserved native reasons do not actually
explain the same repair. A missing before-source archive is not reconstructed:
the authentic frozen pack supplies the original guard/interface commitments,
and the original report supplies the attributed remedy.

Only the named confirmed decision's own-carrier-change requirement is satisfied
by this evidence. Every other report check, supplier and consumer maintenance,
certification, repeat-round obligation, original fatal count and complete native
gate battery remains required. This receipt is not a false-positive disposition
and does not turn a metadata-only consumer observation into an item repair.
