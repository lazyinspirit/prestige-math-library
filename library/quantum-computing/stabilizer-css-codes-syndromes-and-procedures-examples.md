These worked binary examples check the nested-code CSS convention, coset
normalization, stabilizer ranks, logical operators, and syndrome labels. The
four-qubit example deliberately violates the extra dual-containment condition
used in one special-source presentation while satisfying the general
$C_2\subseteq C_1$ construction.
