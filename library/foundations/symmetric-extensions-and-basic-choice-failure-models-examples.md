The first examples distinguish an invariant orbit set from its moved enumeration graph and calculate the three choice-free tests for Dedekind finiteness. The socks example carries out the compatible fresh-coordinate swap in the corrected pair-of-sets-of-reals construction.

Full generic extensions of ZFC grounds satisfy Choice, but symmetric inner models need not. The basic Cohen model alone refutes the universal false statement; the corrected socks model shows the stronger failure of choice for a countable family of pairs.
