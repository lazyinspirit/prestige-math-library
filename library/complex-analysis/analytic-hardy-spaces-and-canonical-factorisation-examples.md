The examples test the factorisation theory of
[[analytic-hardy-spaces-and-canonical-factorisation]] on explicit functions.
[[ex-finite-blaschke-products]] computes finite Blaschke products — including
$B(z)=(1/4-z^2)/(1-z^2/4)$ for the zeros $\pm1/2$ — with their boundary
modulus, their zeros and the strict inequality $|B|<1$ inside the disc.
[[ex-blaschke-product-with-zeros-accumulating-at-one]] builds the infinite
Blaschke product with zeros $1-1/n^2$, evaluates its telescoping value
$B(0)=1/2$, shows that it has no continuous extension to the closed disc and
computes $\|B\|_{H^2}=1$. The counterexample
[[cex-divergent-blaschke-sum]] exhibits the divergent Blaschke sum
$\sum_{n\ge2}1/n$: no nonzero $H^p$ function has those zeros, the formal Blaschke
product is not normally convergent, and a Weierstrass product with exactly
those zeros lies in no Hardy class.

The canonical factors are illustrated by
[[ex-singular-inner-function-from-a-point-mass]], the singular inner function
$\exp(-(1+z)/(1-z))$ generated by the Dirac mass at $1$, whose boundary
modulus fails only on the null set $\{1\}$, and by
[[ex-outer-function-with-prescribed-boundary-modulus]], which identifies the
outer function with modulus $|1-\zeta|^\alpha$ as the principal branch
$(1-z)^\alpha$ and proves it is not rational for non-integer $\alpha$.
[[ex-boundary-vanishing-and-uniqueness]] shows that $1-z$ is outer and that
boundary vanishing of a nonzero Hardy function is confined to a null set, with
the boundary function determining the function. Finally
[[ex-factorization-of-a-rational-function]] writes the rational function
$\frac{z-a}{1-\overline az}\cdot\frac{1+z}{2}$ as a unimodular constant times
a Blaschke factor times an outer factor, with trivial singular part.
