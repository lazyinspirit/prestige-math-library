---
title: Computability Theory
---
These pages begin with formal languages, automata, grammars, and decision problems, then
develop Turing-machine computation, decidability and recognition, reductions,
diagonalization, and recursion theorems. Complexity topics cover time, space, P and NP,
circuit models, hierarchy theorems, randomized and counting classes, interactive proofs,
arithmetization, PCP, approximation, and gap reductions. The collection also treats oracle
degrees, algorithmic randomness, Kolmogorov complexity, and robust machine simulations, with
examples applying reductions and separating computational resources. Several classic results
include Cook–Levin, Savitch, IP = PSPACE, and the PCP theorem.

Set Theory supplies the language and cardinality conventions; Combinatorics, Abstract
Algebra, Linear Algebra, Probability, Measure Theory, Real Analysis, and Number Theory
support finite encodings and algebraic or probabilistic arguments. Group Theory uses
undecidability and machine models, while Quantum Algorithms and Quantum Computing use
machine, circuit, and promise-problem interfaces. Information Theory uses Kraft's
inequality; the Machine Learning Algorithms collection uses coding of finite sequences, and
Statistical Models and Experiments draws on the harmonic bound for set cover.
