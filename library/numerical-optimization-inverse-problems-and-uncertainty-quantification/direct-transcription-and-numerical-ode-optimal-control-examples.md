The examples compute an exact scalar bounded-actuator LQR minimizer and its objective, compare an explicit-midpoint chemical-dosing trajectory with its exact ODE solution, and write the same two-interval control problem in single- and multiple-shooting variables. Each calculation identifies which values are exact and which belong only to a finite transcription.
