This page defines pathwise derivatives on the allowed score tangent space, distinguishes parameter influence curves from estimator influence functions, and characterizes all derivative representers. It defines efficient scores by projecting interest scores off the closed nuisance tangent space. The canonical-gradient formula for a finite-dimensional interest parameter is proved only when the full score space is the stated interest-plus-nuisance sum and the efficient information is nonsingular. The Axiom of Choice supplies selected density versions along dominated paths; Countable Choice supports Hilbert completeness, projection and Riesz representation. These are separate axiom branches. No estimator-attainment result is asserted.
