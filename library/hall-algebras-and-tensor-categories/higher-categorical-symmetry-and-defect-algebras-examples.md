These computations test the A-page structures and stay outside the theorem chain. They calculate matrix composition and interchange, the relative tensor rule for $R=\mathbb C\times\mathbb C$, the trivial-group model, and an explicit $C_4$ coboundary gauge. The codimension example checks only mathematical types; it does not identify a physical system with a particular fusion 2-category.

## Scope boundary

Each example cites the A-page definitions or proved suppliers it uses. No example supplies a general classification premise. In particular, the $C_4$ example is a coboundary and demonstrates a gauge change; it is not evidence for a nonzero class in $H^4(C_4;\mathbb C^\times)$.
