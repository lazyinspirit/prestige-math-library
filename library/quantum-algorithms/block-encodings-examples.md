The examples calculate a two-term LCU with unequal component normalizations and a complex coefficient phase, then evaluate a two-factor normalized product-error bound on explicit diagonal matrices. Each compressed block is realized by a finite unitary dilation, and the query and implementation costs remain attached to the supplied PREPARE, SELECT and component calls.
