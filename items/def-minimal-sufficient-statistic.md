## Definition

A statistic $T$ into a standard Borel space is **minimal sufficient** for $(P_\theta)$ if $\sigma(T)$ is a minimal sufficient $\sigma$-field in the preceding sense. Minimality is modulo sets null under every model law. It does not assert literal pointwise equality with any other minimal sufficient statistic.
