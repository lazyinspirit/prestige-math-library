## Definition

Let $U\subset\mathbb R^d$ be open, let $f=(f_1,\ldots,f_n):U\to\mathbb R^n$ be a $C^m$ map, and let $1\le l\le m$. A point $x_0\in U$ is $l$-nondegenerate for $f$ if the vectors $\partial^\alpha f(x_0)$ with multi-indices $\alpha$ satisfying $1\le |\alpha|\le l$ span $\mathbb R^n$. It is nondegenerate if it is $l$-nondegenerate for some such $l$. The order-zero value $f(x_0)$ is not included among these derivative vectors.
