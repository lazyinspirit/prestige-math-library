## Statement

If the generator in [[def-qc-uniform-circuit-family]] halts on input $1^n$ within $T(n)\le c(n+1)^k$ transitions, then the generated description has length at most $n+T(n)+O(1)$. Consequently its number of gates and total number of wires are polynomial in $n$. This is a full-list size bound; it does not establish equivalence with indexed-gate uniformity.

## Facts & Assumptions

**Given:** A full-list family generated by a deterministic one-tape Turing machine $G$ in at most $T(n)$ transitions on input $1^n$.

[F1] [[def-qc-uniform-circuit-family]]: the output is a complete self-delimiting gate-list description, each gate record has a gate label, and the total wire count is encoded in unary.

[F2] [[def-deterministic-one-tape-turing-machine]]: one transition writes exactly one symbol on the scanned tape cell and moves the head by one cell.

[F3] [[def-partial-function-computed-by-a-machine]]: the output is the finite binary word on the final tape, with all later cells blank.

## Proof

1.1 Initially the input $1^n$ occupies $n$ cells. In $T(n)$ transitions the head visits at most $T(n)+1$ additional positions, and each transition writes only one symbol by [F2]. At halting, the output convention [F3] therefore gives a binary word of length at most $n+T(n)+1$. The description is self-delimiting by [F1], so the number of its symbols is bounded by this polynomial quantity. [given, F1, F2, F3]

2.1 Each gate record contains at least one symbol, so its number of gates is no greater than the description length. The total wire count is explicitly unary in the same description, so it too is no greater than the description length. With $T(n)\le c(n+1)^k$, both quantities are $O(n+c(n+1)^k+1)$ and hence polynomial in $n$. The argument makes no claim that an indexed-gate generator can be converted to a full list. [step 1.1, F1, algebra] ∎
