## Example

For $\operatorname{Cl}_{5\infty}(\mathbb Q)\cong C_4$ with generator $g=[(2)]_{5\infty}$, define $\chi(g^k)=i^k$ for $k\in\mathbb Z/4\mathbb Z$, where $i\in\mathbb C$ satisfies $i^2=-1$. This is a finite-order ray class character modulo $5$ and the real place, with image $\{1,i,-1,-i\}$.

## Facts & Assumptions

**Given:** The cyclic ray class group and generator in the Example.

[F1] The group $\operatorname{Cl}_{5\infty}(\mathbb Q)$ is cyclic of order four generated by $g=[(2)]_{5\infty}$. ([[ex-ray-class-groups-of-q-mod-5-and-5-infinity]])

[F2] A finite-order ray class character is a group homomorphism from the ray class group to $\mathbb C^\times$ with finite image. ([[def-ray-class-character]])

[F3] The complex number $i$ satisfies $i^4=1$, and $1,i,-1,-i$ are distinct. ([[def-complex-numbers-and-arithmetic]])

## Proof


**Given:** The data in the Example.

1.1 By [F1], each ray class has a unique expression $g^k$ with $k\in\mathbb Z/4\mathbb Z$. Since $i^4=1$ by [F3], the value $i^k$ is independent of the chosen integer representative of $k$, so $\chi$ is well-defined. [F1, F3, given]

2.1 For classes $g^k,g^\ell$, the group law and exponent laws give $\chi(g^kg^\ell)=\chi(g^{k+\ell})=i^{k+\ell}=i^ki^\ell=\chi(g^k)\chi(g^\ell)$. The image is exactly the four distinct values in [F3], hence finite, so [F2] makes $\chi$ a finite-order ray class character. [F1, F2, F3, step 1.1, algebra] ∎
