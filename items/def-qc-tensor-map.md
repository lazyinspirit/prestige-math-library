## Definition

For a finite ordered family of finite-dimensional complex vector spaces
$H_k,K_k$ and complex-linear maps $T_k:H_k\to K_k$, the **tensor map**
$\bigotimes_{k<n}T_k:H_0\otimes\cdots\otimes H_{n-1}\to
K_0\otimes\cdots\otimes K_{n-1}$ is the unique linear map satisfying

$$\left(\bigotimes_{k<n}T_k\right)(x_0\otimes\cdots\otimes x_{n-1})=T_0x_0\otimes\cdots\otimes T_{n-1}x_{n-1}.$$

For $n=0$, the tensor map is the identity map $z\mapsto z$ on the empty tensor
product $\mathbb C$.

## Facts & Assumptions

**Given:** A finite ordered family of complex vector spaces and linear maps
$T_k:H_k\to K_k$.

[F1] A binary algebraic tensor product is generated by elementary tensors,
and a tensor with a zero factor vector is zero
([[def-tensor-product-of-modules-by-generators-and-relations]]). Over
$\mathbb C$, tensoring is complex-linear in each factor
([[thm-commutative-ring-module-structure-on-a-tensor-product]]).

[F2] A finite iterated tensor product represents multilinear maps, including
the empty and one-factor cases
([[cor-finite-iterated-tensor-products-represent-multilinear-maps]]).

[F3] Each $T_k$ is linear on its factor ([[def-linear-map]]).

## Proof

1.1 For $n=0$, the prescribed map is the identity on $\mathbb C$. For $n>0$, the function $(x_0,\ldots,x_{n-1})\mapsto T_0x_0\otimes\cdots\otimes T_{n-1}x_{n-1}$ is linear in each argument: replacing any $x_k$ by $a x_k+b y_k$ replaces its image by $aT_kx_k+bT_ky_k$ by [F3], and tensoring is linear in that factor. [given, F1, F3, algebra]

2.1 For $n>0$, [F2] gives a unique linear extension of the multilinear function in step 1.1, hence the map in the Definition. Repeated use of [F1] shows that elementary tensors span any nonempty iterated tensor product. If some $H_k=0$, every source elementary tensor is zero by [F1], so the domain is zero and the unique linear map from it is zero. If some $K_k=0$, the same argument makes the codomain zero, and the unique linear map to it is zero. In either case the displayed rule holds. For $n=0$, the empty elementary tensor is $1\in\mathbb C$ by [F2]; its prescribed image is $1$, which uniquely determines the identity linear map. [step 1.1, F1, F2, algebra] ∎
