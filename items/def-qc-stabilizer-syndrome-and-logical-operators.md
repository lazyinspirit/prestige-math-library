## Definition

Let $n\ge1$ and let $S$ be a stabilizer subgroup generated by an ordered independent
Hermitian list $g_1,\ldots,g_r$. For a phase-aware Pauli error $E$, its
**syndrome** is the bit string $s(E)\in\mathbb F_2^r$ defined by

$$E g_j=(-1)^{s_j(E)}g_jE,\qquad s_j(E):=\omega(\lambda(E),\lambda(g_j)).$$

Here $\lambda(P(k,x,z))=(x,z)$ is the binary Pauli label and
$\omega((x,z),(x',z'))=x\cdot z'+z\cdot x'$. The scalar center of
$\mathcal P_n$ is $Z_n=\{i^kI:k\in\mathbb Z/4\mathbb Z\}$, and the
**normalizer** is $N(S)=\{P\in\mathcal P_n:Pg=gP\text{ for every }g\in S\}$.
The **logical Pauli classes** form the quotient group

$$N(S)/(Z_nS).$$

A normalizer element is logically nontrivial exactly when it lies in
$N(S)\setminus Z_nS$. Multiplication by a scalar phase does not change a
syndrome or logical class.

## Facts & Assumptions

**Given:** The phase-aware Pauli group, its binary label, a stabilizer group
$S$, and an ordered Hermitian generating list.

[F1] [[def-qc-binary-pauli-label-and-quotient]]: $\lambda(P(k,x,z))=(x,z)$
forgets only the scalar phase.

[F2] [[def-qc-binary-symplectic-form]]: $\omega((x,z),(x',z'))=x\cdot z'+z\cdot x'$.

[F3] [[thm-qc-pauli-commutator-is-symplectic-pairing]]: the Pauli
commutator sign is $(-1)^{\omega(\lambda(P),\lambda(Q))}$.

## Verification

1.1 Applying [F3] to $E$ and $g_j$ gives $Eg_j=(-1)^{\omega(\lambda(E),\lambda(g_j))}g_jE$. The exponent is in $\mathbb F_2$, so it determines exactly one bit, and this verifies the stated sign-to-bit convention. [given, F2, F3]

2.1 If $E'=i^aE$ for a scalar phase $i^a$, then $E'g_j=i^aEg_j$ and $g_jE'=i^ag_jE$; the same commutation sign results. Equivalently, $\lambda(E')=\lambda(E)$ by [F1]. Hence the syndrome depends only on the Pauli coset modulo scalar phase. [F1, F3, step 1.1, algebra]

3.1 If $E\in Z_nS$, write $E=zs$ with $z\in Z_n$ and $s\in S$. The scalar $z$ commutes with every generator, and $s$ commutes with every generator because $S$ is abelian, so $E\in N(S)$ and its logical quotient class is the identity. Conversely the denominator of the displayed quotient is exactly the scalar phases times stabilizers; thus a normalizer element outside $Z_nS$ represents a nonidentity logical Pauli class. [given, F1] ∎
