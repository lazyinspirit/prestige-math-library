## Definition

Let $\Omega \subseteq \mathbb C$ be a complex domain, let $a_0 \in \Omega$, and
let $\xi_0$ be a holomorphic germ at $a_0$. Assume that $\xi_0$ admits analytic
continuation along every path in $\Omega$ starting at $a_0$
([[def-analytic-continuation-along-a-path]]).

For a path $\gamma:[0,1]\to\Omega$ with $\gamma(0)=a_0$, write
$\operatorname{Cont}_\gamma(\xi_0)$ for the terminal germ of a continuation of
$\xi_0$ along $\gamma$. This is well defined by
[[thm-end-germ-of-path-continuation-is-independent-of-the-chain]], because the
admissible chains now require agreement at each subdivision endpoint.

The **complete analytic function generated by $\xi_0$** is the set

$$\mathcal A(\xi_0,\Omega):=\{\operatorname{Cont}_\gamma(\xi_0):\gamma(0)=a_0\}.$$

Its elements are holomorphic germs based at points of $\Omega$ reachable from
$a_0$ by path continuation.
