## Statement

Let $G$ be a finitely generated abelian group. If for every positive integer $n$ the map $G\to G$, $g\mapsto ng$, is surjective, then $G=0$.

## Statement references

[Kahn, proof of Lemma 3](https://webusers.imj-prg.fr/~bruno.kahn/preprints/Lang-Neron.pdf)

## Facts & Assumptions

**Given:** A finitely generated abelian group $G$ on which multiplication by every positive integer is surjective.

[F1] A group is finitely generated when some finite subset generates it. [[def-finitely-generated-group]]

[F2] A divisible abelian group is a divisible $\mathbb Z$-module: multiplication by each nonzero integer is surjective. [[def-divisible-module-over-an-integral-domain]]

## Proof

1.1 If the finite generating set is empty then $G=0$. Otherwise choose generators $g_1,\ldots,g_m$. By [F2], for each $i$ choose $h_i\in G$ with $2h_i=g_i$, and write $h_i=\sum_{j=1}^m a_{ij}g_j$ with integers $a_{ij}$. For the column vector $g=(g_1,\ldots,g_m)^T$ and integer matrix $A=(a_{ij})$, these equations give $(I-2A)g=0$. [given, F1, F2, choose, construct]

1.2 Put $M=I-2A$. Since $M\equiv I\pmod 2$, its determinant $d$ is odd and nonzero. Multiplication by the adjugate matrix gives $d g_i=0$ for every generator. Hence $G$ is a quotient of the finite group $(\mathbb Z/|d|\mathbb Z)^m$ and is finite. [step 1.1, algebra]

2.1 Let $N=|G|$. The cosets of the cyclic subgroup generated by any $g\in G$ partition $G$ into sets of equal size, so $Ng=0$. By [F2], multiplication by $N$ is also surjective. It is therefore both the zero map and a surjection, forcing every element of $G$ to be zero. [step 1.2, F2, algebra] ∎

## Axiom use

Only finitely many halves are chosen in step 1.1; finite choice is provable in ZF. The proof uses neither AC nor DC.
