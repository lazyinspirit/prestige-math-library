## Definition

For a left $R$-module $M$, the **socle** is $$\operatorname{Soc}(M):=\sum\{S\le M:S\text{ is simple}\}.$$ Concretely it is the submodule generated by the union of all simple submodules. If there are none, the sum is $0$, so the definition is always meaningful.
