## Statement

Let $B$ be a standard Brownian motion [[def-brownian-motion]] on a probability
space $(\Omega,\mathcal F,P)$. Then there is a process
$\widehat B=(\widehat B_t)_{t\ge0}$ with the following properties.

1. $\widehat B$ is indistinguishable from $B$, and $\widehat B_0=0$ on all of
   $\Omega$.
2. Every path $t\mapsto\widehat B_t(\omega)$ is continuous on $[0,\infty)$, so
   $\omega\mapsto\widehat B(\omega)$ is a map into the path space
   $C([0,\infty),\mathbb R)$ of
   [[def-uniform-on-compacts-metric-on-continuous-path-space]].
3. That map is Borel measurable for the uniform-on-compacts Borel
   $\sigma$-algebra, and $(t,\omega)\mapsto\widehat B_t(\omega)$ is measurable
   for $\mathcal B([0,\infty))\otimes\mathcal F$.

The version is obtained by keeping the original process on one probability-one
event and replacing the whole path by the zero path outside it; no distribution
of $B$ is altered and no path is selected by any choice principle.

## Facts & Assumptions

**Given:** AC and a standard Brownian motion $B$ on $(\Omega,\mathcal F,P)$.

[F1] There is a measurable event $A$ with $P(A)=1$ on which every path $t\mapsto B_t(\omega)$ is continuous, and $B_0=0$ almost surely. [[def-brownian-motion]]

[F2] On $C([0,\infty),\mathbb R)$ the uniform-on-compacts metric induces the topology of uniform convergence on compact subsets of $[0,\infty)$. [[def-uniform-on-compacts-metric-on-continuous-path-space]]

[F3] The Borel $\sigma$-algebra of $C([0,\infty),\mathbb R)$ is generated by the coordinate maps $\pi_t(f)=f(t)$, $t\ge0$. [[lem-borel-sigma-algebra-of-continuous-path-space-is-generated-by-coordinates]]

[F4] The evaluation map $e(f,t):=f(t)$ on $C([0,\infty),\mathbb R)\times[0,\infty)$ is defined for every pair, and it is continuous when the path space carries the uniform-on-compacts topology. [[def-evaluation-map]]

[F5] AC is the ambient assumption of the Brownian interfaces. [[def-axiom-of-choice]]

## Proof

**Proof technique:** direct.

1.1 Put $A':=A\cap\{B_0=0\}$, a measurable event with $P(A')=1$ by [F1], and define $\widehat B_t(\omega):=B_t(\omega)$ for $\omega\in A'$ and $\widehat B_t(\omega):=0$ for $\omega\notin A'$; then $\widehat B$ is indistinguishable from $B$ because it differs from $B$ only on the null set $(A')^c$, and $\widehat B_0(\omega)=0$ for every $\omega$. [given, F1]

1.2 The evaluation map of [F4] is continuous: if $f_m\to f$ in the metric of [F2] and $t_m\to t$ in $[0,\infty)$, choose $N$ with $t_m\le N$ for all $m$ and $|f(s)-f(t)|<\varepsilon/2$ for $|s-t|<\eta$, which is possible because the continuous $f$ is continuous at $t$; convergence in the metric of [F2] gives $\sup_{0\le s\le N}|f_m(s)-f(s)|<\varepsilon/2$ for all large $m$, and then $|f_m(t_m)-f(t)|\le\sup_{0\le s\le N}|f_m(s)-f(s)|+|f(t_m)-f(t)|<\varepsilon$ for all large $m$. [F2, F4]

2.1 Every path of $\widehat B$ is continuous: for $\omega\in A'$ it is the Brownian path, continuous by [F1], and for $\omega\notin A'$ it is the zero path. [step 1.1, F1]

2.2 Each time coordinate of $\widehat B$ is measurable: $\widehat B_t=1_{A'}B_t$ is the product of a measurable indicator with the measurable function $B_t$. [step 1.1]

3.1 The map $\omega\mapsto\widehat B(\omega)$ is a random element of $C([0,\infty),\mathbb R)$ with its Borel $\sigma$-algebra: by [F3] that $\sigma$-algebra is $\sigma(\pi_t:t\ge0)$, and for every $t$ and every Borel $E\subseteq\mathbb R$ one has $\{\omega:\pi_t(\widehat B(\omega))\in E\}=\{\widehat B_t\in E\}$, measurable by [step 2.2]; the family of Borel sets with measurable preimage is a $\sigma$-algebra containing the generating sets $\pi_t^{-1}(E)$, hence all of $\mathcal B(C)$. [step 2.1, step 2.2, F3]

4.1 The pair map $(t,\omega)\mapsto(\widehat B(\omega),t)$ is measurable from $\mathcal B([0,\infty))\otimes\mathcal F$ into the product of the Borel $\sigma$-algebras, because its first component is measurable by [step 3.1] and its second is a coordinate projection; composing with the continuous, hence Borel measurable, evaluation map of [step 1.2] shows that $(t,\omega)\mapsto\widehat B_t(\omega)$ is $\mathcal B([0,\infty))\otimes\mathcal F$-measurable. [step 3.1, step 1.2]

5.1 The boundary cases are covered: the normalization changes the process only on the null set $(A')^c$, so indistinguishability and every almost-sure statement are preserved; the initial value is $0$ on all outcomes as required; the case $t=0$ enters the measurability statements through the coordinate $\widehat B_0$, which is identically zero; and AC enters only through [F5] as the ambient assumption of the Brownian definition. [step 1.1, step 2.1, step 4.1, F5, given] ∎

## Source notes

Durrett, Section 7.1, fixes a continuous version of Brownian motion as part of the definition of the process; Sousi's Chapter 6 treats Brownian motion as a random continuous path. The lemma records the two measurability consequences used later on the page: the path map is a random element of the continuous path space, and the evaluation map makes the process jointly measurable, which is what the Tonelli and Fubini arguments for the zero set and the occupation time need.
