## Statement

**False claim:** Sard's theorem remains true for every $C^1$ map between
arbitrary dimensions.

The differentiability threshold in [[thm-morse-sard-for-euclidean-maps]] is
real. Standard source treatments record Whitney's construction of a $C^1$ map
$\mathbb R^2\to\mathbb R$ whose critical values contain a set of positive
measure, so the naive $C^1$ form of Sard fails once the hypothesis
$r>\max\{m-n,0\}$ is dropped.
