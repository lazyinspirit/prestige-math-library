## Definition

Let $B$ be a Banach space generated by a sequence $(e_j)_{j\ge1}$ that is
linearly independent for finite sums. A linear operator $T$ on the algebraic
span is a **finite-expansion operator** if

$$Te_j=\sum_i a_{ij}e_i$$

where the sum is finite for every fixed $j$. The union of these finite supports
need not be finite. A finite-expansion operator need not have finite rank; when
bounded it extends from the dense algebraic span to $B$.

For a nonempty finite subset $M$ of the generators, define

$$\operatorname{Tr}(M,T):=\sum_{e_i\in M}a_{ii},\qquad \widetilde{\operatorname{Tr}}(M,T):= \frac1{|M|}\operatorname{Tr}(M,T).$$

These are localized diagonal sums relative to the fixed independent generator;
they are not asserted to be representation-independent tensor traces.

The generator has **property A** if for every finite sum
$x=\sum_ja_je_j$ and every participating index $k$,

$$\|x\|\ge |a_k|\,\|e_k\|.$$

For such a finite set $M$, write $[M]$ for its finite-dimensional span and
$\|T\|_{(M)}:=\sup_{0\ne x\in[M]}\|Tx\|/\|x\|$.
