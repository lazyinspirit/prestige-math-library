## Definition

Let $(\mathcal X,\mathcal A,\{P_\theta\}_{\theta\in\Theta})$ be a statistical experiment with nonempty disjoint null and alternative parameter sets $\Theta_0,\Theta_1\subseteq\Theta$. Let $\mathcal S$ be a topological space with its Borel sigma-algebra $\mathcal B(\mathcal S)$, and let $S:\mathcal X\to\mathcal S$ be measurable. Write $\sigma(S):=\{S^{-1}(C):C\in\mathcal B(\mathcal S)\}$, the sigma-algebra generated by $S$ as in [[def-sigma-algebra-generated-by-a-function]]. A possibly randomized test is a measurable function $\varphi:\mathcal X\to[0,1]$ as in [[def-test-size-and-power]]. For each $\theta\in\Theta_0$, a **conditional rejection probability given $S$** is a supplied version $q_\theta$ of $E_\theta[\varphi(X)\mid\sigma(S)]$, where conditional expectation is understood as in [[def-conditional-expectation-given-a-sigma-algebra]]. The test has **conditional level at most $\alpha$ given $S$ on $\Theta_0$** if such versions can be supplied with $q_\theta\le\alpha$ $P_\theta$-almost surely for every $\theta\in\Theta_0$. The almost-sure qualification is separate under each null law; no common null set or pointwise statement at conditioning values of probability zero is asserted.
