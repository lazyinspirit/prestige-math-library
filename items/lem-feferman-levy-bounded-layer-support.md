## Statement

Every hereditarily symmetric name in the Feferman–Levy system is fixed by
$H_m$ for some $m<\omega$. In particular, every real in the symmetric model
$N$ has a name whose Boolean values are all fixed by one such $H_m$.

## Facts & Assumptions

**Given:** The Feferman–Levy system and a generic filter used only to interpret names.

[F1] [[def-feferman-levy-symmetric-collapse-system]] defines the normal filter as the upward closure of the descending family $(H_m)_{m<\omega}$.

[F2] [[thm-forcing-equivalence-and-boolean-completion]] permits passage to the regular-open completion $B=\operatorname{RO}(P)$ without changing the generic extension or valuations.  Its regular-open presentation also lets every order automorphism $\pi$ of $P$ act on $B$ by $U\mapsto\pi``U$.

[F3] [[lem-symmetry-lemma-for-forcing-automorphisms]] transports the forcing relation under every member of the automorphism group.

[F4] [[thm-forcing-theorem]] supplies the truth lemma for the fixed atomic membership formulas in the supplied generic.

## Proof

**Proof technique:** direct support extraction followed by Boolean nice-name replacement.

1.1 Let $\dot x$ be hereditarily symmetric. Its stabilizer belongs to $\mathcal F$. By the definition of the upward closure in F1, some $H_m$ is contained in $\operatorname{sym}(\dot x)$. Thus every $\pi\in H_m$ fixes $\dot x$. Notice that this selects one natural number for one given name; it does not choose supports simultaneously for a family. [F1]

2.1 Now let $x\subseteq\omega$ belong to $N$, and choose one hereditarily symmetric name $\dot x$ with value $x$ in the supplied generic. By step 1.1 fix $m$ such that $H_m$ fixes $\dot x$. In the complete Boolean algebra $B$ from F2 put $b_k=\lVert\check k\in\dot x\rVert_B$ for $k<\omega$ and form the Boolean name $\dot y=\{\langle\check k,b_k\rangle:k<\omega\}$. By F4, the supplied Boolean generic contains $b_k$ exactly when $k\in\dot x_G=x$. Hence $\dot y_G=\{k:b_k\in G\}=x$. This proves equality of the two values in the fixed generic; it does not assert that an arbitrary name which happens to evaluate to a real is forced to be a real in every generic. [F2, F4, step 1.1]

3.1 Make the Boolean action explicit.  In the regular-open presentation from F2, $\widehat\pi(U)=\pi``U$ preserves arbitrary unions followed by regularization, intersections, and complements, and so is a complete Boolean automorphism extending $p\mapsto\pi p$.  The truth value $b_k$ is the regular open generated by conditions forcing $\check k\in\dot x$.  If $\pi\in H_m$, then $\pi\check k=\check k$ and $\pi\dot x=\dot x$; F3 therefore maps that generating set to itself, whence $\widehat\pi(b_k)=b_k$. Hence $H_m$ fixes the displayed Boolean name $\dot y$ and fixes each of its Boolean coefficients. Its only subnames are the canonical natural-number names, so $\dot y$ is hereditarily symmetric. This is the asserted common bounded layer support. [F2, F3, step 2.1] ∎
