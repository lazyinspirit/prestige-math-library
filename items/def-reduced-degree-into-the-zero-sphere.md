## Definition

Write $S^0=\{-1,+1\}=\partial[-1,1]$ for the $0$-sphere
([[def-euclidean-spheres-and-closed-balls]]) and orient it by the boundary
orientation of the interval $[-1,1]$ ([[def-induced-boundary-orientation]]):
the point $+1$ carries the sign $+1$ and the point $-1$ the sign $-1$, since an
orientation of a $0$-manifold is a sign at each point
([[def-oriented-smooth-manifold-and-oriented-chart]]). Let $(P,s)$ be a finite
oriented $0$-manifold, that is, a finite set $P$ together with a sign
$s(x)\in\{+1,-1\}$ for every $x\in P$
([[def-oriented-smooth-manifold-and-oriented-chart]]); it is **balanced** when
$$\sum_{x\in P}s(x)=0.$$
For a **balanced** $(P,s)$ and a map $f:P\to S^0$ — every map is continuous because $P$ is discrete and
$S^0$ is discrete — define the **reduced degree**
$$\deg(f):=\frac{1}{2}\sum_{x\in P}s(x)\,f(x)\in\mathbb Z,$$
the signed count of the values divided by two, where the values
$f(x)\in\{-1,+1\}$ are read in $\mathbb R$. This is well defined: since $f$
takes only the two values $\pm1$, balance gives
$\sum_{f(x)=+1}s(x)=-\sum_{f(x)=-1}s(x)$, hence
$\sum_x s(x)f(x)=2\sum_{f(x)=+1}s(x)$ is even, and replacing $s$ by $-s$
changes the sign of $\deg(f)$ exactly as changing an orientation changes the
ordinary degree ([[def-degree-of-a-map-between-oriented-closed-manifolds]]).

The case $P=S^0$ with the standard orientation above is balanced, and then
$$\deg(f)=\frac{f(+1)-f(-1)}{2}\in\{-1,0,+1\}.$$
This is the induced map on the reduced group
$\widetilde H_0(S^0;\mathbb Z)\cong\mathbb Z$ generated by the difference of
the two point classes ([[def-reduced-homology-theory-and-augmentation]]): the
identity has reduced degree $+1$, the antipodal map $-1$, and the two constant
maps $0$. It is the scalar replacement for the fundamental-class degree of
[[def-degree-of-a-map-between-oriented-closed-manifolds]], whose scalar
definition is stated only for nonempty connected closed oriented manifolds and
therefore does not apply to a source as disconnected as $S^0$.

The motivating balanced sources are boundaries: if $W$ is a compact oriented
smooth $1$-manifold and $\partial W$ carries the induced boundary orientation,
then $\sum_{p\in\partial W}\varepsilon(p)=0$
([[lem-oriented-boundary-of-a-compact-oriented-one-manifold-has-zero-signed-count]]),
so $\partial W$ is balanced and every map $\partial W\to S^0$ has a reduced
degree. No choice principle is used in the definition; the cited boundary-count
lemma assumes $\mathrm{AC}_\omega$.
