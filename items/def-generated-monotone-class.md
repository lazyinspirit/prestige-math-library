## Definition

Let $X$ be a set and $\mathcal E\subseteq\mathcal P(X)$. The **monotone class
generated by $\mathcal E$** is

$$m_X(\mathcal E):=\bigcap\{\mathcal M:\mathcal M\text{ is a monotone class on }X\text{ and }\mathcal E\subseteq\mathcal M\}.$$

Write $m(\mathcal E)$ when $X$ is clear. Its existence as a monotone class and
its minimality are proved in
[[lem-generated-monotone-class-exists-and-is-minimal]].
