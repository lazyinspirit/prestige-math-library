## Definition

Let $\mathcal T$ be a matching simplicial mesh as in
[[def-matching-affine-simplicial-meshes]]. Set $C_{-1}(\mathcal T;\mathbb Z)=0$.
For $0\le k\le d$, let
$C_k(\mathcal T;\mathbb Z)$ be the free abelian group generated by ordered
$k$-faces $[v_0,\ldots,v_k]$, with the orientation relation
$$[v_{\pi(0)},\ldots,v_{\pi(k)}]=\operatorname{sgn}(\pi)[v_0,\ldots,v_k]$$
for every permutation $\pi$. Define $\partial_0:C_0\to C_{-1}$ to be the
zero map. For $1\le k\le d$, define the **simplicial boundary**
homomorphism $\partial_k:C_k\to C_{k-1}$ on a generator by
$$\partial_k[v_0,\ldots,v_k]:=\sum_{j=0}^k(-1)^j [v_0,\ldots,\widehat v_j,\ldots,v_k].$$
This is the oriented incidence convention; no geometric
integration is part of the definition. The identity
$\partial_{k-1}\partial_k=0$ is proved directly from this alternating
formula in the following lemma.
