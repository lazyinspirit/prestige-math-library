## Statement

Let $f : X \to \mathbb{R}$ and $g : X \to \overline{\mathbb{R}}$. Then $g$ is
$\sigma(f)$-measurable if and only if there is a Borel measurable function
$h : \mathbb{R} \to \overline{\mathbb{R}}$ such that

$$g = h \circ f.$$

## Facts & Assumptions

**Given:** Functions $f : X \to \mathbb{R}$ and $g : X \to \overline{\mathbb{R}}$.

[L1] The sigma-algebra generated by $f$ is
$\sigma(f)=\{f^{-1}(B):B \in \mathcal{B}(\mathbb{R})\}$.
([[def-sigma-algebra-generated-by-a-function]])

[L2] Threshold measurability characterizes $\overline{\mathbb{R}}$-valued
measurability.
([[thm-threshold-characterisations-of-real-and-extended-real-measurability]])

## Proof

**Proof technique:** direct.

1.1 If $g=h \circ f$ for a Borel measurable $h$, then for every Borel set [L1]
$B \subseteq \overline{\mathbb{R}}$,

$$(h \circ f)^{-1}(B) = f^{-1}(h^{-1}(B)) \in \sigma(f),$$

because $h^{-1}(B)$ is Borel in $\mathbb{R}$ and [L1] describes exactly the sets
whose preimages under $f$ lie in $\sigma(f)$. So $g$ is $\sigma(f)$-measurable.
[L1]

2.1 Conversely, assume $g$ is $\sigma(f)$-measurable. For each rational [step 1.1, L1, L2, algebra]
$q \in \mathbb{Q}$, the threshold set $\{g \le q\}$ lies in $\sigma(f)$ by [L2],
so [L1] provides a Borel set $A_q \subseteq \mathbb{R}$ with

$$\{g \le q\} = f^{-1}(A_q).$$

Define

$$B_q := \bigcap_{\substack{r \in \mathbb{Q}\\ r>q}} A_r.$$

Then each $B_q$ is Borel, the family $(B_q)_{q \in \mathbb{Q}}$ is increasing in
$q$, and

$$\{g \le q\} = f^{-1}(B_q)$$

for every rational $q$, because
$\{g \le q\}=\bigcap_{r>q,\ r \in \mathbb{Q}}\{g \le r\}$. [L1, L2, algebra]

3.1 For $y \in \mathbb{R}$, define [step 2.1, L2]

$$h(y) := \inf\{\, q \in \mathbb{Q} : y \in B_q \,\},$$

with the infimum taken in $\overline{\mathbb{R}}$, so the empty-set case gives
$+\infty$. Because the sets $B_q$ are increasing,

$$\{y : h(y) \le q\} = B_q \qquad (q \in \mathbb{Q}),$$

so [L2] makes $h$ Borel measurable. [step 2.1, L2]

4.1 Fix $x \in X$ and write $t:=g(x)$. If $q<t$ is rational, then [step 2.1, step 3.1, L2]
$x \notin \{g \le q\} = f^{-1}(B_q)$, so $f(x) \notin B_q$ and therefore
$h(f(x))>q$. If $q \ge t$ is rational, then
$x \in \{g \le q\} = f^{-1}(B_q)$, so $f(x) \in B_q$ and therefore
$h(f(x)) \le q$. Thus $h(f(x))$ is at once at least every rational below $t$
and at most every rational above $t$, which forces $h(f(x))=t=g(x)$. [step 2.1,
step 3.1, L2]

5.1 Steps 1.1 and 4.1 prove the two directions of the equivalence. [step 1.1, step 4.1]
∎
