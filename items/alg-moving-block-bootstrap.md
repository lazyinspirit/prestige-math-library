## Definition

**Input:** observations $x_1,\ldots,x_n$ in a real Hilbert space $H$, and an integer block length $b$ with $1\le b\le n$.

**Output:** a pseudo-series $X_1^*,\ldots,X_n^*$, generated by [[alg-overlapping-block-resampling]]: within each selected block retain the original order and concatenate blocks in their draw order, truncating only the last block when $b\nmid n$. The conditional bootstrap sample mean is $\bar X_n^*=n^{-1}\sum_{t=1}^nX_t^*$. Its conditional center is $E^*\bar X_n^*$, where $E^*$ averages over the independent uniform block starts while the observations remain fixed.

This algorithm specifies the resampling law only. It does not assert that the conditional law approximates the sampling law for any data-generating process or block-length regime.

Under [[def-resampling-sampling-unit-contract]], take each observation $x_t$ to be a complete time-indexed unit record. Each draw selects an ordered group of $b$ consecutive records; the output retains every record of each complete block and only the initial $r=n-b\lfloor n/b\rfloor$ records of the final block when $r>0$. Thus selected length-$b$ groups are not declared indivisible sampling units. Unit compatibility for a stated target requires that block boundaries and final truncation do not split any bundle declared indivisible by that target's sampling or assignment design. This is the sampling-unit interface, not a bootstrap-validity result.
