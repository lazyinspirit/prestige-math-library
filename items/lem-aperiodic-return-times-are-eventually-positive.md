## Statement

Let $p$ be an irreducible aperiodic transition matrix on a nonempty countable
state space $E$ ([[def-aperiodic-chain]]). Then every state $x\in E$ has an
integer $N_x\ge1$ such that
$$p^{(n)}(x,x)>0\qquad\text{for all }n\ge N_x .$$
Consequently, for every $u,v\in E$ there is an integer $N_{u,v}\ge1$ such that
$$p^{(n)}(u,v)>0\qquad\text{for all }n\ge N_{u,v}.$$

## Facts & Assumptions

**Given:** An irreducible aperiodic countable transition matrix $p$ and states $x,u,v$.

[F1] The positive return set is $R_x=\{n\in\mathbb N:n\ge1,\ p^{(n)}(x,x)>0\}$; when $R_x\ne\varnothing$, $d(x)$ is the greatest positive integer dividing every element of $R_x$, and $d(x)=0$ when $R_x=\varnothing$. ([[def-period-of-a-state]])

[F2] For an irreducible matrix the periods $d(x)$ are independent of $x$, the period of the chain is that common value, and the chain is aperiodic exactly when this period is $1$. ([[def-aperiodic-chain]])

[F3] $p^{(r+s)}(x,z)=\sum_{w\in E}p^{(r)}(x,w)p^{(s)}(w,z)$ for all $r,s\ge0$. ([[lem-matrix-chapman-kolmogorov-equations]])

[F4] Accessibility means $x\to y$ exactly when $p^{(n)}(x,y)>0$ for some $n\ge0$, with $p^{(0)}(x,y)=\mathbf 1_{\{x=y\}}$; the matrix is irreducible when every pair communicates. ([[def-accessibility-communication-and-irreducibility]])

[F5] For integers $a,b$, not both zero, $\gcd(a,b)$ is the greatest common divisor of $a$ and $b$, it is a common divisor of both, and $\gcd(a,b)\ge1$. ([[def-common-divisor-and-gcd]])

## Proof

**Proof technique:** direct finite arithmetic: extract a finite subset of the return set with gcd one, then fill every residue class modulo its least element.

1.1 Fix $x\in E$; first, $R_x\ne\varnothing$, so $d(x)\ge1$. If $E=\{x\}$, then $p(x,x)=1$ by row stochasticity, so $1\in R_x$. If $E$ has at least two elements, fix $y\ne x$; by [F4] and irreducibility there are $r,s\ge0$ with $p^{(r)}(x,y)>0$ and $p^{(s)}(y,x)>0$, and since $x\ne y$ the zero-step entries $p^{(0)}(x,y)$, $p^{(0)}(y,x)$ vanish, so $r,s\ge1$. By [F3], $p^{(r+s)}(x,x)\ge p^{(r)}(x,y)p^{(s)}(y,x)>0$, so $R_x\ne\varnothing$. In either case $d(x)$ is a positive integer, and [F2] gives $d(x)=1$. [F1, F2, F3, F4, given]

2.1 A finite $F\subseteq R_x$ with $1$ as its greatest common divisor exists. Start with any $a_1\in R_x$ and let $g:=a_1$. While $g>1$: since $1$ is the greatest positive integer dividing every element of $R_x$ by step 1.1 and [F1], $g$ cannot divide every element of $R_x$, so choose $b\in R_x$ with $g\nmid b$ and replace $g$ by $\gcd(g,b)$; then add $b$ to $F$. By [F5] the new value is a positive common divisor of $g$ and $b$, hence a divisor of $g$, and it is not $g$ because $g\nmid b$; a positive divisor of $g$ different from $g$ is strictly smaller than $g$. The positive integers $g$ strictly decrease at each update while remaining divisors of $a_1$, so the process stops after finitely many updates, and it stops only when $g=1$. The resulting finite set $F\subseteq R_x$ has iterative gcd $1$: every element of $F$ is divisible by no positive integer other than $1$ that also divides all other elements. [F1, F5, step 1.1, given]

3.1 Let $a:=\min F$; then $a\in F$ and $a\ge1$. Let $\langle F\rangle$ be the set of nonnegative integer combinations of the elements of $F$. Every positive element of $\langle F\rangle$ lies in $R_x$: this follows from [F1] and [F3] for sums of two return times, by induction for finite combinations, while the empty combination is $0$ and is excluded. Let $H$ be the set of residues modulo $a$ of the elements of $\langle F\rangle$. Since $a\in F$, the element $a$ has residue $0$, so $H$ is the subgroup of $\mathbb Z/a\mathbb Z$ generated by the residues of the elements of $F$. If $H$ were a proper subgroup, then $H$ would be the set of multiples of $h$ modulo $a$ for some divisor $h$ of $a$ with $1<h\le a$, so $h$ would divide every $f\in F$; as $a\in F$, the integer $h>1$ would then divide every element of $F$, contradicting step 2.1. Hence $H=\mathbb Z/a\mathbb Z$, and for every residue $r$ there is $s_r\in\langle F\rangle$ with $s_r\equiv r\pmod a$. [F1, F3, step 2.1, given]

4.1 Put $N_x:=\max\bigl(1,\max_{0\le r<a}s_r\bigr)$ and fix $n\ge N_x$. Let $r$ be the residue of $n$ modulo $a$. Then $n-s_r$ is a nonnegative multiple of $a$, so $n=s_r+\frac{n-s_r}{a}\,a$ belongs to $\langle F\rangle$ and $n\ge1$. By step 3.1, $p^{(n)}(x,x)>0$. Since $x$ was arbitrary this proves the first assertion. [F3, step 3.1, given]

5.1 Fix $u,v$. By irreducibility [F4] there is $r\ge0$ with $p^{(r)}(u,v)>0$. Put $N_{u,v}:=r+N_v$, where $N_v$ is the threshold of step 4.1 for the state $v$. If $n\ge N_{u,v}$, then $n-r\ge N_v$, so $p^{(n-r)}(v,v)>0$, and [F3] gives $p^{(n)}(u,v)\ge p^{(r)}(u,v)\,p^{(n-r)}(v,v)>0$. If $u=v$ this recovers the first assertion; if $r=0$ then $u=v$. [F3, F4, step 4.1, given]

6.1 Boundary cases. If $E=\varnothing$ the statement is vacuous. The aperiodicity hypothesis is equivalent to $d(x)=1$ by [F2] and is used in step 2.1 to produce a smaller divisor; without it the conclusion can fail (a deterministic two-cycle has $p^{(n)}(x,x)>0$ only for even $n$). The argument uses $R_x\ne\varnothing$, ensured by irreducibility in step 1.1, and positive return times only, so the time-zero entry $p^{(0)}(x,x)=1$ plays no role. All steps are finite assertions about nonnegative entries and integer combinations; no choice principle, limit or renewal theorem is used, the display $p^{(n)}$ for $n=0$ is the identity entry, and both assertions are one-way implications. [F1, F2, F3, F4, step 1.1, step 5.1, given] ∎
