## Definition

Fix a triangular decomposition $\mathfrak g=\mathfrak n^-\oplus \mathfrak h\oplus \mathfrak n^+$ from [[thm-triangular-decomposition-from-a-chosen-positive-root-system]]. Let $M$ be a $\mathfrak g$-module and let $\lambda\in \mathfrak h^*$. A nonzero vector $v\in M$ is a **highest-weight vector of weight $\lambda$** when

$$hv=\lambda(h)v \qquad (h\in \mathfrak h), \qquad \mathfrak n^+v=0.$$

A $\mathfrak g$-module $M$ is a **cyclic highest-weight module of highest weight $\lambda$** when it is generated by such a vector $v$.
