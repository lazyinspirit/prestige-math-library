## Statement

Let $(\mathcal X,\mathcal A)$ and $(\mathcal S,\mathscr S)$ be standard Borel spaces as in [[def-standard-borel-space]]. Fix Polish topologies realizing these specified Borel sigma-algebras, as the standard-Borel definition permits. Let $\Theta_0,\Theta_1$ be nonempty disjoint parameter subsets, and write $\{P_\eta:\eta\in\Theta_0\}$ for the null subfamily. Let $S:\mathcal X\to\mathcal S$ be measurable. Suppose there is one probability kernel $K(s,\cdot)$ such that, for every $\eta\in\Theta_0$, $K(S,\cdot)$ is a regular conditional distribution of the full data $X$ given $\sigma(S)$ under $P_\eta$. This is the common-kernel premise of sufficiency for the null subfamily in [[def-sufficient-statistic]]. For any measurable $\varphi:\mathcal X\to[0,1]$, define
$$q(s):=\int_{\mathcal X}\varphi(x)K(s,dx).$$
Then $q$ is measurable and $q(S)$ is a version of the conditional rejection probability of $\varphi$ given $S$ under every $P_\eta$. The same function $q$ works for every nuisance value, with conditional-expectation identities interpreted almost surely under each corresponding law.

## Facts & Assumptions

**Given:** The spaces, null family, statistic, common probability kernel and bounded test function in the Statement.

[A1] For every $\eta\in\Theta_0$, the same kernel $K(S,\cdot)$ satisfies the conditional event-integral identities for $X$ given $S$ under $P_\eta$, which is the common-kernel sufficiency condition in [[def-sufficient-statistic]].

[F1] A conditional law $K(s,\cdot)$ of a random element given $S$ composes with $S$ to give a regular conditional distribution given $\sigma(S)$. [[def-conditional-law-given-a-random-element]]

[F2] Integrating a product-measurable function against a probability kernel gives a measurable function of the kernel parameter. [[thm-measurability-of-integration-against-a-kernel]]

[F3] If $K(S,\cdot)$ is a supplied regular conditional distribution of $X$ given $\sigma(S)$, then $\int f(x)K(S,dx)$ satisfies the conditional event-integral identities for nonnegative measurable $f$; for integrable real $f$ its signed integral is a conditional-expectation version. [[thm-conditional-integration-through-a-regular-conditional-law]]

[F4] A conditional test's rejection probability given $S$ is a conditional-expectation version of $\varphi(X)$. [[def-conditional-test-given-statistic]]

[F5] The product sigma-algebra is generated by rectangles, so the second-coordinate projection is measurable; composing it with measurable $\varphi$ makes $(s,x)\mapsto\varphi(x)$ product-measurable. [[def-product-sigma-algebra-and-finite-product-sigma-algebras]], [[thm-composition-with-borel-functions-preserves-measurability]]

## Proof

1.1 The map $(s,x)\mapsto\varphi(x)$ is product-measurable by [F5]. Kernel integration [F2] therefore makes $q$ measurable. Since $K(s,\cdot)$ is a probability measure and $0\le\varphi\le1$, every value satisfies $0\le q(s)\le1$. [F2, F5, given]

2.1 Fix $\eta\in\Theta_0$. By [A1] and [F1], $K(S,\cdot)$ is a regular conditional distribution of $X$ given $\sigma(S)$ under $P_\eta$. Applying [F3] to the bounded function $\varphi$ shows that for every $A\in\sigma(S)$, $\int_A q(S)\,dP_\eta=\int_A\varphi(X)\,dP_\eta$. Thus $q(S)$ is a version of the conditional rejection probability under this null law. The same kernel in [A1] defines the same $q$ for every $\eta$, proving nuisance-freeness; only the individual laws' almost-sure qualifications are used. [A1, F1, F3, F4, step 1.1] ∎
