## Statement

Let $R$ be a commutative ring and let $M$ be a finitely presented $R$-module.
Then for every $k\ge0$ the elementary ideal $E_k(M)$ of
[[def-elementary-ideals-of-a-finitely-presented-module]] is independent of the
chosen finite presentation of $M$; in particular it is an invariant of the
isomorphism class of $M$, and isomorphic modules have the same elementary
ideals.

## Facts & Assumptions

**Given:** A commutative ring $R$, a finitely presented $R$-module $M$ and an
integer $k\ge0$. No choice principle is used.

[F1] For a presentation $R^m\xrightarrow{A}R^n\to M\to0$ with $m,n$ finite,
$E_k(M)$ is the ideal generated by all $(n-k)\times(n-k)$ minors of $A$, with
$E_k(M)=R$ for $k\ge n$ and $E_k(M)=0$ for $k<n-m$
([[def-elementary-ideals-of-a-finitely-presented-module]]).

[F2] For a finitely generated module $N$ presented as $R^{(J)}\xrightarrow{\varphi}R^n\to N\to0$ with $n$ finite and $J$ arbitrary, the ideal $I_{n-k}(\varphi)$ generated by the $(n-k)\times(n-k)$ minors depends only on $N$ and the fixed integer $k$, not on the presentation; it is written $\operatorname{Fitt}_k(N)$. The conventions are $I_r=R$ for $r\le0$ and $I_r=0$ when there are no $r\times r$ minors. In particular the minor size changes when the number of presentation generators changes. Fitting ideals are compatible with base change ([[lem-fitting-ideals-presentation-independent]]).

[F3] A finitely presented module $M$ is finitely generated and admits a
presentation $R^m\to R^n\to M\to0$ with $m,n$ finite; the cokernel of the
presentation map is $M$
([[def-finitely-presented-module-and-algebra]],
[[def-module-homomorphism-kernel-image-and-cokernel]],
[[def-generated-cyclic-finitely-generated-and-free-modules]]).

[F4] An isomorphism $u:M\to M'$ of $R$-modules carries a presentation
$R^m\to R^n\to M\to0$ to the presentation
$R^m\to R^n\xrightarrow{u\circ\beta}M'\to0$ with the same presentation matrix;
hence isomorphic modules admit presentations with identical matrices. [F3, given]

## Proof

1.1 **Identification with the Fitting indexing.** Given a finite presentation of $M$ with presentation matrix $A$ of size $n\times m$, [F1] defines $E_k(M)$ as the ideal generated by the $(n-k)\times(n-k)$ minors of $A$, with the values $R$ for $n-k\le0$ and $0$ when $n-k$ exceeds the number $m$ of columns. This is exactly the ideal $I_{n-k}(A)$ of [F2] for the same presentation (whose index set $J$ is finite of size $m$), including both conventions; hence $E_k(M)=I_{n-k}(A)=\operatorname{Fitt}_k(M)$ for every finite presentation of $M$. [F1, F2, F3]

2.1 **Independence and isomorphism invariance.** By [F2] the value $I_{n-k}(A)$ is independent of the presentation, so by step 1.1 $E_k(M)$ is independent of the chosen finite presentation. If $u:M\to M'$ is an isomorphism, [F4] transports any finite presentation of $M$ to one of $M'$ with the same matrix, so the two ideals agree. This proves the statement. [F2, F4, step 1.1] ∎
