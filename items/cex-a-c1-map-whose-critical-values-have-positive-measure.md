## Statement refuted

**False claim:** every $C^1$ map has critical values of measure zero.

Whitney's classical construction gives a $C^1$ map
$f:\mathbb R^2\to\mathbb R$ whose critical values contain a set of positive
measure. That source-backed phenomenon is the concrete counterexample behind
[[fs-sard-theorem-holds-for-every-c1-map-between-arbitrary-dimensions]]; this
item records the example honestly without pretending to reconstruct Whitney's
construction inside the current page.
