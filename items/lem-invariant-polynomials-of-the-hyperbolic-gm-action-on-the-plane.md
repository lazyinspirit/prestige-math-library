## Statement

Let $\mathbf G_m=\mathbb C^\times$ act on $\mathbb C^2$ by
$t\cdot(x,y)=(tx,t^{-1}y)$ ([[def-rational-action-on-affine-variety]]). Then
the invariant subring of $\mathbb C[x,y]$
([[def-classical-affine-coordinate-ring]]) is
$\mathbb C[x,y]^{\mathbf G_m}=\mathbb C[xy]$, a polynomial ring in one
variable; explicitly, a polynomial $f=\sum_{a,b}c_{ab}x^ay^b$ is invariant if
and only if $c_{ab}=0$ for every pair with $a\neq b$
([[def-monomials-multidegree-and-total-degree]]).

## Facts & Assumptions

**Given:** the multiplicative group $\mathbf G_m=\mathbb C^\times$ acting on
$\mathbb C^2$ by $t\cdot(x,y)=(tx,t^{-1}y)$, and a polynomial
$f=\sum_{a,b}c_{ab}x^ay^b\in\mathbb C[x,y]$ written in its unique finite
monomial expansion.

[F1] *The action and the action on functions.* The map
$t\cdot(x,y)=(tx,t^{-1}y)$ is an algebraic action of $\mathbf G_m$ on the
affine plane, and the induced left action on functions is
$(t\cdot f)(p)=f(t^{-1}\cdot p)$, so that $(t\cdot f)(x,y)=f(t^{-1}x,ty)$
([[def-rational-action-on-affine-variety]]).

[F2] *Unique monomial expansion.* Every polynomial in $F[x_1,\dots,x_n]$ has a
unique finite expansion $f=\sum_{\mathbf t}c_{\mathbf t}x^{\mathbf t}$ over
finitely many multi-indices; in particular the monomials are linearly
independent over $F$ and a polynomial is zero exactly when all its
coefficients vanish ([[def-monomials-multidegree-and-total-degree]]).

[F3] *The coordinate ring of the plane.* For an affine algebraic set
$X\subseteq k^n$ the coordinate ring is $k[X]=k[x_1,\dots,x_n]/I(X)$; for
$X=\mathbb C^2$ this is $\mathbb C[x,y]$, with $x$ and $y$ the coordinate
functions ([[def-classical-affine-coordinate-ring]]).

## Proof

**Proof technique:** direct.

1.1 For $t\in\mathbf G_m$ and a monomial $x^ay^b$ the function action of [F1] gives $(t\cdot(x^ay^b))(x,y)=(t^{-1}x)^a(ty)^b=t^{b-a}x^ay^b$, so the multiplicative group acts on each monomial by the scalar $t^{b-a}$: monomials on the diagonal $a=b$ are fixed, while off-diagonal monomials are scaled by a nonconstant character. [F1]

2.1 An element $f=\sum_{a,b}c_{ab}x^ay^b\in\mathbb C[x,y]$ is invariant under $\mathbf G_m$ if and only if $\sum_{a,b}c_{ab}(t^{b-a}-1)x^ay^b=0$ for every $t\in\mathbf G_m$; by step 1.1 this is the difference between $t\cdot f$ and $f$, and by uniqueness of the monomial expansion it holds if and only if $c_{ab}t^{b-a}=c_{ab}$ for all pairs $(a,b)$ and all $t\in\mathbf G_m$. [F1, F2, step 1.1]

3.1 The coefficient conditions hold if and only if $c_{ab}=0$ for every pair with $a\neq b$. If $f$ is invariant, fix a pair with $a\neq b$; evaluating the condition of step 2.1 at the nonzero complex number $t=2$ gives $c_{ab}(2^{b-a}-1)=0$, and $2^{b-a}\neq1$ because $2^{b-a}>1$ for $b>a$ and $0<2^{b-a}<1$ for $b<a$; hence $c_{ab}=0$. Conversely, if $c_{ab}=0$ whenever $a\neq b$, then $f=\sum_ac_{a}x^ay^a$ is a sum of diagonal monomials, and by step 1.1 each such monomial satisfies $t\cdot(x^ay^a)=t^{a-a}x^ay^a=x^ay^a$, so $t\cdot f=f$ for every $t$ and $f$ is invariant. [F2, step 2.1]

4.1 Consequently a polynomial $f\in\mathbb C[x,y]$ is $\mathbf G_m$-invariant if and only if its expansion has no off-diagonal terms, that is, if and only if $f=\sum_ac_ax^ay^a$ lies in the subalgebra $\mathbb C[xy]$ generated by the invariant function $xy$. Hence $\mathbb C[x,y]^{\mathbf G_m}=\mathbb C[xy]$. The substitution $\varphi:\mathbb C[z]\to\mathbb C[x,y]$, $z\mapsto xy$, is injective: if $\varphi(g)=0$ for $g=\sum_nd_nz^n$, then $\sum_nd_nx^ny^n=0$, and uniqueness of the monomial expansion forces every $d_n=0$, so $g=0$. Therefore $\mathbb C[xy]\cong\mathbb C[z]$ is a polynomial ring in one variable, and the plane's invariant ring is $\mathbb C[xy]$. [F2, F3, step 3.1] ∎

## Remarks

- This is the invariant computation behind Brion's Example 1.27(2): the
  quotient of $\mathbb C^2$ by the hyperbolic $\mathbf G_m$-action is the
  affine line with coordinate $xy$. The companion example uses exactly this
  lemma to identify the invariant ring with $\mathbb C[xy]$ and to describe the
  quotient map $(x,y)\mapsto xy$; that the raw level set $\{xy=0\}$ contains
  both the origin and the two coordinate axes is the phenomenon behind the
  stable-locus analysis there.
- No choice is used: a single test value $t=2$ already separates every
  off-diagonal monomial from the invariant ones, so no infinite family of
  excluded values has to be avoided.
