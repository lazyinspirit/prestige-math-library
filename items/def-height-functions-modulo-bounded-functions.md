## Definition

For a set $S$, let $\mathbb R^S$ be the additive group of real-valued functions on $S$, and let $B(S)\subseteq\mathbb R^S$ be the subgroup of bounded functions. The group of functions modulo bounded functions is $\mathbb R^S/B(S)$. Two functions $f,g:S\to\mathbb R$ represent the same class precisely when $f-g$ is bounded on all of $S$.
