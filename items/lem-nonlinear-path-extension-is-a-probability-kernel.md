## Statement

Let $T\ge0$ be finite, let $(\mathsf Z_t,\mathcal Z_t)$ be standard-Borel
spaces for $0\le t\le T$, and for $1\le t\le T$ let
$M_t:\mathsf Z_{t-1}\rightsquigarrow\mathsf Z_t$ be probability kernels,
with the kernel convention of
[[def-measure-kernel-and-probability-kernel]]. For $1\le t\le T$, define the path-extension kernel
from $\mathsf Z_{0:t-1}$ to $\mathsf Z_{0:t}$ by
$$\overline M_t(z_{0:t-1},A)=\int_{\mathsf Z_t}\mathbf1_A(z_{0:t-1},z_t)M_t(z_{t-1},dz_t).$$
Then $\overline M_t$ is a probability kernel and $\mathsf Z_{0:t}$ is
standard Borel. Its ordered iterates append the nonlinear states with the
original transition law.

## Facts & Assumptions

**Given:** The nonlinear path spaces, transition kernels, and definition in the Statement.

[F1] Each $\mathsf Z_t$ is standard Borel, meaning measurably isomorphic to a Polish space, and each $M_t$ is a probability kernel. [[def-standard-borel-space]] [[def-measure-kernel-and-probability-kernel]]

[F2] Finite products of standard-Borel spaces, with the finite-product sigma-algebra, are standard Borel. [[lem-finite-products-of-standard-borel-spaces-are-standard-borel]]

[F3] The finite-product sigma-algebra is generated by measurable coordinate rectangles. [[def-product-sigma-algebra-and-finite-product-sigma-algebras]]

[F4] Kernel sections are measures, probability sections have mass one, and their set evaluations are measurable. [[def-measure-kernel-and-probability-kernel]]

[F5] Integrating a nonnegative product-measurable function against a probability kernel gives a measurable function of the source point. [[thm-measurability-of-integration-against-a-kernel]]

## Proof

**Given:** The hypotheses in the Statement.

1.1 By [F2], both finite path spaces carry their stated product sigma-algebras and the target path space is standard Borel. Fix a prefix $z_{0:t-1}$. The append map $j_{z_{0:t-1}}(z_t)=(z_{0:t-1},z_t)$ is measurable: the inverse image of a generating rectangle is either empty or the final-coordinate measurable set, and [F3] generates the target sigma-algebra from these rectangles. Thus $A\mapsto M_t(z_{t-1},j_{z_{0:t-1}}^{-1}(A))$ is the pushforward of the probability measure $M_t(z_{t-1},\cdot)$ and is a probability measure. [F1, F2, F3, F4, given]

2.1 The projection $z_{0:t-1}\mapsto z_{t-1}$ is measurable, so composing each set-evaluation map $z_{t-1}\mapsto M_t(z_{t-1},B)$ with this projection gives a probability kernel from the prefix space to $\mathsf Z_t$. The function $(z_{0:t-1},z_t)\mapsto\mathbf1_A(z_{0:t-1},z_t)$ is product-measurable. By [F5], its integral against this composed kernel is measurable in the prefix. Together with step 1.1, this proves that $\overline M_t$ has probability-measure sections and measurable set evaluations, hence is a probability kernel. Iterating the definition appends each state using exactly $M_t$ because at each step the indicator is evaluated on the already fixed prefix and the new coordinate. [F1, F3, F4, F5, step 1.1] ∎
