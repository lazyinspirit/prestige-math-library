## Statement

For a number field $K$ and its ring of integers $R=\mathcal O_K$, every element of $\operatorname{SL}_\infty(R)/E_\infty(R)$ has finite order. Here $E_\infty(R)$ is generated by the stabilized transvections $I+xE_{ij}$, $i\ne j$. This is a torsion assertion, not a claim of a uniform exponent, finite group, or vanishing. The proof requires no axiom of choice.

## Facts & Assumptions

**Given:** A number field K, its integer ring R, and one element of the displayed quotient.

[F1] Every stable special-linear matrix is elementary equivalent to a 2×2 special-linear matrix. [[lem-number-ring-stable-special-linear-reduces-to-sl2]]

[F2] The quotient of R by any nonzero integral ideal is finite. [[lem-nonzero-number-field-ideal-has-finite-quotient]]

[F3] The stable elementary group is the kernel of the stable general-linear abelianization. [[lem-quillen-q-components-and-stable-elementary-perfectness]]

## Proof

**Proof technique:** Explicit 3×3 Mennicke product and one finite residue-unit order.

1.1 By [F1], represent the given class by A=(a b; c d) in SL₂(R), with ad−bc=1. Its stable class depends only on (a,b): if A′ has the same first row, write A′A⁻¹=(1 0; t 1), since its first row is (1,0) and its determinant is 1. Denote this class by [a,b]. Right multiplication by the transvection I+xE₁₂ changes b to b+xa, so [a,b]=[a,b+xa]. Conjugation by diag(−1,1,−1), an element of the stable general-linear group, changes the first row (a,b) to (a,−b) after stabilization and does not change the class in the abelian quotient of [F3]. If b is a unit, a finite pivot-and-clear sequence makes A elementary; use a signed elementary permutation to move that unit to the first pivot and clear the other entries. The remaining diagonal diag(u,u⁻¹) equals w(u)w(−1), where w(u)=E₁₂(u)E₂₁(−u⁻¹)E₁₂(u); multiplying these three transvections gives (0 u;−u⁻¹ 0). The same argument applies if a is a unit. All matrices and operations are finite. [F1, F3, given, construct, algebra]

2.1 Let A₁=(a b₁; c₁ d₁) and A₂=(a b₂; c₂ d₂) be two matrices in SL₂(R). In the stable quotient, A₂ has the class of D₂=((d₂,0,−c₂),(0,1,0),(−b₂,0,a)): its nontrivial 2×2 block is A₂^(−t), conjugate to A₂ by the signed permutation J=(0 1;−1 0), and moving that block to rows and columns 1 and 3 is another signed permutation conjugation. This is legitimate in the abelian quotient [F3]. Multiply diag(A₁,1) by D₂. Add c₂ times its third row to its first; because ad₂−b₂c₂=1, the first row becomes (1,b₁,0). Subtract b₁ times the first column from the second and then clear the entries under the resulting top-left 1 by row additions. The remaining 2×2 block is N=((d₁−b₁c₁d₂,−c₁c₂),(b₁b₂,a)); its determinant is a d₁−b₁c₁(ad₂−b₂c₂)=1. Conjugate this block by J: its first row is (a,−b₁b₂). The sign-invariance from step 1.1 changes that to (a,b₁b₂). Therefore [a,b₁][a,b₂]=[a,b₁b₂]. Each equality is obtained from the displayed matrices by finite row operations and stable conjugations. [F3, step 1.1, construct, algebra]

3.1 If a=0 then b is a unit by ad−bc=1, so step 1.1 gives the identity class. If a≠0, [F2] says R/(a) is finite; the image of b is a unit since −bc≡1 modulo a. Its order is a positive integer r, so bʳ=1+ta for some t∈R. Iterating the multiplicativity of step 2.1 gives [a,b]ʳ=[a,bʳ]=[a,1+ta]=[a,1]=1, using step 1.1 for the last two equalities. The finite residue ring, the one order r and its witnesses are chosen for this one matrix; no uniform bound or global choice is used. [F2, step 1.1, step 2.1, construct, algebra]

4.1 Every quotient element has a representative A by step 1.1 and has finite order by step 3.1. Retain that finite construction. The argument does not assert any common exponent or that the quotient itself is finite or zero. [F1, step 1.1, step 3.1, construct, algebra, discharge-construct] ∎
