## Definition

Let $(\Theta,\mathcal T)$, $(\mathsf X,\mathcal A)$, and
$(\mathsf Z,\mathcal C)$ be measurable spaces (sets equipped with
sigma-algebras; [[def-measurable-space]]). Let $\nu$ and $\mu$ be sigma-finite
reference measures on the observation and latent spaces; each has a countable
measurable cover by sets of finite measure
([[def-finite-sigma-finite-and-semifinite-measures]]). The finite product
sigma-algebra is generated by measurable rectangles
([[def-product-sigma-algebra-and-finite-product-sigma-algebras]]). The product
reference measure $\nu\otimes\mu$ is the one supplied by
[[thm-sigma-finite-product-measure-exists-is-rectangular-and-is-unique]].

A **jointly measurable latent-variable density** is a specified function
$$p:\Theta\times\mathsf X\times\mathsf Z\longrightarrow[0,\infty]$$
measurable for $\mathcal T\otimes\mathcal A\otimes\mathcal C$ and normalized
on every parameter fibre:
$$\int_{\mathsf X\times\mathsf Z}p(\theta,x,z)\, (\nu\otimes\mu)(d(x,z))=1\qquad(\theta\in\Theta).$$
Here $x$ is the observed coordinate and $z$ the latent coordinate. The
observed marginal density is
$$m(\theta,x):=\int_{\mathsf Z}p(\theta,x,z)\,\mu(dz).$$
The valid-fibre set is
$V:=\{(\theta,x):0<m(\theta,x)<\infty\}$. Only on $V$ define the normalized
latent-fibre density
$$q(z\mid\theta,x):=\frac{p(\theta,x,z)}{m(\theta,x)}.$$
This definition requires a single jointly measurable density as an input.
[[def-likelihood-density]] supplies neither a sigma-algebra on $\Theta$ nor
joint parameter measurability from separately specified likelihood sections;
the joint measurability above is an additional hypothesis. Because $p$ is
already supplied as one joint function, this definition uses no choice axiom.
It does not assert that AC can turn separately specified pointwise likelihood
versions into a jointly measurable version. No quotient or pointwise
conditional density is asserted on a zero or infinite marginal fibre.
