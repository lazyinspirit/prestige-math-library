## Statement

An **atom** of $B$ is a nonzero element with no strictly smaller nonzero element. If $B$ is a finite Boolean algebra and $A$ is its set of atoms, the map

$$b\longmapsto\{a\in A:a\le b\}$$

is a Boolean isomorphism $B\to\mathcal P(A)$. Each nonzero element contains an atom. Every ultrafilter is $\{b:a\le b\}$ for a unique atom $a$. This holds in ZF, including the trivial algebra.

## Facts & Assumptions

[F1] [[def-boolean-algebra-for-stone-duality]] supplies the bounded distributive lattice and complement laws, allowing $0=1$.

[F2] [[lem-generated-boolean-filter-and-ultrafilter-tests]] identifies ultrafilters with proper filters deciding complementary pairs.

## Proof

**Given:** A finite Boolean algebra $B$ and its set $A$ of atoms.

1.1 For $b\ne0$, the finite nonempty set $\{c:0<c\le b\}$ has a minimal member: a strict descending sequence cannot have more distinct terms than this finite set. Such a minimal member is an atom. If atoms $a,d$ have nonzero meet, minimality gives $a\wedge d=a=d$. Thus distinct atoms are disjoint. [F1, given, algebra]

2.1 Put $s=\bigvee\{a\in A:a\le b\}$. This finite join is at most $b$. If $b\wedge\neg s\ne0$, step 1.1 gives an atom $d\le b\wedge\neg s$. Then $d\le b$ puts $d\le s$, contradicting $d\le\neg s$ and $d\ne0$. Hence $b=s$. [F1, step 1.1, algebra]

3.1 Write $\phi(b)=\{a\in A:a\le b\}$. Meets correspond to intersections by the definition of lower bound. For an atom $a$, the equation $a=(a\wedge b)\vee(a\wedge\neg b)$ implies exactly one of $a\le b$ and $a\le\neg b$, since each piece is $0$ or $a$. Therefore complements correspond to set complements, and joins correspond to unions by De Morgan's law; bounds correspond to $\varnothing,A$. Step 2.1 proves injectivity. For $T\subseteq A$, distinct-atom disjointness gives $\phi(\bigvee T)=T$: an atom outside $T$ meets that finite join in $0$. This proves surjectivity. If $B$ is trivial, $A=\varnothing$ and both algebras have one element. [F1, step 1.1, step 2.1, algebra]

4.1 For an ultrafilter $U$, finiteness makes $a=\bigwedge U$ a member of $U$, so $a\ne0$ and $U=\{b:a\le b\}$. If $0<c<a$, then $c\notin U$, so F2 gives $\neg c\in U$ and $a\le\neg c$, contradicting $0<c\le a$. Hence $a$ is an atom. Conversely the upward filter generated by an atom is proper and decides every pair by step 3.1, so F2 makes it an ultrafilter. Two atoms generating the same filter each lie above the other and are equal. QED. [F1, F2, step 3.1, algebra]
