## Definition

Let $X$ be a smooth vector field on $M$.

A **local flow** of $X$ consists of an open set $\mathcal D\subseteq\mathbb R\times M$
containing $\{0\}\times M$ and a smooth map $\Phi:\mathcal D\to M$ such that:

1. $\Phi(0,p)=p$ for every $p\in M$;
2. for each $p$, the fibre $\mathcal D_p:=\{t:(t,p)\in\mathcal D\}$ is an
   interval;
3. for each $p$, the curve $t\mapsto \Phi(t,p)$ is an integral curve of $X$ on
   $\mathcal D_p$;
4. whenever both sides are defined,
   $\Phi(t,\Phi(s,p))=\Phi(t+s,p)$.

If $\mathcal D=\mathbb R\times M$, then $\Phi$ is the **global flow** of $X$.
