## Example

Let $E=\mathbb R\alpha$ be a Euclidean line and $\Phi=\{\alpha,-\alpha\}$ with
$(\alpha,\alpha)=1$. Then $\Phi$ is the reduced crystallographic root system
$A_1$; its Weyl group has order $2$, its only base is $\{\alpha\}$, and its
Cartan matrix is the $1\times1$ matrix $[2]$.

## Facts & Assumptions

**Given:** A Euclidean line $E=\mathbb R\alpha$ with $\alpha\ne0$ and the set $\Phi=\{\alpha,-\alpha\}$.

[L1] A reduced crystallographic root system is a finite spanning set of nonzero vectors closed under its root reflections with integral Cartan integers and reducedness ([[def-reduced-crystallographic-euclidean-root-system]]).

[L2] The reflection $s_\alpha$ negates $\alpha$, the Weyl group is the subgroup of $O(E)$ generated by the root reflections, and the Cartan matrix of a base $\{\alpha\}$ is the $1\times1$ matrix with entry $2(\alpha,\alpha)/(\alpha,\alpha)=2$ ([[def-weyl-group-of-a-root-system]], [[def-cartan-matrix-of-a-based-root-system]]).

## Verification

**Proof technique:** direct.

1.1 $\Phi$ is finite, spans $E$, omits $0$, and $\mathbb R\alpha\cap\Phi=\{\pm\alpha\}$; the reflection $s_\alpha$ sends $\alpha$ to $-\alpha$ and $-\alpha$ to $\alpha$, so $s_\alpha(\Phi)=\Phi$; the only Cartan integers are $2(\pm\alpha,\pm\alpha)/(\alpha,\alpha)=\pm2$, which are integers. Hence $\Phi$ is a reduced crystallographic root system. [L1, algebra]

2.1 The Weyl group is $\{1,s_\alpha\}$ of order $2$, and with the base $\{\alpha\}$ the Cartan matrix is $[2]$ by [L2]. This is the rank-one system $A_1$. [L2, step 1.1, algebra] ∎
