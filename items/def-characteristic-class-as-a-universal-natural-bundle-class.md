## Definition

Fix a commutative unital ring $R$ and an integer $k\geq0$. Throughout this page
an **admissible base** is a paracompact Hausdorff space of CW type, that is, a
space homotopy equivalent to a CW complex; every CW complex is admissible. This
is the class on which the general Thom and Gysin theorems of this page are
stated. The **classification-scope** bases are the paracompact Hausdorff CGWH
spaces of the published classification theorems, and every CW complex belongs
to both classes; a classification statement is invoked only over a base in
that scope. An **admissible bundle** is a numerable finite-rank real or complex
vector bundle over an admissible base; pullback of an admissible bundle along
a continuous map of admissible bases is numerable, with the pulled-back linear
charts and the composed partition of unity. Let
$\mathbb F\in\{\mathbb R,\mathbb C\}$.

A **degree-$k$ characteristic class for rank-$n$ $\mathbb F$-bundles with
values in $R$** is an assignment $c$ that sends each isomorphism class of
numerable rank-$n$ $\mathbb F$-bundles $E\to B$ over a base $B$ that is both
admissible and in the classification scope — in particular over every CW
complex — to a class $c(E)\in H^k(B;R)$ and satisfies:

1. **pullback naturality**: $c(f^*E)=f^*c(E)$ for every continuous
   $f:B'\to B$ between such bases;
2. **isomorphism invariance**: $c(E)=c(E')$ whenever $E\cong E'$ over the
   identity, so that the assignment is well defined on the isomorphism class
   named in the first clause.

The total space of a numerable bundle with compact fiber over an admissible
base is again admissible, by
[[lem-compact-fibre-numerable-bundle-totals-are-paracompact-hausdorff-of-cw-type]];
this is what lets the projective and flag constructions of this page be
iterated over their own total spaces.

For real bundles the universal object is the tautological bundle
$\gamma_n\to B\operatorname O(n)=\operatorname{Gr}_n(\mathbb R^\infty)$, for
complex bundles it is $\gamma_n^{\mathbb C}\to B\operatorname U(n)=
\operatorname{Gr}_n(\mathbb C^\infty)$, and for oriented real bundles it is
$\gamma_n^+\to B\operatorname{SO}(n)=\operatorname{Gr}_n^+(\mathbb R^\infty)$.
These are the chosen classifying-space models of
[[def-stiefel-space-grassmannian-and-tautological-bundle]] and
[[def-oriented-grassmannian-and-tautological-oriented-bundle]]. The definition
claims, and the Verification proves, that a degree-$k$ characteristic class is
equivalently a single class
$$u\in H^k(B\operatorname O(n);R),\quad u\in H^k(B\operatorname U(n);R),\quad\text{or}\quad u\in H^k(B\operatorname{SO}(n);R)$$
of the corresponding universal bundle, the correspondence being
$u\mapsto\bigl(E\mapsto c_E^*u\bigr)$ for a classifying map $c_E$ of $E$, and
$c\mapsto c(\gamma)$ in the reverse direction. Thus every characteristic class
on this page is generated by one universal class.

## Facts & Assumptions

**Given:** AC, a commutative unital ring $R$, an integer $k\geq0$, a rank $n\geq0$, and $\mathbb F\in\{\mathbb R,\mathbb C\}$, together with the classifying-space models named above.

[F1] Under AC, pullback of the tautological bundle gives natural bijections $[X,\operatorname{Gr}_n(\mathbb F^\infty)]\cong\operatorname{Vect}^{\mathbb F}_n(X)$ on paracompact Hausdorff CGWH spaces $X$, with isomorphism classes of numerable rank-$n$ bundles on the right ([[thm-real-and-complex-vector-bundles-are-classified-by-stable-grassmannians]]).

[F2] Under AC, pullback of $\gamma_n^+$ gives a natural bijection $[X,\operatorname{Gr}_n^+(\mathbb R^\infty)]\cong \operatorname{Vect}^{\mathbb R,+}_n(X)$ on paracompact Hausdorff CGWH spaces, the right side consisting of orientation-preserving isomorphism classes of numerable oriented rank-$n$ real bundles ([[thm-oriented-real-vector-bundles-are-classified-by-bso]]).

[F3] Homotopic maps induce the same map on singular cohomology for every abelian coefficient group ([[thm-homotopic-maps-induce-equal-maps-in-singular-cohomology]]).

[F4] Singular cohomology is contravariantly functorial: $f^*g^*=(gf)^*$ and $\operatorname{id}^*=\operatorname{id}$ ([[prop-singular-cohomology-is-contravariantly-functorial]]).

[A1] AC is the Axiom of Choice in the form fixed by [[def-axiom-of-choice]].

## Verification
1.1 Every universal class gives a characteristic class. Let $u$ be a class of $\gamma_n$ on $BG$, where $BG$ is one of the three Grassmannian models. For a numerable bundle $E\to B$ over a base in both classes choose a classifying map $c_E$, that is, $c_E^*\gamma_n\cong E$; such a map exists by [F1] or [F2], since $B$ lies in the classification scope. Set $c_u(E)=c_E^*u$. If $c_E'$ is a second classifying map of the same bundle, both maps represent the same element of $[B,BG]$, because the bijection of [F1] or [F2] is defined on homotopy classes and has the same value on them; hence $c_E\simeq c_E'$ and [F3] gives $c_E^*u=c_E'^*u$. Isomorphic bundles have the same classifying homotopy class by the same injectivity, so $c_u$ is well defined on isomorphism classes. For a map $f:B'\to B$ of such bases, $f^*E$ is classified by $c_Ef$, since $(c_Ef)^*\gamma_n\cong f^*c_E^*\gamma_n\cong f^*E$; therefore [F4] gives $$c_u(f^*E)=(c_Ef)^*u=f^*c_E^*u=f^*c_u(E).$$ This clause uses AC exactly through [F1] and [F2]. [F1, F2, F3, F4, A1]

1.2 Every characteristic class comes from a universal class. Let $c$ satisfy the two clauses of the Definition. By [[thm-schubert-cells-give-the-stable-grassmannian-cw-structure]] the Grassmannian model $BG$ is a CW complex, so it lies in both classes, and $\gamma_n$ is a numerable bundle over it by the numeration supplied in [F1]; hence $u:=c(\gamma_n)$ is defined. For a numerable bundle $E\to B$ over a base in both classes with classifying map $c_E$ we have $c_E^*\gamma_n\cong E$, so isomorphism invariance and pullback naturality give $$c(E)=c(c_E^*\gamma_n)=c_E^*c(\gamma_n)=c_E^*u .$$ Thus $c$ is $c_u$ for the universal class $u=c(\gamma_n)$. [F1, F2, given]

2.1 The two passages are inverse and determine all values. Starting with $u$, the identity map classifies the universal bundle, so $c_u(\gamma_n)=\operatorname{id}^*u=u$ by [F4]. Starting with $c$, step 1.2 returns $c$ from $u=c(\gamma_n)$. Hence the assignments $u\mapsto c_u$ and $c\mapsto c(\gamma_n)$ are mutually inverse bijections between universal classes and characteristic classes, and a characteristic class is determined by its single value on the universal bundle. For $n=0$ all three Grassmannian models are points, so both sides reduce to a single class in $H^k(*;R)$, which is zero for $k>0$ and the unit for $k=0$; the empty base carries the zero cohomology groups and the same formulas apply vacuously. All constructions choose only a classifying map, whose ambiguity is absorbed in step 1.1, and no choice beyond [A1] is made. [F1, F2, F3, F4, A1, step 1.1, step 1.2] ∎
