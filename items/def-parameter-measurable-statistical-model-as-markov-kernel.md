## Definition

Suppose an experiment on $(\mathcal X,\mathcal A)$ also has a measurable
parameter space $(\Theta,\mathcal T)$ ([[def-measurable-space]]). A
**Markov kernel** (or **probability kernel**) representation is a function
$$
K:\Theta\times\mathcal A\to[0,1]
$$
such that, for every $\theta\in\Theta$, the set function
$A\mapsto K(\theta,A)$ is a probability measure on $(\mathcal X,\mathcal A)$,
and, for every $A\in\mathcal A$ and every Borel set $C\subseteq[0,1]$,
$$
\{\theta\in\Theta:K(\theta,A)\in C\}\in\mathcal T.
$$
Here the Borel sigma-algebra on $[0,1]$ is generated by its relatively open
subsets $U\cap[0,1]$, where $U$ is open in $\mathbb R$. Thus the second
condition says that each event-probability map $\theta\mapsto K(\theta,A)$ is
measurable. The kernel represents the given experiment exactly when
$K(\theta,A)=P_\theta(A)$ for every $\theta$ and $A$
([[def-statistical-experiment]], [[def-probability-measure]]).

This is an optional parameter-measurable version of a model. An arbitrary
experiment does not include a measurable structure on $\Theta$ or imply this
kernel condition.
