## Definition

Let $K\ge2$, let $Y$ be a random variable into the finite label set $\{1,\ldots,K\}$ with its full power-set sigma-algebra on a probability space $(\Omega,\mathcal F,\mathbb P)$, and let $G=(G_1,\ldots,G_K):\Omega\to\Delta_K$ be a measurable forecast, where $\Delta_K=\{p\in[0,1]^K:\sum_jp_j=1\}$. The forecast is **fully reliable** if for every label $j$ and every Borel set $B\subseteq\Delta_K$,
$$\mathbb P(Y=j,\ G\in B)=\mathbb E[\mathbf1_{\{G\in B\}}G_j].$$
It is **classwise calibrated** if for every $j$ and every Borel set $B\subseteq[0,1]$,
$$\mathbb P(Y=j,\ G_j\in B)=\mathbb E[\mathbf1_{\{G_j\in B\}}G_j].$$
For the **top-confidence calibration** condition, define $C=\max_jG_j$ and $\widehat Y=\min\{j:G_j=C\}$, so ties go to the smallest label. The forecast is top-confidence calibrated if for every Borel set $B\subseteq[0,1]$,
$$\mathbb P(Y=\widehat Y,\ C\in B)=\mathbb E[\mathbf1_{\{C\in B\}}C].$$
A measurable function $r:\Delta_K\to\Delta_K$ is a **calibration function** for $G$ if for every $j$ and every Borel set $B\subseteq\Delta_K$,
$$\mathbb P(Y=j,\ G\in B)=\mathbb E[\mathbf1_{\{G\in B\}}r_j(G)].$$
When such a function is supplied and $d:\Delta_K\times\Delta_K\to[0,+\infty)$ is measurable, the **expected calibration error with discrepancy $d$** is $\eta_d=\mathbb E[d(r(G),G)]$.
