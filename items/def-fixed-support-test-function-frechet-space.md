## Definition

For an integer $n\ge1$, a compact $K\subseteq\Omega$, and an open set $\Omega\subseteq\mathbb R^n$, put $\mathcal D_K=\{\varphi\in\mathcal D(\Omega):\operatorname{supp}\varphi\subseteq K\}$, using [[def-test-function-space-d-of-an-open-set]]. For integers $m\ge0$ set

$$p_m(\varphi)=\max_{|\alpha|\le m}\sup_{x\in K}|\partial^\alpha\varphi(x)|,\qquad d(\varphi,\psi)=\sum_{m=0}^\infty2^{-m-1}\min(1,p_m(\varphi-\psi)).$$

The topology is generated by the seminorms $p_m$: neighborhoods at zero contain finite intersections of $p_m<\varepsilon$ with $\varepsilon>0$. Derivatives are continuous on $K$, so these suprema are finite; for $K=\varnothing$ all suprema are defined as zero and $\mathcal D_K=\{0\}$. For nonempty $K$, $p_0$ separates functions because all functions vanish off $K$. These are increasing seminorms and the displayed series converges since its terms are at most $2^{-m-1}$.

The term **fixed-support Fréchet space** refers to this topology and metric. Their agreement and completeness are established by the registered justifier [[lem-fixed-support-test-function-spaces-are-complete]], rather than included as unproved consequences of the name. If $K$ has empty interior, every test supported in $K$ is zero: a nonzero continuous value would have a neighborhood of nonzero values inside $K$.
