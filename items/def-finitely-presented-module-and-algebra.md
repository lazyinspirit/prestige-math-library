## Definition

Let $R$ be a commutative ring. For $n\in\mathbb N$ write $R^n$ for the free
$R$-module $R^{(\{1,\ldots,n\})}$ on an $n$-element set, with standard basis
$e_1,\ldots,e_n$ ([[def-free-module-on-a-set-and-standard-basis]]); at $n=0$ the
index set is empty and $R^0=0$.

**Finitely presented modules.** An $R$-module $M$ is **finitely presented** when
there are $m,n\in\mathbb N$ and module homomorphisms making

$$R^{m}\xrightarrow{\ \alpha\ }R^{n}\xrightarrow{\ \beta\ }M\longrightarrow0$$

an exact sequence ([[def-exact-and-short-exact-sequences-of-modules]]): that is,
$\operatorname{im}\alpha=\ker\beta$ and $\beta$ is surjective
([[def-module-homomorphism-kernel-image-and-cokernel]]).

**The equivalent quotient form.** $M$ is finitely presented exactly when
$M\cong R^{n}/K$ for some $n\in\mathbb N$ and some finitely generated submodule
$K\le R^{n}$ ([[def-generated-cyclic-finitely-generated-and-free-modules]]).
Given a presentation, put $K=\ker\beta=\operatorname{im}\alpha$, which is
generated by $\alpha(e_1),\ldots,\alpha(e_m)$, and
[[thm-first-isomorphism-theorem-modules]] gives $M\cong R^{n}/K$. Conversely,
given $M\cong R^{n}/K$ with $K$ generated by $k_1,\ldots,k_m$, the universal
property of the free module ([[thm-universal-property-of-free-modules]])
supplies $\alpha\colon R^{m}\to R^{n}$ with $\alpha(e_j)=k_j$, whose image is
$K$, and composing the canonical projection with the isomorphism gives $\beta$;
the displayed sequence is then exact.

**Finitely presented algebras.** A commutative $R$-algebra $A$ is **finitely
presented** when there are $n\in\mathbb N$ and a finitely generated ideal
$\mathfrak a\subseteq R[x_1,\ldots,x_n]$
([[def-generated-and-principal-ideals]]) with $A\cong R[x_1,\ldots,x_n]/\mathfrak a$
as an $R$-algebra.

**Finitely presented implies finitely generated, in both senses.** A finitely
presented module is generated by $\beta(e_1),\ldots,\beta(e_n)$, since $\beta$
is surjective. A finitely presented algebra is of finite type
([[def-finite-type-and-module-finite-algebras]]), being a quotient of
$R[x_1,\ldots,x_n]$.

**The boundary values are admitted.** Taking $m=n=0$ presents the zero module,
and taking $m=0$ with $n$ arbitrary presents the free module $R^n$; taking
$\mathfrak a=0$ presents the polynomial algebra itself.

## Remarks

- **What finite presentation adds to finite generation is a bound on the
  relations.** Finite generation says $M$ is a quotient of some $R^n$; finite
  presentation says the kernel of that quotient map is itself finitely
  generated. Over an arbitrary commutative ring the second is strictly stronger.

- **The two notions carry the same name and are not the same condition.** A
  finitely presented algebra is finitely presented as an algebra, which
  constrains a defining ideal in a polynomial ring, and says nothing on its own
  about the underlying module.
